# 自动化中心：提示词 Agent 自动化 · 定时工作流

> **一句话**：EvoFlow 自动化中心统一管理**自动化配置、运行计划与执行历史**，包含两种到点执行模式——**提示词驱动的 Agent 执行**，以及**已发布工作流的定时触发**。  
> 它不是「普通定时提醒 + 工作流自动化」的简单拼接；也**不是** AI 员工的主动上班 / 巡检。

侧栏入口：**自动化**（`#/cron`）。操作见 [自动化操作指南](../guides/tasks/scheduled-tasks.md)。

正式功能全景图建议命名：**《EvoFlow 自动化中心功能全景图》**，突出四块：**提示词 Agent 自动化 · 定时工作流 · 调度管理 · 执行历史**。

---

## 1. 两大核心功能

| 模式 | 执行主体 | 执行依据 | 典型例子 |
|------|----------|----------|----------|
| **01 自动化任务（Agent 执行）** | 所选 Agent / 在编员工 | 自然语言提示词；到点由 Agent 理解并完成，**不要求**事先编排工作流 | 「每天上午检查 AI 行业最新动态，总结五条值得关注的新闻。」 |
| **02 定时自动化（工作流执行）** | 已发布工作流 | 预设流程；到点触发该工作流，**不是**每次重新由 Agent 自主规划步骤 | 「每天早上 9 点自动执行商品数据分析工作流。」 |

面板创建时「执行内容」二选一：**提示词** / **已发布工作流**（与上表一一对应）。

---

## 2. 执行 Agent 选谁？（已确认）

**不是**只能用自动化中心内置的通用 Agent。

提示词模式（自动化任务）下，用户可**选择执行者**：

| 情况 | 行为 |
|------|------|
| 已有在编 **AI 员工** | 优先从员工名册选择（面板展示为执行员工 / 岗位名） |
| 暂无在编员工 | 回退到已有**智能体**列表供选择 |

因此：自动化中心与 AI 员工体系是**可衔接**的——同一岗位能力既可值班主动干活，也可被自动化任务按计划叫醒执行固定提示词。  
定时工作流模式的执行者由**工作流步骤自身**指定，不在此再选员工。

这不等于把自动化任务变成「员工值班」：员工主动巡检仍归 [AI 员工中心](smart-employees.md)，见下文对比表。

---

## 3. 功能清单（全景图草案）

| 功能模块 | 具体功能 |
|----------|----------|
| **自动化任务** | 创建任务、编写提示词、选择执行 Agent / 员工、配置运行计划 |
| **定时自动化** | 选择已有（已发布）工作流、配置定时规则、自动触发执行 |
| **调度管理** | 执行时间、重复周期、启用 / 停用、下次运行时间 |
| **任务管理** | 自动化列表、配置编辑、状态查看、删除 |
| **执行历史** | 历史运行记录、执行时间、成功 / 失败状态、执行结果 |
| **执行详情** | 单次执行过程、输出结果及异常信息 |

**出图暂不列为已确认能力位**（避免画进全景图主叙事）：手动运行、重试、通知推送等。面板若已有对应按钮，以操作指南为准，概念图仍以四块重点为主。

**明确不画进本中心**：工作流「业务参数传递」——与任务中心 / Agent 应用已对齐的边界一致，定时工作流也不新增该能力位。

## 5. 与 AI 员工主动工作的区别

| 对比 | 自动化任务 | 定时自动化 | AI 员工主动工作 |
|------|------------|------------|-----------------|
| **执行主体** | Agent / 所选员工（按提示词跑一轮） | 工作流 | AI 员工 |
| **执行依据** | 提示词要求 | 预设流程 | 岗位职责与工作策略 |
| **启动方式** | 配置的自动化计划 | 定时调度 | 员工自己的上班与巡检策略 |
| **管理位置** | 自动化中心 | 自动化中心 | AI 员工中心（侧栏「员工」） |

**特别注意**：AI 员工每隔几小时主动检查、主动工作，**不属于**自动化中心的这两种自动化。

与[任务中心](task-center.md)的关系：到点触发后，工作流跑次等可进入任务中心观测；自动化中心本身管的是**规则与运行历史**，不是待办 / 员工协作派发账本。

---

## 6. 出图统一遵守

1. 两大模式并列：**提示词 Agent 自动化** ∥ **定时工作流**。  
2. 四块重点：上述两模式 + **调度管理** + **执行历史**。  
3. 提示词模式可选**在编 AI 员工**（或智能体），非强制内置唯一 Agent。  
4. 不把员工主动值班画进自动化中心。  
5. 不画「业务参数传递」。  
6. 手动运行 / 重试 / 通知等不进本全景图主能力清单（除非后续产品单独确认）。
