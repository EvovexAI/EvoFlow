# 资产中心

> **资产中心就是 AI「关于你」和「会干什么」的笔记本。**
>
> 你平时只要在对话里说：
> - **「记住……」** → 记成一条事实  
> - **「把这套做法沉淀成经验」** → 写成可复用的本事  
> - **「记一下今天的反思」** → 写进当日反思  
>
> AI 会直接写进本地文件。你打开 **侧栏 → 资产中心**（`#/assets`），主要是**看看写了啥、改个错字**，不是天天填表。

## 和「知识库」「旧记忆页」有什么不同

| | 资产中心 | 知识库 | （旧）记忆文件页 |
|--|----------|--------|------------------|
| **存什么** | 画像、偏好事实、过程记录、反思、专长经验 | 你整理的文档 / Vault 笔记 | 已并入资产中心 |
| **谁写入** | 多半是对话里 AI 自动写；你也可侧栏快捷沉淀 | 你导入或编辑文档 | — |
| **入口** | 侧栏「资产中心」 | 侧栏「知识库」 | 会跳到资产中心「记忆」 |

记忆存的是「你是谁、你喜欢什么、做过什么」；知识库存的是「某份材料/笔记正文」。两者 AI 都可能参考，但**不是同一套东西**。

## 你平时怎么用（推荐）

1. **对话里说一句**（主路径）  
   - 记录：`记住我默认用 Python`  
   - 沉淀经验：`把刚才这套排查沉淀成经验`  
   - 反思：`记一下今天的 wrap-up`  
2. **需要时打开资产中心**  
   切换「我 / 某个 Agent / 某个员工」，翻画像、记忆、经验、反思、专长。  
3. **发现记错了**  
   点开文件改两行 → 保存。下一轮对话就会按新内容来。

聊天侧栏「信息」里也有 **记录 / 沉淀经验 / 反思** 快捷按钮，等价于让当前 Agent 立刻落盘。

## 页面里有什么

| Tab | 你能看到什么 |
|-----|----------------|
| **画像** | 用户画像、身份边界、人格等说明文件 |
| **记忆** | 站立摘要、事实、过程记录；也可看记忆图谱 |
| **经验 / 专长** | 沉淀下来的本事（`craft`）；可晋升为自定义技能 |
| **反思** | 按日的反思日志 |
| **统计** | 哪些文件常被用到、哪些久未使用、有多少草稿待整理；可「整合 inbox」或「全库扫描」 |
| **导出** | 打包备份、把资产**应用到**某个员工/Agent |

> 这里的「导出 Pack」是 **实体资产**备份。若要把整套「员工 + 工作流 + 扩展」分享给别人，见 [资源包与资源市场](../guides/configuration/resource-packs.md)。

回复气泡下若出现**引用标签**，点一下可跳到对应资产文件（表示这次回答参考了哪条记录）。

## 系统还会自动做什么

- 对话告一段落后，会把偏好与可复用经验整理进资产（不必你每次手动点）  
- 软件启动时，也会扫一遍未整理的草稿并尝试合并  
- 长对话被压缩后，助手更倾向用资产检索补细节，而不是只靠摘要猜

这些都可以在环境变量里关闭（一般保持默认开启即可），见仓库根目录 `.env.example` 中的 `EVOFLOW_ASSET_*` 说明。

## 常见问题

**Q：我必须每天来资产中心维护吗？**  
不必。日常靠对话里说「记住 / 沉淀 / 反思」；资产中心是翻看与校对。

**Q：记错了怎么办？**  
打开对应文件改掉并保存；或删掉明显过时的文件。统计页里的「冷资产」可帮你找久未使用的条目。

**Q：和知识库该放哪边？**  
偏好、习惯、个人/岗位经验 → 资产中心；制度、手册、长文档 → 知识库。

**Q：员工和「我」的资产是分开的吗？**  
是的。顶部可切换实体（我 / Agent / 员工）。需要时用「导出 → 应用到…」把某份资产拷给员工。
