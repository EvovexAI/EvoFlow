# 加人：第一个员工

> **先分清智能体和员工**
>
> 1. **区别**：智能体管「会什么」（人设、模型、工具、技能、连接器 MCP）。员工管「何时主动干」（岗位、职责、部门与上级、上班时间、转交审批、工作空间、绑定知识库、预算）。聊天里 @ 智能体不会自动值班。
> 2. **员工能配什么**：加人时填岗位名称、职责、部门、上级、知识库；更多设置里有能力来源、工作空间、工作模型、转交审批（全自动 / 平衡型 / 谨慎型）、自动上班。编辑岗位还可配工作方式、模型思考、系统提示词注入、知识库检索和预算。工具、技能、连接器到「智能体」页改。
> 3. **怎么操作**：侧栏「员工」→「加人」→ 填岗位和至少一条职责 →「确认加人」→ 打开自动上班，或点「现在开始工作」，急活用小V 派活。交工后到任务中心确认或打回。字段见 [智能体员工](../guides/configuration/smart-employees.md)。

> **目标**：加一个值班岗，打开自动上班，手动开工一轮，并知道待审批和工作日志在哪。
>
> 概念见 [智能体员工是什么](../explanation/smart-employees.md)；字段见 [智能体员工](../guides/configuration/smart-employees.md)。

## 你将学到什么

- 智能体（会什么）和员工（何时主动干）的差别
- 如何加人、开自动上班、现在开始工作
- 去哪处理待审批、去哪看工作轨迹与工作汇报

## 前置条件

- 已打开 EvoFlow 桌面端或 Web
- 已配置至少一个可用对话模型（没有模型时只能存草稿）
- 工作空间可以加人后再选；不选则用默认工作空间

不必先去「智能体」页建角色。加人会自动创建能力。只有要沿用已经配好的人设、工具和连接器时，才在更多设置里选「沿用未入职能力」。

预计用时：**10～15 分钟**。

## 步骤

### 1. 先分清两页

| | 智能体 | 员工 |
|--|--------|------|
| 入口 | `#/expert` | `#/proactive`，按钮 **加人** |
| 管什么 | 人设、模型、工具、技能、连接器（MCP） | 岗位、职责、部门、上级、知识库、工作空间、审批、上班时间 |
| 不会做 | 不会按点自己上班 | 不在这里安装连接器、不改人设正文 |

### 2. 加人

1. 打开侧栏 **员工**
2. 点 **加人**（也可先点一个模板预填）
3. 填写：
   - **岗位名称**（如：研发助理）
   - **职责**（每行一条，写可检查的事，例如「每轮检查工作区是否有未提交的调试日志并报告」）
   - **部门**、**直属上级**、**绑定知识库**（都可以先空着）
4. 展开 **更多设置**（可选）：
   - **能力来源**：保持「自动创建能力」
   - **管辖工作空间**
   - **转交审批策略**：先选 **谨慎型**
   - **自动上班**时间表
5. 点 **确认加人**（也可先 **保存草稿**）

名册里应出现该员工。草稿需要再点 **确认上班** 才会参与自动上班。

### 3. 开启全局值班

在页头 **自动上班总开关**：

1. 若显示「值班已关闭」，点 **开启自动上班**
2. 状态应变为 **员工自动上班中**，并显示在岗人数

> 单岗「请假」只停这一人；全局「关闭自动上班」会停掉所有人的自动上班。

### 4. 现在开始工作一轮（不必等自动上班）

1. 在该员工卡片 **⋯** 菜单点 **现在开始工作**
2. 可选：勾选「本轮事项」聚焦某一项
3. 等待本轮跑完（卡片可能显示「工作中」）

同时可打开 **小V** → **对话** → 点选该员工，边看汇报边等。

### 5. 处理待审批（有下游交工或事项时）

新任务默认会直接开跑；待审批更常见于：

- **交接审批** → 点 **同意派发**（上游已交工、等放行叫醒下级）  
- 少数 **事项同意** → 点 **同意**

步骤：

1. 切到 **待审批** Tab  
2. 看芯片：有「交接审批」用 **同意派发**，否则用 **同意**  
3. 不合适则 **驳回**（填原因）；快捷键 `Y` / `N` / `J`

单岗试用若本轮没有下游、也没有事项，待审批可能是空的——属正常。

### 6. 看上班记录与工作过程

1. 点卡片近况，进入 `#/proactive/<agent_code>`
2. 打开 **上班记录**，找到本轮
3. 需要细节时点 **工作过程**
4. 若出现「本轮汇报未写完」，按员工指南排查，不要只改职责文案

### 7. 交工后如何验收（若本轮有交工）

1. 打开对应 **工作项详情**，或到任务中心点进该协作任务
2. 阅读 **任务总结** / 交付物
3. **确认完成**，或 **要求修改**（须写说明）
4. 有下游转交时，在员工页 **待审批** 用 **同意派发**，不要和验收混用

## 验收清单

- [ ] 名册里有该岗，且自动上班总开关为「员工自动上班中」
- [ ] 至少成功触发过一次「现在开始工作」
- [ ] 知道待审批在哪处理（含同意 vs 同意派发）
- [ ] 能打开上班记录 / 工作过程
- [ ] （可选）小V 里能对该员工发一条临时委派
