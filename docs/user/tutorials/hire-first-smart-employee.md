# 雇佣第一个智能体员工

> **目标**：从零雇佣一个「值班岗」，开启值班，手动开工一轮，并知道待审批 / 工作日志在哪看。
>
> 适合第一次接触「智能体员工」的用户。概念背景见 [智能体员工是什么](../explanation/smart-employees.md)；字段与排障见完整指南 [智能体员工](../guides/configuration/smart-employees.md)。

## 你将学到什么

- 智能体（会什么）和智能体员工（何时主动干）的差别
- 如何雇佣、开值班、立即开工
- 去哪处理待审批、去哪看工作轨迹与交班

## 前置条件

- 已安装并打开 EvoFlow 桌面端 / Web
- 已配置至少一个可用对话模型
- 「智能体」页里已有可用角色（可用预设，或先走 [创建自定义 Agent](create-agent.md)）
- 聊天侧栏已添加至少一个本机**工作空间**目录

预计用时：**10～15 分钟**。

## 步骤

### 1. 确认「会什么」——智能体页

1. 打开侧栏 **智能体**（`#/expert`）
2. 选一个合适的角色（例如通用助手、运维相关角色），确认：
   - 工具权限够用（至少能读写工作区；巡检类需要 terminal 等）
   - 人设 / SOUL 写得清楚
3. 可直接点卡片上的 **雇佣**，或记住该角色，下一步在员工页选择

> 人设和工具只在「智能体」页改；岗位页不管「会不会写代码」，只管「什么时候上班、盯哪块盘」。

### 2. 雇佣上岗

1. 打开侧栏 **智能体员工**（`#/proactive`）
2. 点 **雇佣员工**（若上一步已点雇佣，表单会带上该智能体）
3. 填写最少字段：
   - **选择智能体**
   - **岗位名称**（如：仓库巡检）
   - **职责**（每行一条，写具体可验收的事，例如「每轮检查工作区是否有未提交的调试日志并报告」）
   - **管辖工作空间**（必选）
   - **交接审批策略**：先选 **谨慎型**
   - **上岗节奏**：可先选每 30 分钟或每小时
4. 点 **确认上岗**（也可先「保存草稿」再确认）

名册里应出现该员工，状态接近「上班中」或「草稿→确认后上班中」。

### 3. 开启全局值班

在页头 **值班台**：

1. 若显示「值班已关闭」，点 **开启值班**
2. 状态应变为 **全员值班中**，并显示在岗人数

> 单岗「请假」只停这一人；全局「结束值班」会停掉整台值班引擎的自动心跳。

### 4. 立即开工一轮（不必等心跳）

1. 在该员工卡片 **⋯** 菜单点 **立即开工**
2. 可选：勾选「本轮事项」聚焦某一项
3. 等待本轮跑完（卡片可能显示「工作中」）

同时可打开 **小V** → **对话** → 点选该员工，边看汇报边等。

### 5. 处理待审批（谨慎型几乎总会碰到）

1. 切到 **待审批** Tab  
2. 阅读事项说明  
3. `Y` / **同意**（若是跨岗交接芯片「交接审批」，用 **同意派发**）  
4. 不合适则 **驳回**（填原因）

清掉阻塞后，员工才能继续往下干。

### 6. 看工作日志与工作轨迹

1. 点卡片近况，或进入 `#/proactive/<agent_code>` **工作日志**
2. 找到本轮记录；需要细节时点 **工作轨迹**
3. 看是否有 **本轮小结**；若出现「自动交班·未完成」，按指南排查，不要只改职责文案

### 7. 交工后如何验收（若本轮有交工）

1. 打开对应 **工作项详情**（状态可能是「待你验收」）
2. 阅读 **任务总结** / 本岗交付物
3. **确认完成** 或 **打回重做**
4. 也可到 [任务中心](../guides/tasks/task-center.md)「智能体员工」来源里统一验收

## 验收清单

- [ ] 名册里有该岗，且值班台为「全员值班中」
- [ ] 至少成功触发过一次「立即开工」
- [ ] 知道待审批在哪处理（含同意 vs 同意派发）
- [ ] 能打开工作日志 / 工作轨迹
- [ ] （可选）小V 里能对该员工发一条临时委派
