# 加人：第一个员工

> **先分清智能体和员工**
>
> 1. **区别**：智能体管「会什么」（名称、系统提示词、人设、工具、技能、连接器 MCP）。员工管「何时主动干」（部门与上级、巡检时间、交工审核、工作空间、绑定知识库、预算）。名称与提示词共用智能体，不再单独维护「岗位职责」清单。聊天里 @ 智能体不会自动值班。
> 2. **员工能配什么**：加人时填名称、系统提示词、部门、上级、知识库；更多设置里有能力来源、工作空间、工作模型、交工审核（需要审核 / 无需审核；编辑还可选「有风险才审」）、自动巡检时间表。编辑共八段（含内置工具 / MCP / 技能）。字段见 [智能体员工](../guides/configuration/smart-employees.md)。
> 3. **怎么操作**：侧栏「BOT」→「加人」→ 填名称与系统提示词 →「确认加人」→ 打开自动巡检，或点「现在开始工作」，急活用小V 派活。交工后到任务中心确认或打回。多人同屏见 [部门群聊](../guides/chat/dept-group-chat.md)。

> **目标**：加一个值班岗，打开自动巡检，手动开工一轮，并知道待审批和巡检记录在哪。
>
> 概念见 [智能体员工是什么](../explanation/smart-employees.md)；字段见 [智能体员工](../guides/configuration/smart-employees.md)。

## 你将学到什么

- 智能体（会什么）和 BOT / 员工（何时主动干）的差别
- 如何加人、开自动巡检、现在开始工作
- 去哪处理待审批、去哪看巡检记录与工作过程
- （可选）编入部门后怎么进部门群聊

## 前置条件

- 已打开 EvoFlow 桌面端或 Web
- 已配置至少一个可用对话模型（没有模型时只能存草稿）
- 工作空间可以加人后再选；不选则用默认工作空间

不必先去「智能体」页建角色。加人会自动创建能力。只有要沿用已经配好的人设、工具和连接器时，才在更多设置里选「沿用未入职能力」。

预计用时：**10～15 分钟**。

## 步骤

### 1. 先分清两页

| | 智能体 | BOT / 员工 |
|--|--------|------|
| 入口 | `#/expert` | `#/proactive`（侧栏 **BOT**），按钮 **加人** |
| 管什么 | 人设、模型、工具、技能、连接器（MCP）、平台能力 | 部门、上级、交工审核、巡检时间；编辑里也可改工具 / MCP / 技能 |
| 不会做 | 不会按点自己巡检 | 不在这里安装新的 MCP 服务（装连接器去设置） |

### 2. 加人

1. 打开侧栏 **BOT**
2. 点 **加人**（也可先点一个模板预填）
3. 填写：
   - **岗位名称**（如：研发助理）
   - **系统提示词**（写可检查的事，例如「每轮检查工作区是否有未提交的调试日志并报告」——不要写「好好工作」）
   - **部门**、**直属上级**、**绑定知识库**（都可以先空着；有部门才能进部门群）
4. 展开 **更多设置**（可选）：
   - **能力来源**：保持「自动创建能力」
   - **管辖工作空间**
   - **交工审核**：先选 **需要审核**
   - **自动巡检**时间表
5. 点 **确认加人**（也可先 **保存草稿**）

名册里应出现该员工。草稿需要再点 **确认启用** 才会参与自动巡检。

### 3. 开启自动巡检（全局）

在页头 **自动巡检** 开关：

1. 若显示 **已关闭**，拨到开
2. 状态应变为 **已开启**，并显示在岗人数

> 单岗「停用」只停这一人；全局「关闭自动巡检」会停掉所有人的**到点巡检**，但员工仍显示「已启用」，仍可对话 / 派活。

### 4. 现在开始工作一轮（不必等自动巡检）

1. 在该员工卡片 **⋯** 菜单点 **现在开始工作**
2. 可选：勾选「本轮事项」聚焦某一项
3. 等待本轮跑完（卡片可能显示「工作中」）

同时可打开 **小V** → **对话** → 点选该员工，边看汇报边等。

### 5. 处理待审批（有下游交工或事项时）

新任务默认会直接开跑；待审批更常见于：

- **交接审批** → 点 **同意派发**（上游已交工、等放行叫醒下级）  
- 少数 **事项同意** → 点 **同意**

步骤：

1. 切到 **待审批** Tab（或 `#/proactive?tab=approvals`）
2. 点 **同意派发** 或 **驳回**（驳回须写说明）

### 6. 看巡检记录与验收

1. 点进该员工 → **巡检记录**：看近几轮小结  
2. 需要细节：开 **工作过程**（是否真调了工具）  
3. 交工验收：工作项详情或 [任务中心](../guides/tasks/task-center.md) → **确认完成** / **要求修改**

### 7.（可选）部门群聊

若加人时选了部门：

1. 首页总览组织指挥台 → 部门卡 → **打开部门群聊**  
   或 BOT 侧栏部门旁点 **进群**
2. 直接说事由由负责人接；写 `@岗位名` 点名  
3. 派工条看排队中 / 回答中 / 已回 / 失败  

详见 [部门群聊](../guides/chat/dept-group-chat.md)。

## 验收清单

- [ ] 侧栏 BOT 能看到新岗，状态不是草稿（或已确认启用）
- [ ] 页头自动巡检为已开启（或你已用「现在开始工作」跑通一轮）
- [ ] 知道待审批主按钮是「同意派发」
- [ ] 知道巡检记录与工作过程在员工详情
- [ ] （可选）能进部门群并 @ 一次

## 常见问题

**加人了但不干活？**  
查自动巡检是否开启、是否草稿/已停用、系统提示词是否具体、模型 Key，再「现在开始工作」。

**必须先建智能体吗？**  
不必。

**同级能交工吗？**  
同一上级下的平级可以正式交工；跨上级用派发 / 小V / 部门群。
