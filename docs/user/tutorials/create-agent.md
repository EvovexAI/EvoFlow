# 创建自定义智能体

> **先分清智能体和员工**
>
> 1. **区别**：智能体管「会什么」（人设、模型、工具、技能、连接器 MCP）。员工管「何时主动干」（岗位、职责、部门与上级、上班时间、转交审批、工作空间、绑定知识库、预算）。聊天里 @ 智能体不会自动值班。
> 2. **员工能配什么**：加人时填岗位名称、职责、部门、上级、知识库；更多设置里有能力来源、工作空间、工作模型、转交审批（全自动 / 平衡型 / 谨慎型）、自动上班。编辑岗位还可配工作方式、模型思考、系统提示词注入、知识库检索和预算。工具、技能、连接器到「智能体」页改。
> 3. **怎么操作**：侧栏「员工」→「加人」→ 填岗位和至少一条职责 →「确认加人」→ 打开页头「自动上班」，或点「现在开始工作」，急活用小V 派活。交工后到任务中心确认完成或要求修改。

每个智能体是一份可复用的能力：名称、系统提示词、人格 SOUL、默认模型、工具、MCP、技能。它不会自己按点上班；要值班再到 [员工](../guides/configuration/smart-employees.md) 加人。

## 前置条件

- 已完成 [安装](../getting-started/installation.md)
- 已配置至少一个对话模型（设置 → 模型）

## 预计用时

约 10 分钟

## 步骤

### 1. 打开智能体中心

1. 侧栏点 **智能体**（`#/expert`）
2. 确认页头是「智能体中心」，顶栏在 **智能体** Tab（不是技能 / 连接器）

### 2. 新建智能体

1. 点右上角 **新建智能体**
2. 在 **基本信息** 填写：
   - **角色标识**（必填，创建后不可改，如 `research-assistant`）
   - **中文名称**（如「调研助手」）
   - 可选：角色描述、默认模型、标签、系统提示词
3. 左侧切到 **人格 SOUL**，写清性格与边界，例如：

```
你是专业的研究助手，擅长信息搜集、分析和报告撰写。
回答要结构清晰、引用准确；不确定时先说明假设。
```

4. （可选）在 **内置工具 / MCP 服务 / 技能模块** 里按最小权限勾选
5. 点 **创建智能体**

### 3. 在聊天里试用

1. 新开对话，输入框 `@` 刚建的智能体
2. 问一句符合其职责的问题，看口吻与工具是否符合预期
3. 不对就回列表 ⋯ → **编辑** → **保存更改**，再新开对话验证

### 4.（可选）加入员工编制

若要按点上班：卡片上点 **加入员工**，或去侧栏 **员工** → **加人**，在「能力来源」里选这个智能体。

## 验收清单

- [ ] 「我的智能体」列表里能搜到
- [ ] 新对话 `@` 后回复风格符合 SOUL / 系统提示词
- [ ] （若勾了 MCP）已安装连接器为可用，且该智能体「MCP 服务」已勾选
