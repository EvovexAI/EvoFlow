## 这是什么（一句话）

雇一个 AI **按岗位自动上班**：盯你的文件夹/仓库，写工作清单；你只用看结果，偶尔点一下审批。

作者是**个人开发者**，适合先自己试用；不是企业多账号系统。

## 开始前：配一个对话模型

1. 打开侧栏 **模型**  
2. 添加你可用的 API / 本地模型并设为默认  
3. 没有模型时，雇佣员工会被拦住（可以先保存草稿）

---

## 10 分钟：雇第一个「研发助理」员工

1. 侧栏打开 **智能体**，确认已有可用智能体（可用预设）  
2. 打开 **智能体员工** → **雇佣员工**  
3. 点模板 **研发助理**（会预填职责与节奏）  
4. **管辖工作空间**：选你的项目目录（须先在聊天侧栏加过本机目录）  
5. **确认上班** → 页头 **开启自动上班**  
6. 员工卡片 ⋯ → **现在开始工作**  
7. 等一轮结束：在工作日志（默认近 2 天）或任务总结里看清单  

更细步骤：[雇佣第一个智能体员工](../../user/tutorials/hire-first-smart-employee.md) [[tutorials/hire-first-smart-employee|雇佣第一个智能体员工]]（仓库文档；飞书里可改成你的站点链接）。

## 你会在哪处理审批？

- **待审批**里常见的是交工后的 **同意派发**（有下游时才出现）  
- 单岗多数时候待审批是空的——正常  
- 验收看 **任务总结** → 确认完成 / 打回  

---

## 卡住了？

| 现象 | 先做 |
|------|------|
| 雇不了 / 选不到工作区 | 聊天侧栏先加本机目录 |
| 开工没反应 | 检查模型是否配好；看员工是否「请假」 |
| 汇报未写完 | 打开该员工 **工作过程**；或再点一次「现在开始工作」 |
| 想看历史任务 | 员工页 **本岗全部任务** → 任务中心 |

反馈：【填你的微信号 / 飞书群】
