# 工作流

> **新手可跳过**：这是进阶功能，日常聊天就够用。等你需要把同一套步骤反复跑、每次只换参数（比如每周换个周次生成周报）时，再来本页。

侧栏入口：**工作流**（`#/apps`）。页头文案是「工作流」——把跑通的流程存成模板，以后填参数就能直接跑，不用每次从头聊。

旧文档里的「应用中心」指的就是这一页。任务中心**类型**筛选里对应标签也是 **工作流**（含自动化触发的跑次）。

> 别和任务详情里的执行流程图搞混：`#/apps` 是**搭流程的画布**，要你事先编排；任务详情里的 `#/workflow/:id` 是**某次运行的执行步骤图**，不用事先来这里建任何东西。

推荐路径：新建 → 画布编排 → **试跑** → **发布** → 卡片 **▶ 运行** 或 **怎么用** → 在 [任务中心](../tasks/task-center.md) 看执行。

---

## 5 分钟固化第一条

1. 侧栏打开 **工作流**，点 **新建工作流 ▾** → **空白工作流**（或从模板 / 从任务沉淀）。
2. 进画布：顶栏点 **节点**（或展开右上悬浮面板的「节点库」）加步骤，用线定先后。
3. 点某一步：在悬浮面板「配置」里写任务名与本步目标，再在 **本步能力** 里挂技能 / 工具 / MCP / 知识库，并可为本步选模型与思考开关。执行者只是「执行壳」，能力以本步配置为准。
4. 点 **设置**：可选填描述；建议设 **工作空间**（默认运行目录，各步可覆盖）；运行参数按需添加。
5. 点 **试跑** 在画布内填参验证（草稿也可）。
6. 满意后点 **发布**。回到列表，已发布卡片点 **▶ 运行**；画布上也可点 **怎么用**（面板运行 / API / 自动化）。

## 和聊天 / 任务 / 员工的区别

| 能力 | 适合 |
|------|------|
| **实时聊天 / Plan** | 探索、一次性复杂协作 |
| **任务中心** | 看某次执行、验收、同意派发；类型可筛「工作流」 |
| **员工** | 岗位值班、心跳巡检、跨岗转交 |
| **自动化** | 到点触发提示词或已发布工作流 |
| **工作流**（本文） | 流程已固定，只换参数反复开跑 |

注意：`#/workflow/:id` 是协作任务的全屏 DAG（从任务详情打开），**不是**本页画布。画布在 `#/apps/:id`。

| 路由 | 用途 |
|------|------|
| `#/apps` | 工作流列表 |

## 列表页

页头提示：① 点卡片进画布编排 → ② **发布** → ③ ⋯ **填参运行**（已发布卡片上也有 **▶ 运行**）。

| 控件 | 说明 |
|------|------|
| 筛选 | **活跃** / **已归档** / **全部** |
| 搜索 | 「搜索工作流…」按名称、描述 |
| **新建工作流 ▾** | **空白工作流** / **从模板创建** / **从任务沉淀** |
| **刷新** | 重载列表 |
| 卡片 | 点空白处进画布；显示步数、参数数、状态徽章 |
| 状态 | **草稿** / **已发布** / **已归档** |

### 已发布卡片

| 操作 | 说明 |
|------|------|
| **▶ 运行** | 进 `#/apps/:id/run` |
| **编辑流程** | 回画布 |
| ⋯ **填参运行** | 同运行 |
| ⋯ **编辑信息** | 改名称、描述、图标、执行方式 |
| ⋯ **归档** | 离开活跃列表；不能新开填参 / API；可 **恢复为草稿** |
| ⋯ **删除** | 定义与运行记录一并删除 |

草稿卡片没有底部运行按钮；点卡片进画布试跑，满意再发布。空态可 **创建空白工作流** 或 **从模板创建**。

## 画布 `#/apps/:id`

### 顶栏（与界面一致）

| 控件 | 说明 |
|------|------|
| 返回 | 回工作流列表 |
| 名称 | 可直接改；未命名占位「未命名工作流」 |
| 状态徽章 | 草稿 / 已发布 / 已归档 |
| **节点** | 展开右上悬浮面板并切到「节点库」 |
| **设置** | 打开「工作流设置」（描述、工作空间、执行方式、运行参数） |
| **历史** | 跳转运行历史 |
| **怎么用** | 已发布时一级按钮；草稿在「更多」里。面板运行 / API / 自动化说明 |
| **更多** | **版本**、**操作记录**、**单步验证**（开发者）、**整理视图**；草稿时还有「怎么用」 |
| **保存** | 存草稿；已发布上保存会立刻更新线上定义 |
| **发布** / **更新发布** | 列表填参运行与 API 的前置条件 |
| **试跑** | 画布内填参试跑（草稿也可） |

### 右上悬浮面板

节点库与节点配置合并为一张悬浮卡（可收起成「面板」气泡）：

| Tab | 作用 |
|-----|------|
| **节点库** | 系统节点（开始、输出等）与任务步骤；拖到画布或点一下添加 |
| **配置** | 选中节点后自动展开：任务名、目标、工作空间、本步能力 |

选中画布节点会自动切到「配置」。顶栏「节点」也可强制展开节点库。

### 配置一步任务

点任务步骤后，在「配置」里按顺序填：

1. **任务名称**（必填）— 画布上显示的短名  
2. **目标**（可选）— 本步要做什么；可用 `/` 引用运行变量  
3. **工作空间**（建议）— 本步目录；留空则用工作流默认工作空间  
4. **本步能力** — 显式挂载本步要用的能力，勿留空指望「执行者默认能力」：
   - **模型** + **思考**开关（可跟系统默认，或为本步单独指定）
   - **技能** / **工具**（合一选择面板，可多选）
   - **MCP** 服务器
   - **知识库**

执行者用下拉直选；「编辑执行者」打开员工 / 智能体编辑。执行者是执行壳，**本步实际能力以本步配置为准**。

### 工作流设置（点「设置」）

标题是「工作流设置」：

| 区块 | 内容 |
|------|------|
| **描述** | 可选；给人看的说明 |
| **工作空间** | 默认运行目录（各步可覆盖）；留空则运行时再解析 |
| **执行方式** | **按步骤自动跑完**（推荐）或 **先确认计划再执行**（高风险，生成计划后需人工确认） |
| **调度触发时自动执行** | 定时或接口触发时无需人工确认 |
| **运行参数** | 填参页 / OpenAPI 用的字段表 |

保存设置点 **保存设置**。

发布成功后会引导打开 **怎么用**（填参运行或创建 API Key）。

## 填参运行 `#/apps/:id/run`

| 控件 | 说明 |
|------|------|
| ← 工作流列表 | 返回 |
| **编辑流程** | 回画布 |
| 参数表单 | 按定义填写 |
| **运行** | 启动；跑次进任务中心，类型为「工作流」 |
| 运行中 | 可 **暂停** / **继续** / **取消**（以界面按钮为准） |

页上说明：填参 → 运行 → 看结果；改流程去「编辑流程」。发布后可在画布 **怎么用 → API** 建 Key。

监督模式（先确认计划）启动后，需在任务里确认再执行。

试跑 / 正式跑时，点画布上的步骤可打开节点对话（与协作任务节点进度同款：可续聊、进行中可刷新）。

## 运行历史 `#/apps/:id/history`

- 分页浏览历次运行
- 点 **查看结果** 打开大屏详情（节点产出、最终 HTML 等）
- **← 返回画布** 回编辑器

试跑工作台内也可 **使用相同参数再次运行**、**查看全部产出**、**查看任务详情**。

## 常见问题

**点运行没反应？**  
确认状态是 **已发布**。草稿用画布 **试跑**，不要指望列表 ▶ 运行。

**画布试跑成功，列表却跑不了？**  
试跑可在草稿上验证；列表运行要求已发布。

**怎么用 / API 灰掉、建不了 Key？**  
先 **发布**，再开画布 **怎么用**。

**步骤跑起来却找不到文件 / 各步目录不一致？**  
在 **设置** 里填好工作流 **工作空间**，或在本步覆盖；创建与运行时会带入各步，不要只靠「执行者自己的默认目录」。

**和自动化怎么配合？**  
先发布工作流，再到自动化里选它并设日程。需要无人确认时勾选「调度触发时自动执行」。

**`#/workflow/:id` 是不是画布？**  
不是。那是协作任务的全屏工作流视图；编排模板在 `#/apps/:id`。

## 接口与 CLI

运行：`evoflow workflow run` / platform `workflow.run` / `POST /api/apps/{id}/run`。创建与发布无完整 CLI，用 platform `workflow.*` 或 `/api/apps`。创建时可传顶层 `project_path`（工作空间）。接口示例、入参出参见 [员工 · 知识库 · 工作流 · 任务中心：接口与 CLI](../integration/api-cli-employees-knowledge-workflow-tasks.md#workflow)。
