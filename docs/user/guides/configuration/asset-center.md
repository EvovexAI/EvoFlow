# 资产中心使用指南

> 想先理解「是什么」：看 [资产中心概念说明](../../explanation/asset-center.md)。  
> **架构对齐**：用户记忆 ∥ AI 员工（BOT）独立记忆；**用户画像**可授权给员工复用；员工之间**不**共享工作记忆。主 Agent 对话沉淀归用户侧。  
> 本文只讲**在面板里怎么操作**。

## 打开入口

- 侧栏 → **资产中心**（地址 `#/assets`）  
- **这里就是以前侧栏的「记忆」**：旧入口「记忆」会转到本页的「记忆」Tab；旧「技能 / 专长」相关入口也会落到经验或管理区，不是两套功能

## 三步上手

1. 左上角确认当前实体：**我**（用户资产）或某个 **BOT**（该岗位独立记忆 / 经验 / 情感）。  
2. 用顶部 Tab 浏览（见下表）。记忆主分 **长期记忆 / 过程**；统计、导入导出、应用到…在 **管理**。  
3. 发现错字：点开文件 → 编辑 → **保存**。

### 顶部 Tab（与界面一致）

| Tab | 谁有 | 看什么 |
|-----|------|--------|
| **总览** | 我 / BOT | 当前实体摘要与快捷入口 |
| **画像** | **仅「我」** | 用户画像（员工无画像 Tab；可读授权范围内的用户画像） |
| **情感** | 我 / BOT | 心境文件（`profile/affect.md`）；用户侧≈主智能体，员工侧=该岗 |
| **记忆** | 我 / BOT | **长期记忆**（standing，每次聊天注入）+ **过程**（某次对话） |
| **经验** | 我 / BOT | 可复用做法（`craft/`；旧称「专长」多在这里） |
| **反思** | 我 / BOT | 按日反思日志 |
| **管理** | 我 / BOT | 用量 / 冷资产 / 一键整合 / 全库扫描；**导入 · 导出 · 应用到…** |

旧链接里的「统计」「导出」Tab 已并入 **管理**。

## 日常沉淀（不必先打开本页）

| 你想做的事 | 怎么做 |
|------------|--------|
| 记住一条偏好/事实 | 对话里说「记住……」，或本页快捷「记一条」 |
| 记下这次对话过程 | 对话侧栏「记录过程」（也可等系统空闲后自动写） |
| 沉淀一套做法 | 对话里说「沉淀成经验」，或侧栏「沉淀经验」 |
| 写当日反思 | 对话里说「记一下反思」，或侧栏「反思」 |

写完后再回本页核对即可。主 Agent 对话进**用户资产**；与某 BOT 对话 / 值班沉淀进**该 BOT 资产**。

## 记忆里怎么分

| 分类 | 含义 | 文件侧 |
|------|------|--------|
| **长期记忆** | 本实体整体记忆摘要；每次聊天会注入 | `memory/standing.md`（旧「条目 / facts」深链也会落到这里） |
| **过程** | 某次对话做了什么、结论是什么 | `memory/episodic/` |

偏好类可用对话标签一步写入长期记忆。经验、反思在独立 Tab，不是记忆里的第三种「要你每天维护」的正文。

## 管理：统计 · 导出 · 应用到 BOT

在 **管理** Tab：

- 看工具引用 / 回复引用、待整合草稿、冷资产  
- **一键整合** / **全库扫描**  
- **Pack 导出**：备份当前实体资产目录  
- **应用到…**：勾选范围后**显式复制**到目标 BOT / Agent——是拷贝，不是默认共享记忆  

日常跨岗复用的是**用户画像**（授权范围内），不是把 A 的工作记忆交给 B。概念见 [[explanation/asset-center|资产中心概念]]。

若要分发「员工 + 工作流 + Agent应用」整套场景，那是 **资源包**，不是资产中心 Pack：见 [[guides/configuration/resource-packs|资源包与资源市场]]。

## 和知识库怎么选

| | 资产中心 | 知识库 |
|--|----------|--------|
| 存什么 | 画像、长期记忆、过程、情感、反思、经验 | 你整理的 PDF / Office / Markdown 等文档 |
| 谁写 | 多半对话自动写；也可快捷沉淀 | 你「选择本地文件夹」同步或手写笔记 |
| 入口 | `#/assets` | `#/knowledge` |

会话拖文件只属当轮，两边都不进。
