# 资产中心使用指南

> 想先理解「是什么」：看 [资产中心概念说明](../../explanation/asset-center.md)。  
> **架构对齐**：用户记忆 ∥ AI 员工独立记忆；**用户画像**可授权给员工复用；员工之间**不**共享工作记忆。主 Agent 对话沉淀归用户侧。  
> 本文只讲**在面板里怎么操作**。

## 打开入口

- 侧栏 → **资产中心**（地址 `#/assets`）  
- **这里就是以前侧栏的「记忆」**：旧入口「记忆」会直接转到本页的「记忆」Tab，不是两个功能；旧入口「技能」会转到对应 Tab

## 三步上手

1. 左上角确认当前实体：看**用户资产**选「我」；看某岗位的独立记忆 / 经验则切到对应**员工**。  
2. 用顶部 Tab 看 **画像 / 记忆 / 经验 / 反思**（画像主要在用户侧维护；员工侧是各自记忆与经验）。「记忆」里主分 **条目 / 过程** 两类；需要时再点「记忆摘要」。  
3. 发现错字：点开文件 → 编辑 → **保存**。

## 日常沉淀（不必先打开本页）

| 你想做的事 | 怎么做 |
|------------|--------|
| 记住一条偏好/事实 | 对话里说「记住……」，或本页右上角「记一条」 |
| 记下这次对话过程 | 对话侧栏「记录过程」（也可等系统空闲后自动写） |
| 沉淀一套做法 | 对话里说「沉淀成经验」，或侧栏「沉淀经验」 |
| 写当日反思 | 对话里说「记一下反思」，或侧栏「反思」 |

写完后再回本页核对即可。

## 记忆里怎么分

- **条目**（`facts/`）：一条一条的明细——偏好、约束、短事实（如「我用 pnpm」「周报周五发」）
- **过程**（`episodic/`）：某次对话做了什么、结论是什么；空闲后系统自动写，也可侧栏「记录过程」
- **记忆摘要**（`standing.md`，次级入口）：从上面压出的总览一页，每次聊天先看，一般不用手改

正文就两类明细；记忆摘要是总览，不是第三种要你维护的记忆。

## 统计 Tab

- 看**工具引用 / 回复引用**次数、待整合草稿、冷资产  
- **一键整合**：整理当前实体未合并的草稿  
- **全库扫描**：扫所有实体的待整理草稿（与启动时扫描同类）

## 导出与应用到员工

在 **导出** Tab：

- **Pack 导出**：备份当前实体资产目录（画像/记忆/专长；即 `.evoflow-pack` 一类）  
- **应用到…**：勾选范围后**显式复制**到目标员工或 Agent——这是拷贝，不是员工间默认共享记忆

日常跨员工复用的是**用户画像**（授权范围内），不是把 A 的工作记忆交给 B。概念见 [[explanation/asset-center|资产中心概念]]。

若要分发「员工 + 工作流 + Agent应用」整套场景，那是 **资源包**，不是资产中心 Pack：见 [[guides/configuration/resource-packs|资源包与资源市场]]。
