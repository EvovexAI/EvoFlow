# EvoFlow 桌面端使用指南

> **桌面端就是你操作 EvoFlow 的"遥控器"**：
>
> - **左侧侧栏**：聊天、智能体管理、任务中心、知识库、设置…每个按钮对应一个功能模块
> - **中间聊天区**：所有对话和任务执行都在这里，输入框下方有模式选择、目标、文件上传
> - **右侧面板**：思维导图看 AI 思考过程、工作流看任务 DAG 进度
>
> 等于说：整个 EvoFlow 的能力，你都能在桌面端操作。本文就是桌面端的"地图"，告诉你每个按钮是干什么的。

---

## 什么是 EvoFlow 桌面端

EvoFlow 桌面端是 EvoFlow 的图形界面。**所有功能都在这里**：聊天、智能体、任务中心、工作流、知识库、自动化、员工等。

> 如果你用飞书/Slack 等 IM 渠道，很多操作也能在 IM 中完成，但**桌面端是功能最全的入口**。

---

## 聊天：核心交互入口

打开 EvoFlow 第一眼看到的就是聊天界面。这是你与 AI 对话的前沿。

### 对话模式

聊天输入框底部当前只提供 **Agent** 模式（早期 Ask / Plan 独立档位已下线）：完整工具集，AI 自动调用工具完成任务。复杂多步任务无需切档——AI 会自动先出方案、经你确认后再执行（Plan 流程）。详见 [Plan 模式](../chat/plan-mode.md) [[guides/chat/plan-mode|Plan 模式]]。

### 实时聊天的能力

- 流式响应：AI 逐字回复，不需要等全部生成完
- 文件上传：拖拽或点击上传按钮，支持 PDF/Word/Excel/图片/代码等
- 工具调用可视化：AI 写代码、搜网页、执行命令的过程实时展示
- 会话管理：侧栏查看历史会话，搜索、切换、删除

## 侧栏功能一览

EvoFlow 桌面端的左侧边栏是功能总入口。从上到下依次是：

### 新建对话
点击即开始新聊天。如果当前在其他页面，会跳到聊天页。

### 任务中心（`#/tasks`）
**你能做什么**：页顶两本账——**协作任务**（执行与验收，含员工间 / 上下级派发）和 **我的事项**（用户待办）。协作任务汇聚对话 Plan、员工、工作流、自动化；可按状态与**类型**（对话 / 智能体员工 / 工作流）筛选，处理同意派发与确认完成。主状态旁可能出现 **进程失联** 附注芯片。也可经 **小V** 记待办并派给员工。
**何时用**：记待办、看进度、验收交工、同意派发、查失败重试、看协作链。
**功能关系**：Plan / 员工 / 工作流是「产生任务」；任务中心是「协同中心与拍板」。概念见 [任务中心](../../explanation/task-center.md)；操作见 [任务中心指南](../tasks/task-center.md)。

### 工作流（`#/apps`）
**你能做什么**：把跑通的流程存成模板。画布用右上悬浮面板排节点；每步配 **本步能力**（技能 / 工具 / MCP / 知识库 / 模型 / 思考）与工作空间；**试跑** → **发布** → **▶ 运行** 或 **怎么用**。
**何时用**：流程已固定、只换参数反复跑（竞品分析、周报等）。
**功能关系**：侧栏文案是「工作流」。`#/apps/:id` 是画布；`#/workflow/:id` 是任务 DAG。操作见 [工作流](app-center.md)。

### 自动化（`#/cron`）
**你能做什么**：两种到点模式——**提示词**（选员工/智能体执行）或 **已发布工作流** 定时触发；管理调度与运行记录。
**何时用**：频率固定、内容稳定、不需要人盯的机械重复工作。
**功能关系**：自动化 ≠ 员工主动值班。概念见 [自动化中心](../../explanation/automation-center.md)；操作见 [自动化指南](../tasks/scheduled-tasks.md)。

### 员工（`#/proactive`）
**你能做什么**：点 **加人** 填名称与系统提示词后按岗位上班——盯工作区、建工作项、交工后按 **交工审核**「同意派发」或验收；也可用 **小V** 选员工委派。编辑岗位八段（含内置工具 / MCP / 技能）。
**何时用**：需要长期盯盘、主动值班、跨岗流水线，或临时把事派给某岗。
**功能关系**：加人会自动创建能力。工具与技能可在员工编辑里改；安装新 MCP 去设置 → 连接器。操作与字段见 [智能体员工](smart-employees.md)。

### 智能体（`#/expert`）
**你能做什么**：在「智能体中心」管理人设、模型、工具、技能与平台能力清单。列表可 **加入员工**。装 MCP 连接器在 **设置 → 数据与资源 → 连接器**。
**何时用**：要改「会什么」，或给已在岗员工补能力模板。
**功能关系**：上岗后的完整配置（含工具勾选、排班）也在「员工」编辑里。详见 [智能体管理](agent-management.md)、[工具与连接器](tools-mcp.md)。

### 资产中心（`#/assets`）
**你能做什么**：翻看与校对画像、记忆、经验、反思、专长；看用量统计；导出或应用到员工。
**何时用**：想确认 AI 记了啥、改错字、把资产拷给某个员工时。日常沉淀仍在对话里说「记住 / 沉淀经验 / 反思」。
**功能关系**：旧「记忆」「技能（专长侧）」入口会转到这里。详见 [资产中心](asset-center.md) [[guides/configuration/asset-center|资产中心]] · [概念](../../explanation/asset-center.md) [[explanation/asset-center|资产中心概念]]。

### 知识库（`#/knowledge`）
**你能做什么**：新建知识库（名称 + 向量模型），上传文件 / 文件夹或手写笔记，然后在库里用文档、问 AI、检索、Wiki、图谱。
**何时用**：同一批资料要被多次问答，或要在加人 / 编辑岗位时绑定给员工。
**功能关系**：和会话里拖文件不同，也和资产中心、聊天思维导图不同。列表可看处理中与可用度；内置库只能停用隐藏，不能删除。操作见 [知识库](knowledge-base.md)。旧 Vault 地址会转到这里。

### 设置
点击左下角齿轮图标，打开设置弹窗。常见设置项：

| Tab | 你能做什么 |
|-----|-----------|
| 模型 | 对话模型 / 生图生视频 / 向量模型 / 语音 / 套餐；设主模型；OpenAI 可 ChatGPT/Codex 账号登录 |
| 联网搜索 | 配 `web_search` 引擎与密钥，测通后选定首选引擎 |
| 连接器 | 安装 MCP（数据与资源分组） |
| 插件市场 | 商店安装能力包，齿轮进「管理已安装」启停 |
| IM 通信 | 配置飞书等渠道凭证；可查看员工/小V 飞书专属绑定关系 |
| 快捷键 | 自定义常用操作快捷键 |

侧栏 **Agent应用**（`#/extensions`）用来挂网页：远程入口、本地清单目录或 zip；多来源应用出现在同一列表，点击在面板内打开。它不在设置的插件市场里。概念见 [Agent 应用中心](../../explanation/agent-applications.md)；操作见 [模型、联网搜索、插件与 Agent 应用](settings-capabilities.md)。

> 浏览/编辑长期记忆与专长请到侧栏 **资产中心**（设置里不再单独放「记忆」Tab）。

## 小V（全局 AI 小秘书）

**小V** 是面向用户的全局智能秘书，不是某个 AI 员工。职责包括：待办管理、任务派发、进度查询、结果反馈与跨员工协调。概念见 [任务中心](../../explanation/task-center.md)。

打开 **小V** 可：

- 与小V对话：记待办、查进度、问调度建议
- 左侧联系人列表点选 **智能体员工**，右侧对该岗直接委派目标，并查看进行中任务与汇报
- 需要时再打开 **工作轨迹** 看完整工具过程

侧栏「员工」管编制与值班；任务中心管待办与协作账本；小V 负责全局协调与临时委派。

## 功能关系全景图

```
你打开 EvoFlow
│
├── 聊天界面（核心入口）
│   └── Agent 模式（默认，唯一档位）
│       ├── 可切换工作空间（读写本地仓库）
│       ├── 可切换预设角色（专业岗位）
│       ├── 可上传文件让 AI 分析（图片发送前可缩略图预览）
│       ├── 右侧信息栏：Agent / 产物 / 平台（观测开启时还有「调试」）
│       └── 多步任务自动走 Plan 流程（可调度 project-* 角色）
│
├── 侧栏功能
│   ├── 任务中心 → 用户待办 + 协作任务；小V 派发；员工协作；验收与同意派发
│   ├── 工作流 → 可复用模板（画布 / 发布 / 填参运行）
│   ├── 自动化 → 提示词 Agent ∥ 定时工作流；调度与历史
│   ├── 员工 → 加人后按点上班；也可用小V 委派
│   ├── 智能体 → 人设 / 技能 / 连接器（MCP）
│   ├── 资产中心 → 画像/记忆/经验/反思/专长
│   └── 知识库 → 上传文档、检索、问 AI
│
├── 小V（全局 AI 小秘书）→ 待办 / 派发 / 进度与结果；一员工一会话委派
│
└── 设置弹窗
    ├── 模型配置
    ├── IM 渠道（含员工飞书专属绑定）
    └── 快捷键/外观/语言
```

## 验证是否生效

1. 启动 EvoFlow 桌面端
2. 确认左下角连接状态显示已连接（默认 Gateway `http://127.0.0.1:8012`）
3. 在聊天框发一条消息，确认 AI 正常回复

## 常见问题

**Q: 桌面端无法连接后端？**
确认 Gateway / LangGraph 已运行（`make dev` 或 `make docker-start`）。检查连接设置中的 URL 是否正确。

**Q: 修改了 Agent 配置后不生效？**
部分配置修改后需要重置 Agent 或新建会话才能生效。

**Q: 自动化不执行？**
确认自动化引擎已启动。Gateway 默认运行调度循环，可通过 `EVOFLOW_AUTOMATION_SCHEDULER=0` 关闭。

**Q: 如何备份 EvoFlow 数据？**
EvoFlow 数据存储在 `~/.evoflow/` 目录下。备份该目录即可保留所有任务配置和本地设置。

**Q: `evoflow` CLI 命令或 venv python 启动极慢甚至卡死？**
先跑 `evoflow doctor` 自检，重点看两处：

1. **python 残留进程**——历史崩溃/被杀的 python 进程堆积会让 venv python 启动极慢甚至挂起（Windows 任务管理器结束不需要的 `python.exe` 后重试）；
2. **SQLite sidecar 锁**——`-wal`/`-shm` 被残留进程占用时，DB 操作会失败并给出提示。

CLI 长时间无响应时的替代通道是 gateway HTTP API（地址见 profile 目录下 `backend-runtime.json` 的 `baseUrl`）。AI 侧建议优先走 gateway API 而不是反复重试 CLI。

# 附录：菜单与面板速查表

> 以下内容面向**开发者**和**高级用户**，日常使用可跳过。

EvoFlow 功能入口分三层：**聊天壳侧栏**（主 UI）、**设置弹窗**（模型 / IM / 外观等）、**下钻与直达路由**（详情页、旧 URL）。

## 侧栏路由

| 路由 | 说明 |
|------|------|
| `/tasks` | 任务驾驶舱，含 `#/task/:id` |
| `/apps` | 工作流列表，含 `#/apps/:id` 画布 / run / history |
| `/cron` | 自动化 |
| `/proactive` | 值班岗，含 `#/proactive/*` |
| `/expert` | 智能体（技能 / 连接器已迁入设置 → 数据与资源） |
| `/assets` | 资产中心（画像/记忆/经验/反思/专长） |
| `/knowledge` | 知识库（自有文档库） |
| `/knowledge/owned/:id` | 某个知识库：文档 / 问 AI / 检索 / Wiki / 图谱 |
| `/memory` | 旧入口 → 重定向 `#/assets?tab=memory` |
| `/skills` | 旧入口 → 重定向资产中心专长或智能体技能 Tab |

## 设置弹窗常见 Tab

| Tab | 全屏等价路由 |
|-----|-------------|
| 模型 | `#/models` |
| IM 通信 | `#/channels` |
| 快捷键/外观/关于 | `#/about` 等 |

> 长期记忆与专长请用侧栏 **`#/assets`**，不再依赖设置里的「记忆」Tab。

## 下钻路由

| 路由 | 说明 |
|------|------|
| `/task/:id` | 任务详情 |
| `/workflow/:id` | 协作任务全屏 DAG（不是工作流画布） |
| `/apps/:id` / `/run` / `/history` | 工作流画布 / 填参运行 / 运行历史 |
| `/proactive/:code` / `/work/:taskId` | 员工日志与工作项 |
| `/knowledge/:id` | 知识库详情 |
| `/observability` | 可观测面板 |
| `/agents/team/:code` | 项目团队详情 |

> 菜单布局以实际打开的 EvoFlow 桌面端为准；版本升级可能新增或调整菜单项。
