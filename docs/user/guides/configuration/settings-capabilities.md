# 模型、联网搜索、插件与 Agent 应用

这四样经常被叫成「插件」或「扩展」，入口并不相同。配错地方，聊天、知识库或网页应用都不会生效。

| 你要配的 | 去哪 | 配完谁在用 |
|----------|------|------------|
| **对话 / 向量 / 语音模型** | 左下角齿轮 → **模型**（`#/settings?tab=models`） | 聊天、员工、工作流、知识库嵌入 |
| **联网搜索**（`web_search`） | 齿轮 → **联网搜索**（`#/settings?tab=search`） | Agent 的网页搜索工具 |
| **插件市场** | 齿轮 → 数据与资源 → **插件市场**（`#/settings?tab=plugin-management`） | 能力包（技能、命令等），进商店安装后在「管理已安装」里启停 |
| **Agent 应用** | 侧栏 **Agent应用**（`#/extensions`） | 挂进面板的网页：远程网址，或带清单的本地目录 / zip |

连接器（MCP）不在设置的插件市场里，在侧栏 **智能体 → 连接器**。见 [工具与连接器](tools-mcp.md)。

## 模型配置

打开 **设置 → 模型**。页内四个 Tab：

**对话模型 · 向量模型 · 语音 · 套餐**

### 对话模型

1. 左侧选已有服务商，或 **+ 添加服务商**（预设厂商，或自定义 OpenAI 兼容地址）。
2. 填 **连接与鉴权**：接口地址、API Key。本机服务可不填密钥。密钥保存在本机，编辑时留空表示不改。
3. 点 **+ 添加模型**，勾选或填写模型 ID。
4. 把要用的设为 **主模型**。顶栏会显示当前主模型；未指定模型的新对话和智能体用它。
5. 某个智能体要换脑子：到智能体编辑的 **默认模型**，可选「跟随全局默认」或指定模型。

火山等套餐对话模型由 **套餐** Tab 写入。改 Key、补齐模型到「套餐」，不要在对话模型里手改那一套。

### 向量模型

知识库、代码索引从这里选嵌入模型。

- 已绑 Agent Plan 全家桶：到 **套餐** 点「按套餐目录补齐」，向量会出现在本 Tab。
- 否则点 **+ 添加向量模型**。本地模型第一次检测可能要下载权重。
- 可把某一条设为知识库默认向量模型。没有向量模型时，知识库 **创建** 按钮不可用。

### 套餐

绑定 Agent Plan 后，对话模型、向量模型和联网搜索权益会写到对应页。状态里能看到已补齐的向量模型数量。

## 联网搜索

打开 **设置 → 联网搜索**。

这里配的是 Agent 工具 `web_search`。它和「模型」页里厂商自己的原生联网不是同一条路：模型 Key 通了，不等于网页搜索已通。

页上会显示 **当前生效** 引擎，以及来源：

| 来源文案 | 含义 |
|----------|------|
| **设置表（你选的）** | 你在首选引擎里指定的 |
| **自动探测** | 按已填密钥自动挑 |
| **Agent Plan 默认（豆包）** | 套餐赠送的豆包搜索 |
| **未就绪** | 还没有可用引擎 |

**首选引擎（选完即保存）**：自动探测、豆包搜索、博查搜索、Tavily、Brave Search、SearXNG、Firecrawl、InfoQuest、DDGS（兜底）。有套餐时豆包会标成「豆包搜索（Agent Plan 默认）」。

**引擎与密钥**：每张卡片填 Key 或地址（失焦即保存）。DDGS 写明无需密钥，依赖本机 `ddgs`。卡片上可单测；底部 **测通全部** 用默认测试词（可改「测试关键词」，默认「今天 AI 新闻」）。

套餐已识别但还差 Key 时，横幅会提示去填 **联网搜索 Key**。建议先测通豆包或 Tavily，再把首选引擎指过去。

## 插件市场

打开 **设置 → 插件市场**（左栏分组「数据与资源」）。

进入后默认是商店浏览：搜索、已安装条、刷新、市场源。已安装图标点进详情；齿轮进 **管理已安装**，在那里启用或停用。

和另外三样的差别：

- 不是 MCP 连接器（连接器在智能体页）。
- 不是 Agent 应用（Agent 应用在侧栏，用来嵌网页）。
- 安装后要在管理视图确认已启用，聊天里才会用到它带进来的技能或命令。

## Agent 应用（扩展网页）

侧栏 **Agent应用**。页头说明：把网页应用挂进 EvoFlow，可以是线上网址，也可以是带清单的本地目录 / zip（源码工程需写明启动方式）。

这是「扩展应用」的配置入口。装好后点卡片在面板里打开，不必另开浏览器标签。

### 三种装法

| 按钮 | 适合 | 你要准备的 |
|------|------|------------|
| **添加远程入口** | 已经有网址 | Agent应用 ID、名称、入口 URL，再点 **安装** |
| **安装本地Agent应用** | 本机文件夹 | 文件夹里要有 `evoflow.extension.json` |
| **导入 zip** | 别人发来的包 | 解压后最外层能看到这份清单，不要多套一层目录 |

远程表单字段就是这三项：**Agent应用 ID**（如 `my-ops`）、**名称**、**入口 URL**。

本地清单最小字段：`schema`、`id`、`name`、`version`，以及怎么打开（远程 URL，或本地服务的启动方式）。开发者逐步说明见 [把自有项目装成 Agent 应用](install-own-project-as-extension.md)。

### 装好之后

列表可 **搜索应用…**。卡片角标：

| 状态 | 含义 |
|------|------|
| **无本地服务** | 远程页，点开即可 |
| **已停止** / **启动中** / **运行中** / **失败** | 本机服务 |
| **外部服务** / **需自行启动** | 服务不由面板拉起 |
| **检测中** | 正在探活 |
| **已禁用** | 菜单里关掉了，点不开 |

卡片 ⋯ 菜单：

| 项 | 作用 |
|----|------|
| **启用应用** / **禁用应用** | 是否允许打开 |
| **启动服务** / **停止服务** | 清单里声明了本机进程时用 |
| **查看日志** | 启动失败时先看这里 |
| **打开目录** | 桌面端打开安装目录 |
| **卸载** | 从面板移除 |

申请了任务派发等权限时，启用前会再确认一次。页面要通过 JS Bridge 调智能体、记忆或知识库时，必须在清单里声明权限。

页头 **使用指南** 会打开本页帮助；**刷新** 重载列表。

### 建议顺序

1. 有现成网址：只填远程入口，先确认卡片能打开。
2. 自有前端：写好 `evoflow.extension.json`，用 **安装本地Agent应用** 选到清单所在的那一层文件夹。
3. 需要本机起服务：装完看角标。不是「运行中」就点 **启动服务**，失败则 **查看日志**。
4. 不用了先 **禁用应用**，确认无入口再 **卸载**。
