# 知识库

> **知识库 vs 记忆，别搞混**：**记忆**（在[资产中心](asset-center.md)）存的是关于你的小事实，AI 在对话里自动记；**知识库**存的是你主动上传的资料文档（PDF、Word、Markdown 等），供长期反复检索。
>
> **直接拖进聊天窗口的附件只在当轮对话有效，不会进知识库**；要长期保存、反复查阅的资料，请在本页上传。

侧栏 **知识库**（`#/knowledge`，库详情 `#/knowledge/owned/<id>`）存放会被反复查阅的资料。页头说明是：把会被反复使用的资料放进来，让员工回答时有据可查。上传后先验证检索，再绑定到员工。

会话里拖进去的附件只属于这一轮，见 [文件上传](../chat/file-upload.md)。画像、记忆、经验在 [资产中心](asset-center.md)。聊天右侧的「思维导图」是任务思路图，不是这个知识库。

---

## 5 分钟建好第一库

1. 侧栏打开 **知识库**，点 **新建知识库**。
2. 填 **名称**，并选择 **向量模型**。目录来自「设置 → 模型 → 向量模型」，可点对话框里的 **去管理**。没有向量模型时 **创建** 不可用。
3. 点进该库。右上角 **上传文件**、**上传文件夹**，或 **手写笔记**。
4. 文档状态会显示 **排队中**、**处理中**、**已就绪** 或 **失败**。向量还没建好时，仍可做 **关键词** 检索。
5. 顶栏切到 **检索** 或 **问 AI**，用一句话核对命中。
6. 要让岗位上班时引用：侧栏 **员工** → 加人或编辑岗位 → **绑定知识库**。

## 列表页

页头是标题「知识库」和 **新建知识库**。搜索框搜名称和描述（快捷键 Ctrl/⌘+K）。

四张统计卡：

| 卡片 | 含义 |
|------|------|
| **知识库** | 当前列表里的库数量 |
| **文档总量** | 全部文档，附带已可检索篇数 |
| **处理中** | 排队或正在索引；有失败时会标失败数 |
| **可用度** | 已可检索文档占比 |

每行显示文档数、嵌入方式（本地嵌入 / 云端嵌入或模型名）、更新日期。状态文案包括「等待上传资料」「资料正在建立索引」「可以开始搜索或问 AI」「需要处理失败文档」。内置库有 **内置** 标；隐藏后有 **已停用** 标。

行尾 ⋯ 菜单：

| 菜单 | 作用 |
|------|------|
| **打开** | 进入该库 |
| **重命名** | 改名称。内置库没有这项 |
| **设置** | 打开库设置 |
| **打开所在目录** | 在文件管理器里打开库目录（桌面端） |
| **删除** | 删除库、文档和索引。内置库不能删 |
| **停用（隐藏）** / **恢复显示** | 只出现在内置库上。停用后默认列表不显示，内容仍随版本同步 |

列表上方可切 **显示已停用** / **隐藏已停用**。

## 库详情

顶栏左侧 **返回** 回列表。视图是五个按钮：

**文档 · 问 AI · 检索 · Wiki · 图谱**

旁边可开 **目录**（文件夹树）和 **概览**（当前文档的摘要与相关文档）。

右上角操作：

| 按钮 | 作用 |
|------|------|
| **库设置** | 名称、描述、向量模型、重建索引 |
| **上传文件** | 一次可选多个。格式见下表 |
| **上传文件夹** | 整夹导入，并记住同步源 |
| **打开位置** | 有同步源时打开源目录，否则打开库目录 |
| **再同步** | 对已记住的源目录拉增量。会先问是否清理源里已删除的文档。还没上传过文件夹时按钮不可用 |
| **手写笔记** | 直接写一篇 Markdown |

目录里可以 **新建文件夹**，拖动文档或文件夹调整位置。删文件夹时可选只把文档上移，或连文档一起删。

文档状态：**已就绪**、**排队中**、**处理中**、**失败**。失败行可点 **重试**。索引进度弹窗标题是「索引进行中」或「索引状态」，失败时可 **重新解析整个 KB**。

若库里已有文档但还没向量化，顶上会提示「尚未向量化」或「向量索引未完成」，点 **打开库设置** 去建索引。

### 支持的文件

上传选择器接受：`.md` / `.markdown` / `.mdx`、`.txt`、`.pdf`、`.doc` / `.docx`、`.ppt` / `.pptx`、`.xls` / `.xlsx`、`.csv`、`.json`、`.html` / `.htm`、`.yaml` / `.yml`、`.py`。

文件存在本机知识库目录。选云端向量模型时，嵌入请求发给该模型服务，正文仍留在本机。

### 问 AI 与检索

**问 AI** 用自然语言在本库检索并归纳，回答带可跳转引用。提示语包括「总结当前文档要点」「这份知识库讲了什么？」。选中某篇文档时，范围是「当前文档」，否则是「整个知识库」。

**检索** 查分块。模式：

| 模式 | 作用 |
|------|------|
| **混合** | 关键词 + 向量（默认） |
| **关键词** | 不依赖向量，模型未就绪时仍可用 |
| **语义** | 按向量相似度。索引未就绪时会降级为关键词，并提示「语义索引未就绪」 |

输入框占位是「检索知识库分块…」，回车或点 **检索**。有标签时可按标签过滤。点结果打开对应文档。

### Wiki 与图谱

**Wiki**：点 **生成 / 重建 Wiki**，从文档摘要排队生成百科页。点左侧页面可改正文，再 **保存当前页**。页上会标出链、入链。

**图谱** 三种：

| 视图 | 内容 |
|------|------|
| **Wiki 链接图** | Wiki 页之间的链接。点节点回到 Wiki 页 |
| **文档链接** | Markdown 里的 `[[笔记名]]`。点节点打开文档 |
| **实体图 G2** | 从文档块抽出的实体关系。点 **抽取实体** 排队生成 |

三种都可以 **刷新**。空状态会提示先生成 Wiki、先写 `[[笔记名]]`，或先抽取实体。

### 库设置

标题是「库设置 · 库名」。可改 **名称**（内置库不可改）和 **描述**。

当前向量会写成「本地」或「云端」，带模型名和维度。维度未就绪时说明尚未向量化，关键词检索仍可用。

- 自建库：直接改向量模型。换模型保存时会清空现有向量并整库重建。
- 内置库：先勾选「切换为自定义向量模型（将清空现有向量并整库重建）」，才能改模型。可 **停用（从列表中隐藏）** 或 **恢复显示此内置库**。内置库不可删除。

索引按钮：还没有维度时是 **按当前模型建立索引**；已经向量化过则是 **按当前模型重建（不换模型）**。模型列表旁有 **管理向量模型**，跳到设置。

## 让智能体或员工用上知识库

| 谁 | 在哪绑 | 效果 |
|----|--------|------|
| **员工** | 加人 / 编辑岗位 → **绑定知识库**（可多选） | 值班提示带上这些库。编辑岗位的 **知识库检索配置** 决定调用前自动注入，还是只开放检索工具 |
| **智能体** | 智能体编辑里的知识库能力 | 聊天 `@` 时按它勾选的库检索 |

员工侧默认 **自动注入**：调用模型前检索，把相关片段放进上下文。也可改成仅工具、两者并行，或关闭。条数、相似度、token 上限、混合检索权重、失败时继续还是中止，都在同一块配置里。系统提示词注入里的 **知识库检索** 控制要不要把结果写进该员工的系统提示。

## 和旧入口的关系

- 旧「上传文档 RAG」和「连接 Obsidian Vault」（`#/knowledge/vaults`）不再单独开页。这些地址会进现在的知识库。
- 已有 Markdown 目录：用 **上传文件夹**，之后用 **再同步**。
- 面板和检索走 `/api/knowledge/owned`。旧 dataset API（`/api/knowledge`）对不上，往旧接口塞文件，现在的「问 AI」和员工绑定库都看不到。
