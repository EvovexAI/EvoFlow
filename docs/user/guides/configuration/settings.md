# 面板设置

左下角齿轮打开设置。模型、联网搜索、插件市场、连接器、Agent 应用的逐步操作见 [模型、联网搜索、插件与 Agent 应用](settings-capabilities.md)。侧栏 **Agent应用** 用来挂网页（统一列表、面板内打开），不在这个弹窗里；定位见 [Agent 应用中心概念](../../explanation/agent-applications.md)。

---

## 弹窗结构

设置采用「左侧分组导航 + 右侧面板」：

| 分组 | 常见项（以界面为准） |
|------|----------------------|
| **基础设置** | 外观、工具审批、数据目录、环境变量、快捷键等 |
| **能力与集成** | **模型**、联网搜索、IM 通信、安全、API / SSO / 用户与用量等 |
| **数据与资源** | 资源中心、技能、**连接器（MCP）**、插件市场等 |
| **关于** | 版本、检查更新、许可证 |

每个 Tab 按需加载；URL 带 hash（`#/settings?tab=xxx`），可外链到具体 Tab。模型也可用 `#/models` 直达。

详细字段以各 Tab 页内说明与 [settings-capabilities](settings-capabilities.md) 为准；下文只列高频心智。

---

## 一、外观与安全（基础）

### 主题与外观

| 选项 | 作用 |
|------|------|
| **主题模式** | 日间 / 夜间 / 跟随系统 |
| **字体大小** | 小 / 中 / 大 / 超大 |
| **界面语言** | 中文 / 英文（AI 回复语言默认跟随） |

### 工具审批策略

| 策略 | 作用 |
|------|------|
| **默认询问** | 高风险工具先弹审批条（日常推荐） |
| **自动批准** | 不询问 |
| **仅会话内授权** | 同会话首次问过、后续同名工具自动通过 |

也可对单个工具单独覆盖。

### 数据目录

| 选项 | 作用 |
|------|------|
| **打开数据目录** | 打开本机数据根（会话、记忆、配置等） |
| **清理缓存** | 清临时缓存 |

---

## 二、模型

完整步骤见 [配置模型教程](../../tutorials/configure-models.md) 与 [settings-capabilities · 模型](settings-capabilities.md#模型配置)。

页内五个 Tab：**对话模型 · 生图生视频 · 向量模型 · 语音 · 套餐**。

- 第一次：在 **对话模型** 添加服务商 → 填 Key（或 OpenAI 的 **ChatGPT / Codex 账号登录**）→ 添加模型 → 设 **主模型**。
- 知识库缺嵌入：到 **向量模型**（或 **套餐** 补齐）。
- 套餐写入的火山模型改 Key / 补齐：去 **套餐**，不要在对话列表里手改。

顶栏显示当前主模型；未单独指定的新对话和智能体用它。

---

## 三、环境变量

集中管理 API Key 与系统变量，AI 跑命令、脚本、子代理、MCP 时自动引用。

| 操作 | 作用 |
|------|------|
| **添加变量** | `KEY=VALUE`，如 `OPENAI_API_KEY=sk-xxx` |
| **掩码显示** | 敏感值显示为 `sk-•••••` |
| **编辑 / 删除** | 修改或移除 |

写入后一般不需要重启。

---

## 四、IM 通信

配置飞书、Slack、Telegram 等渠道凭证，让自动化推送、员工审批通知能推到聊天工具。

| 选项 | 作用 |
|------|------|
| **渠道类型** | 选飞书 / Slack / Telegram / Discord 等 |
| **凭证配置** | Bot Token、App ID、Secret 等 |
| **连接状态** | 是否配置成功 |

步骤见 [IM 消息渠道配置](../integration/im-channels.md)。

---

## 五、记忆与资产（已迁出设置）

> **设置里的「记忆」Tab 已退役。** 请到侧栏 **资产中心**（`#/assets`）浏览与校对。

| 你想做的事 | 去哪 |
|------------|------|
| 翻看 / 改偏好与事实 | 资产中心 → 记忆 |
| 沉淀经验 / 专长 | 对话里说一句，或资产中心 → 经验 / 专长 |
| 删掉记错的内容 | 资产中心打开对应文件改正或删除 |

详见 [资产中心](asset-center.md) · [记忆管理](memory-management.md)。

---

## 六、快捷键

把常用操作绑成键盘快捷键（发送、新会话、停止生成、命令面板等）。与系统快捷键冲突时会有告警。一键可恢复默认。

版本号、检查更新、许可证、致谢。

## 附：资源中心与连接器

在左侧「数据与资源」打开：

| 入口 | 作用 |
|------|------|
| **资源中心** | 导出 / 安装员工、工作流、技能等资源包；见 [资源包与资源市场](resource-packs.md) |
| **连接器** | 安装 MCP；装好后在员工 / 智能体编辑里勾选；见 [工具与连接器](tools-mcp.md) |
| **插件市场** | 商店能力包；与连接器、Agent 应用都不是一回事 |

## 多实例支持

EvoFlow 支持同时管理**本机**、**Docker**、**远程**三类实例。

| 特性 | 说明 |
|------|------|
| **设置独立存储** | 本机与远程互不冲突 |
| **实例切换** | 左侧菜单顶部切换器 |
| **远程实例添加** | 见 [EvoFlow 桌面端使用指南](evopanel-guide.md) |
