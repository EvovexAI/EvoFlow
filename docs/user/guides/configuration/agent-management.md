# 智能体管理

> **新手可跳过本页**：普通用户全程不打开也能用好 EvoFlow——默认主智能体已经能聊天、调研、读写文件。只有想固化专属人设 / 工具组合（比如"一个专门写前端的智能体"）时，才需要来这里新建。

> **先分清智能体和员工**
>
> 1. **区别**：智能体管「会什么」（人设、模型、工具、技能、连接器 MCP）。员工管「何时主动干」（岗位、职责、部门与上级、上班时间、转交审批、工作空间、绑定知识库、预算）。聊天里 @ 智能体不会自动值班。
> 2. **员工能配什么**：加人时填岗位名称、职责、部门、上级、知识库；更多设置里有能力来源、工作空间、关注子路径、工作模型、转交审批（全自动 / 平衡型 / 谨慎型）、自动上班。编辑岗位还可配工作方式、模型思考、系统提示词注入、知识库检索和预算。工具、技能、连接器到「智能体」页改。
> 3. **怎么操作**：侧栏「员工」→「加人」→ 填岗位和至少一条职责 →「确认加人」→ 打开页头「自动上班」，或点「现在开始工作」，急活用小V 派活。交工后到任务中心确认完成或要求修改。

侧栏 **智能体**（`#/expert`）页头是「**智能体中心**」：配置可复用能力包；日常加人、排班、工作流指派请到「员工」。

三个顶栏 Tab：

| Tab | 作用 | 主按钮 |
|-----|------|--------|
| **智能体** | 能力名片列表、新建、编辑 | **新建智能体** |
| **技能** | 安装与管理技能 | **导入本地技能** |
| **连接器** | MCP 插件（见 [工具与连接器](tools-mcp.md)） | **添加连接器** |

每个智能体是一份「会什么」：头像、名称、标识、系统提示词、人格 SOUL、默认模型、内置工具、MCP 服务、技能。它不会自己按点上班。要值班，到 [员工](smart-employees.md) **加人**；也可以在卡片上点 **加入员工**，或在加人时把这里已配好的智能体选作「能力来源」。

逐步创建：[创建智能体教程](../../tutorials/create-agent.md)。

## 5 分钟新建并试用

1. 侧栏打开 **智能体**，确认顶栏在 **智能体** Tab。
2. 点 **新建智能体**。
3. **基本信息**：填 **角色标识**（创建后不可改）和 **中文名称**；可选描述、默认模型、标签、系统提示词。
4. 左侧切到 **内置工具 / MCP 服务 / 技能模块 / 人格 SOUL**，按需勾选或填写。
5. 点 **创建智能体**。
6. 聊天里 `@` 它试一句；要值班再点卡片 **加入员工**，或去员工页加人。

也可以在聊天里直接说「帮我创建一个写周报的智能体」，让主助手代建后再回本页精修。

## 列表：我的 / 已部署 / 模板市场

智能体 Tab 下还有三个视图：

| 视图 | 内容 |
|------|------|
| **我的智能体** | 主助手、自建、SkillHub 安装等 |
| **已部署** | 已挂到员工、工作流或自动化的 |
| **模板市场** | 系统模板；可 **从 SkillHub 安装** 专家包到「我的智能体」 |

### 筛选与排序（我的 / 已部署）

- 搜索：「搜索智能体」
- **状态**：可用 / 运行中 / 离线 / 配置异常
- **用途**：代码、项目管理、媒体、视频、动画、文档、营销、社媒、内容等
- **来源**：系统 / 自定义 / SkillHub
- **部署**：未部署 / 员工 / 工作流 / 自动化
- **更多筛选**：标签芯片；窄屏时部分筛选项也会收进这里
- **排序**：最近使用 / 名称 / 标识

当前生效的条件会显示为「当前筛选」芯片，可逐个关掉或 **清除全部**。

模板市场另有「搜索模板」、分类与排序；横幅说明可从 SkillHub 安装。

### 卡片主按钮与 ⋯ 菜单

主按钮随状态变化，常见有：

| 按钮 | 何时出现 |
|------|----------|
| **修复配置** | 配置异常 |
| **启动** | 离线（如外部运行时） |
| **开始对话** | 默认主智能体 |
| **打开值班台** | 已部署为员工 |
| **打开工作流** / **打开自动化** | 已被工作流或自动化引用 |
| **加入员工** | 尚未入职 |

⋯ 菜单通常有：**详情**、**编辑**、**复制**、**导出**、**删除**（主智能体等默认项不可删）；部分角色还有 **扫码绑定 IM**。

点卡片可开侧栏摘要。详情弹窗左侧分区与编辑器相同（只读），脚上可 **编辑此角色**，以及 **加入员工编制** 或 **查看值班台**。

## 新建 / 编辑字段

弹窗标题是 **新建智能体** 或 **编辑智能体**。左侧五个分区：

**基本信息 · 内置工具 · MCP 服务 · 技能模块 · 人格 SOUL**

### 基本信息

| 字段 | 说明 |
|------|------|
| **角色头像** | 预设或上传 |
| **角色标识** | 新建必填；字母、数字、连字符。创建后只读，作 API / 岗位唯一编码 |
| **中文名称** | 列表与选择器显示名 |
| **角色描述** | 一句话定位 |
| **默认模型** | 可选具体模型，或「跟随全局默认」。新对话与「跟随智能体」的会话用这里；单次聊天临时换模型不会改这项 |
| **标签** | 便于筛选（主智能体编辑时可能不提供） |
| **系统提示词** | 硬规则：流程、格式、禁止事项 |

### 内置工具 / MCP 服务 / 技能模块

各有搜索框、计数、**全选** / **清空**。未勾选的能力，该智能体对话时看不到。

MCP 要先在顶栏 **连接器** 里添加并启用，这里才会出现可勾选项。详见 [工具与连接器](tools-mcp.md)。

### 人格 SOUL

软性人格与行为边界，和系统提示词分开维护。空则表示尚未配置人格。

保存：新建点 **创建智能体**；编辑点 **保存更改**。保存后热重载，一般不必重启。

### 特殊角色

| 类型 | 面板行为 |
|------|----------|
| **主智能体** | 可开始对话；不可删除 |
| **外部 CLI** | 可改名称、描述、系统提示词与 SOUL；工具 / MCP / 技能由本机运行时提供，面板不能勾选 |
| **系统前台（小V 等）** | 能力面固定，不在此挂 MCP |
| **子智能体 / ACP** | 详情里会有对应徽章 |

## 在聊天里怎么用

| 入口 | 操作 |
|------|------|
| **@** | 输入框 `@` 选智能体 |
| **切换默认** | 聊天顶栏 / 联系人里切换当前角色 |
| **自然语言** | 对主助手说「切到某某」 |
| **加入员工后** | 自动上班、派发、小V 委派——能力仍以本页配置为准 |

改完人设或工具后，请**新开对话**再 `@`，旧线程可能还记着旧口吻和旧工具列表。

## 和员工的关系

| | 智能体（本页） | 员工 |
|--|----------------|------|
| 侧栏 | 智能体（`#/expert`） | 员工（`#/proactive`） |
| 本质 | 能力包 | 岗位合同（职责、上班、审批、知识库） |
| 触发 | 聊天 `@`、切换角色 | 自动上班、现在开始工作、派发 |

要按点上班：卡片 **加入员工**，或员工页 **加人**（会自动创建能力）。只有想沿用这里已配好的智能体时，才在加人「更多设置 → 能力来源」里选。步骤见 [加人教程](../../tutorials/hire-first-smart-employee.md)。

删除智能体前，确认没有员工岗、工作流或自动化仍引用它。删岗位不会删底层智能体；删智能体会去掉这份能力配置。
