# 自动化操作指南

> **新手可跳过**：这是进阶功能。等你需要「每天 9 点自动出日报」这类到点重复执行的任务时再来；日常一次性的事，用聊天或先计划 Plan 就够。

> **产品定位（自动化中心）**：两种到点模式——**自动化任务**（提示词 + 所选 Agent / 在编员工）与 **定时自动化**（已发布工作流按计划触发）。  
> 概念、与员工值班的边界、全景图四块重点见 [自动化中心概念](../../explanation/automation-center.md)。  
> **不是** AI 员工每隔几小时主动巡检；也不含「业务参数传递」能力位。

> **比如你想让 EvoFlow 每天自动做这些事**：
>
> - **提示词**：每天上午检查 AI 行业动态，总结五条新闻（选一个员工或智能体执行）
> - **工作流**：每天早上 9 点触发已发布的「商品数据分析」工作流
> - **每周五下午 5 点**：汇总本周进展（提示词或工作流二选一）
>
> 自动化与「任务中心」互补：自动化管规则与到点触发；任务中心是待办、协作派发与看板。

侧栏入口：**自动化**（`#/cron`）。

## 一、何时用（别和任务中心 / 员工值班混）

| 你想做的事 | 推荐路径 |
|----------|---------|
| **到点**用提示词让 Agent / 员工跑一轮 | **自动化 · 提示词**（本文） |
| **到点**跑已编排好的工作流 | **自动化 · 已发布工作流**（本文） |
| 复杂多角色、要看板观测的一次性工程 | [任务中心](task-center.md) [[guides/tasks/task-center|任务中心]] |
| 流程已固定、人手点「填参再跑」 | [工作流](../configuration/app-center.md) [[guides/configuration/app-center|工作流]]（旧名「应用中心」） |
| 岗位按点上班、主动巡检、审批与工作汇报 | [智能体员工](../configuration/smart-employees.md) [[guides/configuration/smart-employees|智能体员工]]（**不属于**自动化中心） |
| 单会话边聊边拆步 | [Plan 模式](../chat/plan-mode.md) [[guides/chat/plan-mode|先计划 Plan]]（聊天输入框底部的模式药丸） |
| 开放长任务、聊天里自驱多轮 | [目标 Agent](../chat/goal-agent.md) [[guides/chat/goal-agent|目标 Agent]]（**实时聊天 Goal 模式**，不是任务中心，也不是本页） |

自动化特征：**频率固定、内容相对稳定、不需要人盯**。

## 二、页面布局

| 区域 | 文案 / 内容 |
|------|-------------|
| 标题 | **自动化** |
| 副标题 | 自动化调度管理 — 创建、监控和管理周期性 / 一次性任务 |
| 主按钮 | **＋ 新建任务** |
| 状态栏 | **调度器运行中 / 未启动 / 异常** · **活跃** · **已暂停** · **总计** |
| 空态 | 暂无自动化 · 点击「新建任务」创建… |

### 任务卡片

- 名称、执行频率摘要、任务描述（前几行）
- 徽标：**运行中** / **已暂停** / **一次性**
- 开启推送时显示渠道标签（如「飞书默认群」），不是手填 chat_id
- 操作：**▶ 运行** · **⏸⏸ 暂停** · **↻ 恢复** · **📋 历史** · **✎ 编辑** · **✕ 删除**

> 列表卡片一般**不显示**「下次执行时间」；预览在创建/编辑弹窗的调度摘要里。

## 三、创建任务（界面）

点 **＋ 新建任务**。先选 **执行内容** 类型，再配调度与高级项。

### 执行内容：二选一

| 类型 | 你要准备的 | 到点发生什么 |
|------|------------|--------------|
| **提示词**（自动化任务） | 任务描述 Prompt；在高级设置里选 **执行员工 / 智能体**（有在编员工时优先员工名册）与模型等 | Agent 理解提示词并执行，不要求事先有工作流 |
| **已发布工作流**（定时自动化） | 下拉选已发布工作流 | 按预设流程跑（经任务中心 DAG）；**不是**每次重新自主规划 |

工作流须先在侧栏「工作流」**发布**；列表为空时面板会提示先去发布。定时工作流**不**单独提供「业务参数传递」产品能力位。

### 基本信息

| 字段 | 必填 | 说明 |
|------|------|------|
| **任务名称** | 是 | 如：每日健康检查 |
| **任务描述 (Prompt)** | 提示词模式必填 | 每次发给执行者的指令，写清做什么、产出什么 |
| **工作流** | 工作流模式必填 | 选择已发布工作流 |

Prompt 宜具体，少寒暄。例：「汇总昨日本仓库 PR 与 Issue 变化，生成 Markdown 日报」。

### 调度配置

| 模式 Tab | 说明 |
|----------|------|
| **每小时** | 每小时第 MM 分触发 |
| **每天** | 选时刻（含上下午） |
| **每周** | 星期 chips + 时刻 |
| **一次性** | 日期时间；快捷：**现在** / **+1小时** / **明早 9:00** / **今晚 22:00** |
| **自定义 Cron** | 五字段：`分 时 日 月 星期` |

底部有调度摘要预览（如「每天 09:00 执行」）。

### 高级设置

| 选项 | 适用 | 说明 |
|------|------|------|
| **执行员工 / 智能体** | 提示词模式 | 优先在编员工；无员工时选智能体 |
| **工作目录** | 提示词模式 | 可「选择文件夹」；空则用 Gateway 默认 |
| **记忆 · 启用** | 提示词模式 | 见下方「记忆 vs 线程」 |
| **任务超时时间（分钟）** | 两种模式 | 默认 **30**，常见范围 1–1440 |
| **完成后推送结果** | 两种模式 | 打开后选 **推送渠道**（需先配好消息渠道） |

无可用渠道时提示：**暂无可用的推送渠道**。

按钮：**取消** · **创建任务**（编辑时为 **保存修改**）。

### 对话创建（可选）

在聊天里说明「帮我建一个每天 9 点…的自动化」，确认后创建，与 GUI 等价。

## 四、运行、暂停与历史

| 操作 | 说明 |
|------|------|
| **▶ 运行** | 立即手动触发一次（不改调度） |
| **暂停 / 恢复** | 控制是否参与到点调度 |
| **历史** | 侧栏/面板：**执行历史 — {任务名}** |
| **编辑 / 删除** | 改配置或移除（删除需确认） |

历史行常见：触发方式、耗时、thread 摘要；有会话信息时可 **在聊天中打开**。

执行记录在 Gateway 数据（SQLite）中，不是旧版 `*_history.jsonl` 为主路径。

## 五、推送结果

1. 先在设置 / 消息渠道配好飞书等（见 [飞书集成](../integration/feishu-integration.md) [[guides/integration/feishu-integration|飞书集成]]、[IM 渠道](../integration/im-channels.md) [[guides/integration/im-channels|IM 渠道]]）
2. 编辑自动化 → **完成后推送结果** → 选 **推送渠道**
3. 跑一次（或等下次到点）验证渠道能收到

主路径是渠道单选，不是在表单里手填 chat_id（高级/遗留配置见调度参考）。

## 六、记忆 vs 线程

| 概念 | 面板 | 含义 |
|------|------|------|
| **记忆 · 启用** | 有开关 | `memory_enabled`：是否带记忆能力 |
| **LangGraph 线程 sticky/fresh** | **无 UI** | 默认每次 **fresh** 新线程；要跨次复用同一线程需 TOML/API 设 `langgraph_thread_mode=sticky` |

**记忆开关 ≠ 自动 sticky。** 多数日报类任务保持记忆关闭、每次独立更干净。

深读：[自动化调度参考](automation-scheduler.md) [[guides/tasks/automation-scheduler|自动化调度参考]]。

## 七、常见问题

**Q：到点没跑？**  
卡片是否 **运行中**（非已暂停）；Gateway 是否在跑；全局调度是否被 `EVOFLOW_AUTOMATION_SCHEDULER=0` 关掉；cron 时区与本机是否一致；并发是否打满。

**Q：状态栏一直「调度器未启动」？**  
面板状态指示可能未实时拉 Gateway；以任务是否到点执行、Gateway 日志为准。也可用调度参考里的 API 自查。

**Q：一次性任务跑完后？**  
通常不再按周期触发；徽标仍可能显示「一次性」。需要重复请改成每天/每周或再建一条。

**Q：超时默认多少？**  
界面默认 **30 分钟**（不是 60）。

**Q：和任务中心有何区别？**  
自动化 = 到点规则（提示词或工作流）与运行历史；任务中心 = 用户待办、员工协作派发与看板。二者入口、数据模型都不同。

**Q：和员工「自动上班」有何区别？**  
员工按岗位职责与巡检策略主动干活，在侧栏「员工」管理。自动化是你配好的计划到点触发。详见 [自动化中心概念](../../explanation/automation-center.md)。

**Q：提示词模式只能用内置 Agent 吗？**  
不是。可从**在编 AI 员工**中选；没有员工时再选智能体。

**Q：目标 Agent 在哪？**  
实时聊天的 **Goal** 模式，见 [目标 Agent](../chat/goal-agent.md) [[guides/chat/goal-agent|目标 Agent]]。不在任务中心，也不在本页。
