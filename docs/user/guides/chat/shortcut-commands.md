# 快捷指令使用指南

> **比如你不想点来点去，直接打一条指令搞定**：
>
> - `/goal 每小时检查一次服务器健康` — 创建目标任务并启动
> - `/claude` — 进入代码助手（Claude Code）模式
> - `/new` — 新建会话线程
> - `/status` — 看看当前会话状态
> - `/help` — 查看所有可用指令
>
> 指令在桌面端聊天窗口与 IM 渠道（飞书、Slack、Telegram 等）通用，不用记功能页面路径。
>
> **功能关系**：快捷指令是常用功能的快捷入口——覆盖 [目标智能体](goal-agent.md) [[guides/chat/goal-agent|目标智能体]]、代码助手、会话管理等，让用户在不同渠道获得一致的操作体验。

---

## 一、模式切换类

| 指令 | 别名 | 功能说明 | 使用示例 |
|------|------|----------|----------|
| `/claude` | `/claude-code` | 开启代码助手（Claude Code）模式，使用原生 Claude Code 能力 | `/claude` |
| `/claude [会话ID]` | `/claude-code [会话ID]` | 续接指定 ID 的历史 Claude Code 会话（IM 渠道） | `/claude sess_123456` |
| `/lead` | `/main` | 关闭代码助手模式，切回 EvoFlow 主智能体 | `/lead` |

---

## 二、任务管理类

| 指令 | 别名 | 功能说明 | 使用示例 |
|------|------|----------|----------|
| `/goal [任务目标]` | `/hd`、`/hosted` | 直接创建并启动后台目标任务 | `/goal 每小时检查服务器磁盘占用，超过90%告警` |
| `/goal start` / `/goal apply` | — | 确认/应用最近的目标方案（start 启动，apply 仅填入面板） | `/goal start` |
| `开始` / `确认` / `启动目标` | — | 目标方案确认短指令（桌面端与飞书同一会话通用） | `确认` |

---

## 三、会话与查询类

| 指令 | 功能说明 | 使用示例 |
|------|----------|----------|
| `/new` | 新建独立会话线程，上下文和之前完全隔离 | `/new` |
| `/status` | 查看当前会话的模式、绑定线程、上次 Claude 会话 ID、目标运行状态 | `/status` |
| `/models` | 查看所有可用模型列表 | `/models` |
| `/memory` | 查看当前会话的记忆内容 | `/memory` |
| `/workspace query` | 查询当前工作空间（`create` 新建、`set` 指定，见 [工作空间](workspace.md)） | `/workspace query` |
| `/help` | 查看所有可用指令说明和用法 | `/help` |
| `/bootstrap [提示]` | 初始化工作区（首次配置，IM 渠道） | `/bootstrap 初始化工作区` |

---

## 使用注意事项

1. **不区分大小写**：指令大小写不敏感，`/CLAUDE`、`/Claude`、`/claude` 效果相同
2. **参数支持空格**：指令后面的参数可以包含空格，比如 `/goal 每天9点发日报` 可以正常识别
3. **群聊使用方式**：在飞书/Slack 群聊中使用时，需要 @机器人 后再输入指令
4. **错误提示**：如果输入了不存在的指令，系统会提示 `Unknown command` 并建议输入 `/help`
5. 桌面端未加参数发送 `/goal` 时，等价于打开「目标」面板手动填写
