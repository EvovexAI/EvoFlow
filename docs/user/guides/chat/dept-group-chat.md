# 部门群聊

> **一句话**：把同一部门的在编员工拉进一个群里同屏说话——直接说事给负责人，`@岗位名` 点名谁就谁接；派工条能看排队中 / 回答中 / 已回 / 失败。
>
> **何时用**：多人同屏协同点名、旁观谁在办。  
> **何时不用**：一对一急派 → [小V](../configuration/evopanel-guide.md#小v全局-ai-小秘书)；正式交工审批 → [员工](../configuration/smart-employees.md)；固定填参再跑 → [工作流](../configuration/app-center.md)。

---

## 5 分钟进群

1. 打开 **首页总览**（组织指挥台）：看 `你 → 小V → 各部门`。
2. 点某个 **部门卡** → 浮层里点 **打开部门群聊**。  
   或：聊天侧栏切到 **BOT** → 部门树旁点 **进群**（「去 {部门} 群聊」）。
3. 输入框直接说事由 → **部门负责人**承接；需要指定人时写 `@岗位名` 或点花名册芯片插入 `@`。
4. 看气泡下的 **派工条** 与顶部 **本轮待回复** 轨，确认谁在排队 / 回复。
5. 要看工具过程：点成员头像 → 资料卡 → **实时过程**（右栏跟岗；唤醒时不会自动撑开右栏）。

---

## 怎么打开

| 入口 | 操作 |
|------|------|
| **组织指挥台** | 首页总览 → 部门卡 → **打开部门群聊** |
| **BOT 侧栏** | 部门行旁「进群」图标 |
| **会话键** | 选中后形如 `dept:{部门 id}:chat`；主区加载群聊时间线 |

部门头像可在指挥台部门卡上预设或上传。群成员 = 该部门**在编且已确认上班**的员工；草稿岗一般不进群。

---

## 怎么说话

| 你怎么发 | 谁接 |
|----------|------|
| **直接说事由**（无人 `@`） | **部门负责人**默认承接 |
| **`@岗位名`**（可 `@ 名`、中文紧挨） | 被点名的员工 |
| **点花名册芯片 / 资料卡「@点名」** | 插入 `@` 再发送 |

空态提示大意是：直接说事由由负责人承接；需要谁就 `@` 成员点名。

**小V**：不默认进每个部门群。只有她真属于该部门花名册、且被你显式 `@` 时，才以「群管家」身份参与。

---

## 看懂状态

含 `@` 的用户气泡下会挂 **派工条**：

| 标签 | 含义 |
|------|------|
| **排队中** | 已入队，尚未开跑 |
| **回答中** / **回复中** | 正在执行 |
| **已回** | 已有定稿回复 |
| **失败** | 点名失败 |

主区顶部 **本轮待回复** 轨：芯片显示「排队中 / 回复中」，可点开跟岗。

**唤醒队列（用户侧）**：同一人串行；短窗内重复 `@` 会合并；执行中再 `@` 并入本轮（不另开完整一轮）。成员回复里再 `@` 别人可 **接力**；寒暄 / 报到类不接力（防互相喊到死循环），深度有上限。

---

## 跟岗与右栏

| 操作 | 结果 |
|------|------|
| 头像 → **实时过程** | 打开该员工在本部门的跟岗工作会话（右栏过程面板） |
| 头像 → **查看资料** | 员工详情（`#/proactive/:code`） |
| 过程面板顶栏 **复制对话** | 复制跟岗过程（不是群时间线本体） |

群聊唤醒 **不会**自动撑开右栏；须你点「查看实时过程」或待回复轨。

跟岗会话 ≠ 普通聊天里 `@` 智能体答题：群里点名走的是员工工作会话，可带工具、可进任务中心。

---

## 后台活干完

群里起的后台工作流 / 协作任务终态后，可能以该员工名义回群一条气泡，标 **自动回执**（同一次运行通常只一条）。正式验收、同意派发仍在 [任务中心](../tasks/task-center.md)。

---

## 语音播报

群顶栏可开 **扬声器** / **静音**；播报中可 **停止**。副标题可能显示「正在播 · {名字}」。

可按员工绑定音色与语速（成员卡 / 工作区信息轨）。朗读时剥掉 `@` 符号但仍念人名。打断或切会话会停播。

---

## 和编制、小V、正式交工的关系

| 能力 | 适合 |
|------|------|
| **部门群聊**（本文） | 多人同屏、旁观进度、`@` 点名 |
| **小V 一对一** | 临时委派某岗、查全局待办 |
| **正式交工 / 同意派发** | 上下级流水线、要审批门 |
| **派发 / wake** | 任意在岗同事叫醒（含同级） |

负责人决定「无人 `@` 谁接」；部门与上级在侧栏 **员工 → 组织 / 部门** 配置。详见 [智能体员工](../configuration/smart-employees.md)。

## 常见问题

**@ 了没反应？**  
确认对方在该部门在编且已确认上班；草稿 / 请假岗不接活。看派工条是否「失败」。

**直接说话为什么是负责人回？**  
无人 `@` 时默认负责人承接；要指定人请写 `@岗位名`。

**为什么互相 @ 停了？**  
寒暄 / 报到类不接力；接力深度有上限，属防死循环设计。

**小V 怎么不在群里？**  
她不默认进每个部门群；只有编进该部门花名册且被 `@` 才以群管家出现。一对一委派仍用右侧小V 面板。

**和聊天里 @ 员工有何不同？**  
主聊天 `@员工` 多是派一件活；部门群是多人同屏时间线 + 派工条 + 跟岗过程。

**切到别的部门群会怎样？**  
会话按部门隔离；语音播报通常随切会话停止。
