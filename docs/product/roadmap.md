# EvoFlow 产品路线图

> 状态：初始化模板。路线图由 ChatGPT 维护，落实到可执行的 EVO 任务。

## 产品愿景

将 EvoFlow 建设为可管理、可扩展、可审计的 Agent Runtime 与控制平面，让团队能够安全地组织智能体、技能、工具、记忆和任务。

## 规划周期

| 阶段 | 目标 | 关键结果 | 状态 |
| --- | --- | --- | --- |
| P0 基线 | 建立协作、文档和发布流程 | 分支规则、任务台账、架构基线可用 | 进行中 |
| P1 组织能力 | 定义 Agent、团队、角色和权限的管理体验 | 管理模型、API、EvoPanel 页面与验收用例 | 待规划 |
| P2 运行治理 | 提高 Runtime 的可观测性和可靠性 | 任务追踪、审计、健康检查、故障处置 | 待规划 |
| P3 生态扩展 | 规范 Skills、MCP 和第三方集成 | 可发现、可配置、可验证的扩展机制 | 待规划 |

## 维护规则

- 只记录已决定的方向与可衡量结果，不以路线图代替需求文档。
- 每一条路线图项至少关联一个 `EVO-` 任务。
- 范围、目标或优先级发生变化时，在相关 ADR 或需求条目中说明原因。
