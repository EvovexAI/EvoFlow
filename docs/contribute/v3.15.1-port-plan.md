## 1. P0-A：服务端 command 层（`backend/app/gateway/v4/`）

ZCode 的 command 层是 TS 且与 ZCodeApp core 紧耦合，**移植的是语义与结构，不是逐行代码**。目标：`V4ConversationHub.send_command`（conversation.py:716）从只认 `createSession`/`sendText` 扩到命令族，并把裁决语义对齐 ZCode 的 `CommandInbox`。

参照源码（语义基准）：
- `command-inbox.ts` — admission 三态事实分离：in-flight（pinned）/ live input（pinned）/ settled（512/session LRU）；per-session FIFO gate（key gate → session gate 固定锁序，settle 才释放）；`duplicate`/`stale`/`noop`/`failed` 终态语义（failed 不被 duplicate 覆盖）。
- `commands/executor.ts` — 注册表分发 + `SELECTION_SIDE_CHAT_RESTRICTED_COMMANDS` 守卫 + admission 注入（`__v4Admission`）。
- `commands/types.ts` — host 钩子清单（getQueueItem / hasQueuedDelivery / getInputRoutingMode / resolveStableForkTarget …），EvoFlow 版本按需裁剪。
- `commands/handlers/queue.ts` — queue 命令组语义（delete 未命中=noop 而非 accepted；sendQueuedNow 的 reserve→lease→preempt→start→remove 五步与回滚）。

 checklist：
- [x] `v4/command_inbox.py`：三态事实表 + per-session FIFO admission gate + settled LRU(512) + stale/duplicate/noop 裁决 + `query` 批量查询（对应 `POST /command/query`，logbook 简化项 4）
- [x] `sendText.requestedDelivery`（`startNow | queue | guide`）：turn running 时 `queue`/`guide` 入队而非拒绝 busy；held-choice 校验（heldQueueInputRequiresChoice）→ **held-choice 批次二**
- [x] `stop`：demo 路径 `turn_task.cancel()` + interrupted 终态帧；停止后 `autoDrain=false, pauseReason="stopped"`；镜像路径仍走旧 REST（批次二桥接）
- [x] queue CRUD：`editQueueItem`（compact kind 不可编辑）、`deleteQueueItem`（未命中 noop）、`reorderQueueItem`、`sendQueuedNow`（idle 才提升；running 时拒绝 `guard.queuePromotionBusy`）、`setAutoDrain`（恢复时 idle 立即 drain）
- [x] `setAssistantFeedback`：v1 内存记录（transcript metadata 持久化批次二）
- [x] `retryTurn` / `editUserQuery` / `compact`：显式 `unsupportedCommand`（reasonCode 明确），批次二
- [x] snapshot/state patch 携带 `queue`（结构 = vendored `queueStateSchema`）与 `autoDrain/pauseReason`
- [x] 单测：admission 串行性、幂等重放、stale revision、queue 提升/回滚（16 例）

### 2026-10-24 批次一（本批完成）

**P0-A 服务端 command 层 — ✅ 落地**

- 新增 `backend/app/gateway/v4/command_inbox.py`：ZCode `command-inbox.ts` 的 Python 语义移植——
  in-flight/live/settled(512 LRU) 三态事实、per-session FIFO admission gate（显式 release 到 settle）、
  CAS 守卫（`COMMANDS_REQUIRING_BASE_REVISION` 15 种 / `ROW_TARGETING_COMMANDS` 5 种）、
  duplicate（failed 不覆盖）/ stale / noop 裁决、`query` 批量幂等查询。
- `conversation.py`：`send_command` 重写为 inbox + 分发。新增命令：
  `stop`/`abort`（取消 turn + autoDrain=false + pauseReason=stopped + interrupted 终态帧）、
  `sendText.requestedDelivery`（running 时 queue/guide 入队、startNow 显式拒绝 busy）、
  `sendQueuedNow`（idle 提升；running 拒 `guard.queuePromotionBusy`）、
  `deleteQueueItem`（未命中 noop）/`editQueueItem`（compact 拒编辑）/`reorderQueueItem`/

  `_append_text_delta` 同步维护权威行文本（修快照/终态帧用过期 text 整行替换抹掉流式内容的隐患）。
- 两个关键竞态修复：①cancel-before-start（命令前 `sleep(0)` 让新 turn task 跑完 prologue）；
