**目标**: 当前 v4 shell (`V4ShellRoot` → `V4ChatPane`) 视觉是"光秃秃的 chat 一片"

要换成 zcode 桌面的完整 `WorkspaceShellLayout`,让用户看到 zcode 桌面的"主对话 UI"。

## 3. 障碍

### 3.1 WorkspaceShellLayout 类型约束

`WorkspaceShellLayoutProps`(定义在 `zcode-ui/app-shell/types.ts`)是 **`extends Omit<AppProps, ...>`** 加
~80+ 自有 prop,共 **120+ required**。把 zcode 桌面 `App.tsx` 1201 行的 state machine
**完整搬到 V4ShellRoot 才能填齐**。

### 3.2 App.tsx 状态机

`App.tsx` 用到的关键 state 编排:

| state 来源 | 用途 | 桥接难度 |
|---|---|---|
| `useZCodeStore` (zcode 全局) | theme/user/notificationEnabled | **已通**(StoreProvider 已在 V4ShellRoot) |
| `useZCodeSessionStore` | workspaceState / taskList / draftSessionId | **高**——EvoFlow 没注册 task 概念,需要 mock |
| `useTabStore` | tabs / activeTab | **中**——单 workspace,只一个 tab |
| `useAppPanels` | terminal / side pane / browser panel | **中**——EvoFlow 不接 → 全部 false / null |
| `useWorkspaceActiveTaskState` | activeTaskId / draftSessionId | **中**——可桥到 selectedSessionKey |
| `useWorkspaceShellZCodeState` | activeTaskId / draftFocusVersion | **中** |
| `useGitRepository` | gitState.summary / gitDirtyFileCount | **低**——EvoFlow 不接 → null |
| `useAppChromeState` | sidebar/terminal/sidePane 可见性 | **低**——走 useAppPanels |

### 3.3 不可绕过的硬依赖

- `useZCodeSessionStore` 在 zcode `WorkspaceSidebar` 内被消费:任务列表、新建任务草稿、
  session dock 行为。EvoFlow 不注册则侧栏只显示"新建任务"按钮 + 命令中心(空列表)。
