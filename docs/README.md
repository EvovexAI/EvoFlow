# docs/

Public **user documentation** for MkDocs (`mkdocs.yml` → `make docs-serve` / `make docs-build`).

| Path | Role |
|------|------|
| `index.md` | Docs home + Quick Links (Hermes-style entry) |
| `user/` | Tutorials, guides, cases, explanation |
| `contribute/` | Contributor guide (repo map, branching, skills, RFC) |
| `llms.txt` | Curated LLM doc index (Hermes-style) |
| `assets/` | Screenshots / demo media |
| `generated/` | OpenAPI export (not in MkDocs nav by default) |

Non-public design / system docs live outside this tree (`evo/EvoFlow-private-docs/`).
