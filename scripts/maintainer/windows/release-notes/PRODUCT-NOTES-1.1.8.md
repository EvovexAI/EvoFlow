**EvoFlow v1.1.8 — 媒体生成多模型接入 / 语音与唤醒链路加固 / 阻塞与权限审计修复 / 弹层动效统一**

本版覆盖自 **1.1.7** 以来实际合入的用户可感知变更。

### 新增

- **媒体生成多模型接入**：新增即梦、万相 2.7、可灵、MiniMax 视频、OpenAI 图像等多个生成渠道，统一收口到 provider 工厂，可在生成面板直接选择；平台结果卡新增媒体预览，生成产物就地查看
- **系统状态面板**：设置内新增系统状态页，集中查看运行与依赖概况，排查环境问题更直接
- **向量模型双模式安装**：向量模型支持云端与本机两种安装模式，预设列表可直接点选切换

### 变更

- **语音与唤醒链路优化**：连续对话、唤醒与打断链路整体加固，本地识别与打断模型随包内置，免提体验更稳定
- **任务重试与并发加固**：任务整包重写改为乐观并发，过期提交直接拒绝，重试与自动化删除更可靠
- **弹层与切页动效统一**：模态 / 抽屉 / 菜单的进出场与遮罩淡入淡出统一，路由切换消除白屏闪变，骨架屏节奏一致

### 修复

- 聊天页偶发整页打不开：去重重复的 api 引入后恢复正常
- 任务中心点击无反应：右栏「首页收栏」不再误收起执行过程
- 权限越权风险：工作流 runs 端点鉴权收紧（fail-closed），任务 ACL 与本地直连路径守卫加固
- 自动化单复活：脚本化删除改走显式事务，不再被后续事务回滚复活
- 孤儿待办单：建单归属只认真实执行主体，杜绝自动化每轮产生的孤儿 pending 单
- 市场目录卡顿：目录拉取失败后负缓存 5 分钟，外网波动时不再干等超时
- 系统卡顿：消除多处线程阻塞点，媒体 IO、调度并发与锁竞争优化，长任务可观测
- 打包版语音异常：随包内置 pipecat 本地识别 / 打断模型

### 覆盖安装即可

无数据迁移。从 **1.1.7** 覆盖安装至 **1.1.8**。
