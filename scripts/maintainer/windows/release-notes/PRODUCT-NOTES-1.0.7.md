**EvoFlow v1.0.7 — 知识库归一与角色工具精准管控**

### 用户可见

- **知识库单一路径**：旧的 Obsidian / vault 接入已下线，UI 与文档全部改为 owned KB（每个知识库独立索引）。少了另一套知识库入口，资产与文档储存更加可控
- **角色工具项可显式勾选/取消**：「任务」、「平台」、「侧边面板」等系统级工具现在能够由角色编辑器逐人配置；不再被任何一个角色所「隐性必装」勾选只需不勾选就可彻底不挂载
- **合并修复**：之前部分聊天场景下默认工具面会被强制挂载仒仒拼一个完整工具表（其中含上代项目协作工具），现在该问题已修复 — 默认聊天模式下不再多出多余工具

### 版本与安装

- 桌面端 / 面板 / 后端 / harness 统一 **1.0.7**
- 安装包名：`EvoFlow_1.0.7_x64-setup.exe`（macOS 对应 DMG）

### 升级建议

- 建议从 1.0.6 覆盖安装至 1.0.7
- 本版含知识库迁移点：旧安装路径中的 Obsidian vault 不会自动转换，请使用 owned KB 重新上传
