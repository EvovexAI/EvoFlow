**EvoFlow v1.3.50 — 部门群回复等当前轮完成再派工**

本版相对 **1.3.49**：部门群成员在 V4 接管后仍等本轮跑完再取正文与派工，避免空回复或拿旧 sticky 会话内容误派；寒暄类短句走轻量模式。覆盖安装即可。

---

### 修复

- **部门群 detached 轮次**：`awaitingV4` 后继续监听，按本轮 runId 等最终事件 / 落库正文，不再一返回就当结束
- **旧回复误派工**：去掉「随便取最新助手回复」的回退，防止旧会话内容触发新 @ 派工
- **执行态清空 runId**：桌面端完成后清掉 runId 时，须有本轮非空最终助手行才算完成
- **失败 / 取消 / 超时**：显式报错并释放监听，十分钟上限，不重复发送

### 改进

- **门店设计简要对齐**：门店设计部 / 施工绘图岗在群内交接前提示对齐门店、部位、图号版本
- **轻量寒暄**：单独打招呼、短验收回声走 ask，真正干活仍恢复 agent
- **少读历史**：运行中不扫全量 transcript，只读本轮结果；能力页签选择钩子一并带上

### 覆盖安装即可

无数据迁移。从 **1.3.49**（或更早 1.3.x）覆盖安装至 **1.3.50**。
