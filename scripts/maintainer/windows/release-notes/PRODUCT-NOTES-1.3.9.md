**EvoFlow v1.3.9 — 部门头像、记忆更省 token、连接更稳**

本版相对 **1.3.8**：部门与员工新增头像图库，指挥台和群聊一眼认人；长期记忆目录按类别分组、只列文件名，明显减少上下文占用；模型流式响应新增首帧超时保护，V4 连接失败可手动重新连接；同时修复 macOS 安装包构建（覆盖安装即可）。

### 新增

- **部门头像**：部门和员工都有可选头像，指挥台、群聊、部门详情统一显示
- **模型渠道探活**：维护脚本可直接列出 / 探测 / 试调模型连接

### 改进

- **长期记忆注入**：目录按「事实 / 过程 / 经验 / 反思」分组，只列文件名，回答更快、更省上下文
- **生图提示**：模型能分清「刚生成的图」和「屏幕截图」
- **待发队列**：↑ 加塞不打断整轮；空 Enter 可打断并立刻发送排队消息；扫码会话失效会提示重新扫码

### 修复

- **流式首帧**：上游连上却不吐字时 60 秒断开重试，不再干等
- **连接稳定性**：网关重启 / 网络抖动时有界退避重连，V4 失败态新增「重新连接」按钮
- **macOS 安装包**：修复 v1.3.6–v1.3.8 的 macOS 构建失败
- **todo_write**：修复首轮注入缺字段导致的报错

### 覆盖安装即可

无数据迁移。从 **1.3.8**（或更早 1.3.x）覆盖安装至 **1.3.9**。
