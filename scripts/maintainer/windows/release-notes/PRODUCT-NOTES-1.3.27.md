**EvoFlow v1.3.27 — 正式包构建修复、语音多轮与停写封投影**

本版相对 **1.3.26**：修复导致正式包流水线失败的核心层越权依赖；小 V 多轮 ASR 不再把上一句粘进本句；用户点停时 V4 投影先封口再掐流。覆盖安装即可。

---

### 修复

- **正式包构建失败（arch-guard）**：会话停止封投影、工作流写入进度卡改为经 runtime ports 注入，不再从核心层直接 import Gateway
- **小 V 多轮听写粘句**：已确认的上一句不再粘在本轮 ASR 前面；过短句允许整句重发
- **用户点停**：先封 V4 投影再停流，避免停后工具/思考卡仍转

### 改进

- **性能浮层**：采样与展示更完整，便于本机核对卡顿
- **对话计时日志**：补充首响与轮次闩锁字段

### 覆盖安装即可

无数据迁移。从 **1.3.26**（或更早 1.3.x）覆盖安装至 **1.3.27**。
