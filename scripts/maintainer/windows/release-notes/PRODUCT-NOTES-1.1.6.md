**EvoFlow v1.1.6 — 任务节点进度右栏化 / 员工渠道扫码绑定 / 右侧预览升级 / 自动化补跑与工作流加固 / 模型失败可见化**

本版覆盖自 **1.1.5** 以来实际合入的用户可感知变更。

### 新增

- **任务节点进度**：任务详情新增「任务节点」树，点节点即可在右侧查看对应工作流与每个节点的独立进度，无需跳转会话
- **员工渠道扫码绑定**：创建/雇佣员工、新建知识库后，助手会引导在本岗对话内扫码绑定飞书/企微机器人，扫码完成即自动生效
- **右侧预览升级**：支持代码、补丁、图片、音视频、PDF、PPT 与多文件差异预览，新增 SVG/JSON/CSV/Mermaid 与 HTML「渲染 / 源码」切换，产物可自动打开
- **首页「正在处理」**：工作台新增卡片，聚合正在进行的对话、员工、自动化与工作流
- **员工值班记录**：可查看每次值班的触发轨迹、会话与轮次评分，并显示执行耗时与每步产出
- **进度一键直达**：平台操作结果卡新增「查看进度」；对话中的 Agent/Task 工具卡新增「在右侧打开」
- **定时任务更灵活**：支持按分钟触发；关闭应用期间错过的计划，重新启动后会自动补齐

### 变更

- **任务详情布局**：改为「详情 | 侧栏」双区；任务中心区分「在跑」与「已中断」
- **预览入口**：文件与代码预览统一改为半宽右侧栏，不再弹出接近全屏的窗口
- **会话列表**：工作区排序以服务端为准、本地仅作冷启动缓存；新增分组拖拽换序、置顶整行拖拽与折叠、工作区菜单、空态「新建对话」
- **模型限流**：同一模型最多重试 3 次，退避优先遵循服务端提示（最长 5 分钟），不再自动更换密钥或切换模型
- **渠道并发**：默认由 5 提升到 64，多员工机器人消息处理更顺畅
- **对话模式**：默认 Agent，原「Ask」选项下线（历史 Ask 会话按 Agent 使用）
- **安装包**：支持多会话并发，升级到新版本可直接覆盖安装

### 修复

- 飞书连接重连后重复回应同一条消息
- 员工扫码绑定后消息仍由主智能体处理，员工专属机器人无法独立收发
- 历史会话打开卡在「等待首帧」、大会话无法正常加载
- 发送消息气泡延迟出现、新会话被误判为工作台首页
- 模型调用失败时正文消失、界面一直「生成中」
- 打开网页或文件时右侧栏无反应、话术文件链接无法关闭
- Office/Excel 预览导致页面整体刷新，并让预览跟随明暗主题
- 本地访问时同一用户被拆成两套身份（现统一为主管理员）
- macOS 上员工页面挡住窗口拖动、内嵌浏览器盖住侧栏或最大化后错位
- 定时任务漏跑 / 重复触发 / 配置冲突被静默忽略
- 已完成节点被改回「执行中」而卡住、或对已完成节点的追问被重新执行
- 执行失败只显示笼统错误码，现在会一并显示失败原因

### 覆盖安装即可

无数据迁移。从 **1.1.5** 覆盖安装至 **1.1.6**。
