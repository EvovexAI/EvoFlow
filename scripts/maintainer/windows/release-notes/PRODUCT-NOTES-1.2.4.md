**EvoFlow v1.2.4 — 国内能查出更新，聊天 / 语音 / 协作更稳**

本版相对 **1.2.3**：修复桌面「检查更新」在国内不可用的通道问题；V4 聊天编辑与流式、语音 ASR、知识库目录、中断运行态、协作子任务与并发设置等一批稳定性改进（覆盖安装即可）。

### 修复

- **桌面更新通道**：公仓补上 `update/latest.json`；客户端优先拉 Gitee 清单，下载走 `ghfast` 镜像 GitHub 安装包（Gitee 附件上限约 100MB，装不下完整 setup.exe，由 CI 打 tag 后在 GitHub 自打包）
- **V4 聊天**：恢复改已发消息；避免编辑截断双开线程；空流重试复用输入行；飞书旁观 V4 更新更稳，去掉重复 run 转圈
- **语音**：压制 ASR 错误/日志风暴，避免拖死聊天
- **知识库**：无本地同步目录时仍显示目录树；`markitdown` 失败回退更轻量的抽取器
- **运行态**：中断的 run 不再长期粘在 UI/SQLite 的 running；Gateway 经 HTTP 走渠道工具并尊重 live 租约
- **协作子任务**：新派发步骤在租约戳前视为 live；重入队前清掉终态残留；侧栏心跳与最近活动时钟
- **预览**：窄侧栏代码/diff 可读；Gateway 回 SPA 壳时仍能读本地绝对路径
- **其它**：资产引用深链到右栏；删除员工时清掉对应 IM 会话；侧栏视图模式与聚焦员工可持久化

### 改进

- **设置 → 通用**：可限制 LangGraph 并发
- **Agent**：递归接近上限时软着陆，避免硬崩；放宽 wrap-up / recursion 预算
- **小V**：人声与 Human Signal 技能收紧；右栏与主聊 V4 对齐
- **性能**：流式 bump 贴近 rAF；去掉易撑爆 User Timing 的 React 测量
- **主题**：可读性 token 微调

### 覆盖安装即可

无数据迁移。从 **1.2.3**（或更早 1.2.x）覆盖安装至 **1.2.4**。
