### 改进

- **状态中文化**：通知状态改显示「已完成 / 失败 / 已停止 / 已取消 / 进行中」等中文，并按语义配色——成功绿、失败红、停止琥珀，中文界面下不用再猜英文含义
- **异常一眼可辨**：失败与停止的通知，左侧多了一道状态色条，列表里扫一眼就能挑出出问题的那条
- **面板更紧凑**：会话名与状态徽标合并到同一行，正文和状态重复时不再重复显示；条目间距收窄、正文最多两行。单条通知高度从约 100px 降到 64px，同样高度能多看近一半的通知

### 修复

- 通知正文与状态内容重复时（如 `[Run_xxx] failed`）多占一行的问题

### 覆盖安装即可

无数据迁移。从 **1.3.2**（或更早 1.3.x）覆盖安装至 **1.3.3**。
