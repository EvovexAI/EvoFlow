### 改进

- **状态中文化**：通知状态不再显示 `completed` / `failed` 这类英文枚举，改显示「已完成 / 失败 / 已停止 / 已取消 / 超时」等中文短标签，并按语义配色——成功绿、失败红、停止琥珀、其余中性灰
- **中文结果也能识别**：目标模式的结果多是中文长句（如「任务完成」「执行过程中发生错误」「已手动停止」），现在同样归一成上面的短标签并着色，原始长句放在悬浮提示里查看，不用再猜英文含义
- **异常一眼可辨**：失败与停止的通知左侧多了一道 2px 状态色条，列表里扫一眼就能挑出出问题的那条；已读条目只淡化内容，色条保持实色
- **面板更紧凑**：会话名与状态徽标合并到同一行，`[Run_xxx] failed` 这类只重复状态的正文不再单独占行，条目间距收窄、正文最多两行。实测单条高度从 106px 降到 60px（无正文行）/ 80px（有正文行），同样高度能多看 4～7 条通知

### 修复

- 通知正文与状态内容重复时（如 `[Run_xxx] failed`）多占一行的问题
- `未完成 / 未成功` 的结果被「完成」关键字误判成成功状态的问题

### 覆盖安装即可

无数据迁移。从 **1.3.2**（或更早 1.3.x）覆盖安装至 **1.3.3**。
