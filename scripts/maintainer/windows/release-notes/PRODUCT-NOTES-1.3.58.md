**EvoFlow v1.3.58 — 修复 macOS x64 正式包、会话列表与 V4 稳定性**

本版相对 **1.3.57**：修复 GitHub Actions 上 macOS Intel（x64）打 DMG 失败；会话列表按工作空间组分页；V4 尾快照/内存压力与协作相关改动一并带上。覆盖安装即可。

---

### 修复

- **macOS x64 正式包**：DMG 重试改为只做 `tauri bundle`，并为 local-embed 权重保证可读，避免 cargo 指纹 `Permission denied`
- **会话列表**：工作空间分组树「加载更多」挂组内，展开时按需拉分页
- **V4 尾快照**：remint / rehydrate 场景不再误粘旧行或整帧丢弃

### 改进

- **渲染内存压力 / 投影窗**：cap 与停流日志更稳
- **数据保留 / 会话执行查询**：后台与执行态查询补强

### 覆盖安装即可

无数据迁移。从 **1.3.57**（或更早 1.3.x）覆盖安装至 **1.3.58**。
