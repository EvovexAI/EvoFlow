**EvoFlow v1.3.12 — 会话子任务看得见，百炼 Token Plan 可绑，工作流输出契约真正生效**

本版相对 **1.3.11**：对话里跑着的子任务 / 工作流 / 命令行会挂在会话上可点开看进度；设置里套餐新增阿里云百炼 Token Plan；工作流节点声明的输出结构会真正写进派发提示，下游字段绑定不再空跑。覆盖安装即可。

---

### 新增

- **会话子任务轨**：同一会话下的子智能体、工作流、值班与后台命令会登记到会话运行态；输入框旁有状态图标，可打开右栏「会话运行」面板查看进度；普通对话里的子任务默认后台跑完再回灌，不再把主会话卡住
- **阿里云百炼 Token Plan**：设置 → 套餐可切换火山 Agent Plan / 百炼 Token Plan；用 `sk-sp-` 套餐 Key 一键写入对话模型与媒体凭证；个人版各档模型表相同，界面不展示档位门禁
- **工作流输出契约落地**：节点配置了 `output_schema` 时，派发提示会明确要求返回对应 JSON；缺产出或下游 `{{steps.X.output.字段}}` 解不开时按生产门禁失败，不再静默空结果

### 改进

- **工作流进度更跟手**：节点进度在服务端只跳 10%→100% 时，界面用软爬升填中间态，运行图不再长时间停在 10% 像卡住
- **输入绑定类型纠正**：上游参数是字符串、下游声明数字/布尔时，派发前尽量按 schema 纠偏，减少「类型对不上」直接失败
- **套餐与模型页**：按当前套餐目录切换文案与 Base URL；百炼 / 火山 Plan 模型在列表上有 Plan 标记，避免和按量 Key 混用
- **可观测耗时**：分析侧补充平台动作与命令行 shell 耗时统计，便于排查慢步骤

### 修复

- **会话子任务图标点终端空面板**：打开后台命令时绑定到实际热流，而不再误用会话登记 id 当工具调用 id
- **工作流结构化输出空跑**：派发提示漏掉输出契约、缺产出曾被判合法、默认 warn 静默放行等问题一并收口

### 覆盖安装即可

无数据迁移。从 **1.3.11**（或更早 1.3.x）覆盖安装至 **1.3.12**。
