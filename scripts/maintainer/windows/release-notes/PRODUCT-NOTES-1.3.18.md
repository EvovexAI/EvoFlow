**EvoFlow v1.3.18 — 媒体预览更稳，工作区解析不再拖死界面，失败提示能看懂**

本版相对 **1.3.17**：中文路径成片预览更稳；工作区里扫大媒体目录不会把对话 / 员工接口拖死；模型断连或只报 `run_error` 时给出可操作提示；BOT 列表可单独开关自动巡检。覆盖安装即可。

---

### 新增

- **BOT 巡检快捷开关**：组织 / 员工列表可直接打开或关闭自动巡检，不必进编辑页改排班

### 改进

- **媒体预览**：中文等非 ASCII 路径在桌面预览时改走可播放通道，失败可刷新；并行 heal 限流，避免扫目录卡住
- **失败提示**：上游只回 `run_error` / 连接中断时，文案改为「模型服务中断或负载过高，请稍后重试；超长对话建议开新会话」
- **侧栏触发标签**：主面板会话不再重复显示「对话」芯片，渠道 / 定时等仍保留

### 修复

- **工作区解析拖死界面**：`resolve-target` / 取文件在大媒体树里限并发、限时软失败，避免员工页与对话 REST 长时间无响应
- **连发像死机**：上一轮已发送但未出首帧时再点发送，会识别卡顿并便于排查，而不是静默叠请求

### 覆盖安装即可

无数据迁移。从 **1.3.17**（或更早 1.3.x）覆盖安装至 **1.3.18**。
