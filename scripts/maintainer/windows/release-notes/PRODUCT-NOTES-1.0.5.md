**EvoFlow v1.0.5 — 知识库独立索引改造**

### 用户可见

- 知识库存储升级为**每个知识库独立索引**：文档、分块、嵌入、全文检索、资产与 wiki 均落在该知识库目录下的 `.evoflow/kb/index.db`
- 中心库只保留知识库注册表、任务队列与 Agent 记忆，多知识库场景更清晰、更省资源
- 修复知识库资产（blob）跨库路径串用问题
- 技能索引与加载优化
- 平台「经验库」保存字段扩展（问题/方案/结果/步骤等）

### 版本与安装

- 桌面端 / 面板 / 后端 / harness 统一 **1.0.5**
- 安装包名：`EvoFlow_1.0.5_x64-setup.exe`（macOS 对应 DMG）

### 升级建议

- 建议从 1.0.4 覆盖安装至 1.0.5
- 升级后旧知识库数据会自动迁移到新的 per-KB 布局
