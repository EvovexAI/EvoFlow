**EvoFlow v1.2.8 — 语音更顺，提示词更干净，员工设定一屏管**

本版相对 **1.2.7**：语音链路（SmartTurn、ASR 热词、打断归因、性能汇总）与提示词体系（身份去重、soul/职责拆分、缓存优化）双线打磨；新增员工角色设定条、聊天摘要面板重构与小V 跳舞 / 讲解形象（覆盖安装即可）。

### 新增

- **员工角色设定条**：思考、识图、系统提示词、SOUL、职责在同一面板管理，改完立即生效
- **语音**：支持 ASR 热词表；打断 / 播报问题可看到原因；语音报表新增六条汇总行
- **可观测性开关**：需要时再开 OBS，请求明细完整不截断
- **小V 形象**：新增跳舞与知识讲解状态，手臂贴图更自然

### 改进

- **提示词**：`<role>` 只出现一次身份锚点，SOUL 与职责去重；心境块后置，提升厂商前缀缓存命中
- **记忆**：退役工作区记忆注入，员工 / 用户资产中心即够用
- **聊天摘要面板**：结构与措辞打磨，能力概览标签统一中文
- **IM 渠道**：可见正文不再夹带推理内容

### 修复

- Gateway 暴露 `Range` 头，媒体 Range 探测恢复正常
- 错误提示、WebSocket 客户端、toast 等细节修补

### 覆盖安装即可

无数据迁移。从 **1.2.7**（或更早 1.2.x）覆盖安装至 **1.2.8**。
