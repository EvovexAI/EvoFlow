**EvoFlow v1.3.25 — 部门群语音、小 V 思考诊断与 SpecStream 搜索**

本版相对 **1.3.24**：部门群可按员工配置朗读音色并排队播报；小 V 语音台展示关思考是否传到厂商；联网搜索可选 SpecStream（需 API Key，不参与自动探测）；会话标题不再被后续轮次覆盖。覆盖安装即可。

---

### 新增

- **部门群语音**：群聊可按员工绑定音色，消息按队列朗读
- **小 V 思考诊断**：语音台可见关思考是否写入厂商请求
- **SpecStream 联网搜索**：设置中可选；填写 API Key 后作为首选后端（不参与自动探测）

### 修复

- **会话标题被覆盖**：生成标题后，后续轮次不再改写已有标题
- **角色思考配置**：按员工角色应用关思考 / 思考强度，语音与前台一致
- **会话模型覆盖**：覆盖模型时正确落库，避免切回默认模型

### 改进

- **会议 / Agent TTS**：音色与播报队列抽成共用模块，设置页与群聊共用同一套音色表
- **运行观测**：补充思考链路环缓冲，便于本机核对

### 覆盖安装即可

无数据迁移。从 **1.3.24**（或更早 1.3.x）覆盖安装至 **1.3.25**。
