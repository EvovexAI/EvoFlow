**EvoFlow v1.3.30 — 本机资源市场与多源目录**

本版相对 **1.3.29**：资源中心可开内网市场、添加同事的 catalog 源，并支持 zip 直链安装；打包分享可一键发布到本机市场。覆盖安装即可。

---

### 新增

- **本机资源市场**：在「获取资源」开启内网分享，生成带可选 token 的 catalog 地址发给同事
- **多源市场目录**：默认合并官方 GitHub 市场与你添加的自定义源；刷新一次看齐
- **导出并发布到本机市场**：打包分享可写 zip + 本机 Host，同事刷新即可安装

### 改进

- **zip 直链安装**：catalog 条目带 `download.zip_url` 时走 HTTP 安装（内网 / CDN）
- **资源包指南**：补充本机市场、市场源与公开 GitHub 市场上架步骤

### 修复

- **工具层契约**：任务状态别名、资产路径报错与自诊断度量脚本与现网口径对齐

### 覆盖安装即可

无数据迁移。从 **1.3.29**（或更早 1.3.x）覆盖安装至 **1.3.30**。
