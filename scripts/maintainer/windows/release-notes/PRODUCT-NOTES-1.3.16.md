**EvoFlow v1.3.16 — 长会话可提醒压缩，删员工不再留僵尸号，安装占用更好清**

本版相对 **1.3.15**：长对话会提示可主动压缩；演示工作台能看到运行转圈与实时调用；删掉员工会同步停掉 IM 连接；知识库向量额度用尽仍可关键词搜；升级安装时清掉安装目录里的后台孤儿进程。覆盖安装即可。

---

### 新增

- **长会话压缩提示**：消息很多或上下文偏满时，对话顶栏提醒可手动压缩（可关掉）
- **演示工作台可视化**：运行中转圈、进度软爬升、节点下实时调用记录与头像

### 改进

- **员工 MCP 绑定口径**：区分「跟随全局 / 已绑白名单 / 显式空绑」，空绑不再误显示成「N 个 MCP」
- **知识库配额友好降级**：嵌入额度或限流撞墙后冷却一段时间，文档仍可关键词检索，不再整队空撞
- **中文 MCP 服务名**：显示名含中文时用安全 id 挂到模型工具，避免函数名非法导致挂不上

### 修复

- **删员工后 IM 还在线**：删除时停掉该员工专属连接，并清掉孤儿绑定，避免僵尸号
- **升级安装文件被占用**：安装/卸载时清安装目录下的 bash / python / node 孤儿（不杀全机其他软件的 python）；提示从托盘完全退出
- **多会话同时打开卡死**：冷加载并发限流，避免几个大会话一起暖起把界面拖死

### 覆盖安装即可

无数据迁移。从 **1.3.15**（或更早 1.3.x）覆盖安装至 **1.3.16**。
