**EvoFlow v1.0.6 — 界面主题与色卡打磨**

### 用户可见

- **VS Code 风格全侧栏染色**：色卡变化时侧栏背景跟随同步，界面视觉更统一协调
- **历史会话与导航 active 态底色**：当前选中项底色跟随主题色卡，不再固定为单一颜色
- **accent palette 修 bug**：修复全局 CSS 变量覆盖问题，补齐默认/蓝色卡差异处理，修复渐变硬编码颜色问题

### 版本与安装

- 桌面端 / 面板 / 后端 / harness 统一 **1.0.6**
- 安装包名：`EvoFlow_1.0.6_x64-setup.exe`（macOS 对应 DMG）

### 升级建议

- 建议从 1.0.5 覆盖安装至 1.0.6
- 本版为 UI 打磨更新，无数据迁移
