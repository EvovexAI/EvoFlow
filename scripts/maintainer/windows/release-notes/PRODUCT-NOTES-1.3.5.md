**EvoFlow v1.3.5 — 旧库升级不再缺列，资产索引照常注入，子任务旁观可刷新**

本版相对 **1.3.4**：覆盖安装后的旧库会自动补齐遗漏的表与列（工作流工作目录、对话轮次字段、推送绑定等），避免「无此列 / 无此表」；记忆侧即使站立摘要为空，资产目录仍会注入；工作流节点对话可轮询刷新。覆盖安装即可。

---

### 参与本次发版

- 全栈开发工程师：旧库 post-baseline 补列/补表、空 standing 仍注入资产目录、子任务旁观轮询与刷新、资产快捷入口计数
- 发版工程师：CI/CD 正式包发布

---

### 改进

- **子任务对话旁观**：应用内查看节点执行记录时，执行中会定时拉取状态并刷新 V4 时间线；结束后再收一帧；可手动点「刷新」；嵌入侧栏时顶栏更紧凑，并显示「工作中」齿轮
- **资产快捷入口**：对话侧栏资产快捷区会显示经历 / 经验 / 反思文件数量，任务结束后自动刷新计数
- **记忆注入口径**：站立摘要为空或仅占位时，仍注入资产索引（经验 / 过程 / 反思文件名），不再整块消失；提示词明确「记忆仅供参考，以本轮最新用户问题为准」

### 修复

- **旧库缺列 / 缺表**：已处于最新 schema 版本号的数据库，启动时仍会补上后续才进基线的列与表——应用 `project_path`、聊天消息 `turn_*` 字段，以及机器人绑定 / 部门 / 推送绑定等表。否则工作流写工作目录、读历史轮次、IM 绑定时会报「无此列 / 无此表」
- **站立摘要误当成有内容**：磁盘上只剩 `v1` 壳子时按空处理，避免挡住资产目录注入

### 覆盖安装即可

无数据迁移；缺列 / 缺表在启动时自动补齐。从 **1.3.4**（或更早 1.3.x）覆盖安装至 **1.3.5**。
