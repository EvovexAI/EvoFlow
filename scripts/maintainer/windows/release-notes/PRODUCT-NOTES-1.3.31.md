**EvoFlow v1.3.31 — 对话 KeepAlive、资源包升级与终端/索引稳场**

本版相对 **1.3.30**：切会话不再整页拆装对话区；已装资源包可一键升级；长命令终端持续出字；重启后对话不再被索引暖机拖死。覆盖安装即可。

---

### 新增

- **对话 KeepAlive / 可选分屏**：切会话保留滚动与测高，输入栏不再跟着飘顶；支持主副栏并排
- **已装资源包升级**：市场有新版本时在「已装」里一键升级
- **代码索引检索卡**：对话里展示检索命中，引导优先走索引再翻文件
- **bash 输出流式化**：长命令执行期间终端持续出字；转后台后仍有增量与事件

### 改进

- **资源包防漂移**：装包持久化、流式下载与发布链路更完整；可检测并同步漂移
- **代码索引**：`.tsx` 用正确语法解析；块级向量与排序更准；私有符号可被检索
- **投影窗口 / 内存水位**：长对话按渲染压力裁顶，降低 WebView 撑爆风险
- **会话快照磁盘缓存**：重进会话更快回填时间线

### 修复

- **重启后对话卡死**：Windows 默认跳过 embedding 暖机；索引重建不再拖死整站接口
- **叫醒已入队仍报失败**：忙线排队按成功返回，不再误报失败
- **MCP / 桌面 stdio**：UTF-8 重配后日志与 MCP stderr 绑定失效导致插件起不来
- **内部续跑劈轮**：无新用户输入的续跑挂回同一轮，避免左侧「AI 回复」被劈成两截
- **循环守卫**：写盘后重置探索账本；复合命令指纹与终端双条件硬拦，减少空转连环点

### 覆盖安装即可

无数据迁移。从 **1.3.30**（或更早 1.3.x）覆盖安装至 **1.3.31**。
