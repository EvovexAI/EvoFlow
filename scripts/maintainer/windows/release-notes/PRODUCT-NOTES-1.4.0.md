**EvoFlow v1.4.0 — 工作流能按节点配能力，画布打开不再等**

本版相对 **1.3.3**：工作流编排从「选个人」改成「配能力」，每个节点可以单独挂技能、工具、MCP、知识库、模型和思考开关；应用详情页与子任务对话的打开速度明显变快；任务中心状态不再被「进程失联」盖掉。覆盖安装即可。

---

### 参与本次发版

- 全栈开发工程师：工作流节点级能力编排、画布与编辑面板重做、应用详情与子任务打开提速、任务状态口径修正、侧栏新建会话与右栏自动打开修复
- 发版工程师：CI/CD 正式包发布

### 新增

- **节点级能力配置**：工作流的每个节点可以单独指定技能、工具、MCP 服务器、知识库、模型和思考开关。节点不再默认继承某位员工的整套能力，而是按这一步实际要做的事来挂
- **工作流工作目录**：应用新增「工作目录」字段，写进应用定义并随运行带入，同一个工作流每次跑都落在指定目录，不用每次重填
- **悬浮式编辑面板**：工作流的节点库与节点配置合成右上角一张悬浮卡，可收起成气泡；选中节点自动展开到「配置」，顶栏点「节点库」也能唤出
- **员工选择下拉**：节点执行者改为下拉直选，不再弹整窗，选完就地生效；「编辑执行者」直接复用员工编辑面板

### 改进

- **应用详情页打开更快**：画布代码改为按需加载，并与应用数据并行拉取；列表 hover 即预热。以前点开要等画布整包解析完才发请求，现在两者同时进行，首屏明显更短
- **子任务对话打开更快**：打开工作流步骤记录时只取会话标识和结果，不再顺带跑整条任务的汇总修复，之前那种「一直转圈加载中」不会再出现
- **工作流运行图自动展开**：从对话里点「打开工作流」、或工作流开跑时，右栏运行图会直接展开，不再因为之前收起了右栏而像没反应
- **任务中心状态更准**：任务主状态只跟任务本身的执行状态（执行中 / 已完成 / 失败…），「进程失联」降级为附注芯片，不再把还在跑的任务盖成莫名其妙的「已中断」；详情页会写出账本最近更新时间和失联含义
- **排队消息不再丢**：流式中排队的消息按会话分开存放，切走再切回来还在，以前切一次会话排队就没了
- **员工在岗判定**：关掉自动巡检或总开关，员工仍显示「在岗」（可对话、可派活），只有请假和草稿才显示「已停」，不再把还能用的人误标成停岗
- **建流引导**：平台在生成/创建应用前会先查一遍可用技能、工具、MCP 和知识库目录，再把真实能力挂到节点上，不再先建空壳、事后靠「默认能力」补
- **更省 token**：资产目录已在每轮完整注入，去掉重复的逐轮标题匹配提示；会话意图汇总中间件退役（历史里本来就有前几轮用户消息）

### 修复

- **侧栏「新建会话」没反应**：侧栏空态按钮踩到一个不存在的变量，点击直接报错；现在能正常新建，并先从其他页面切回对话页
- **工作流运行通知标题显示任务 id**：改成显示应用名，不再是一串 `Run_xxx`
- **右栏工作流 CTA 点了没反应**：反馈里丢了任务标识时，点「打开工作流」会静默失败；现在用应用 id 补上，挂载失败还会回落到运行页深链
- **MCP 工具挂不上**：工作流节点绑定的 MCP 服务器在工具目录缓存偏冷时会挂载 0 个工具；现在会从热身缓存补齐并清掉过期缓存；命令行侧改员工工具绑定时，`mcp__服务器__工具` 也不会再被判为未知工具
- **按文件名找文件的工具**：`glob` 撤除，按名查找统一走命令行（`find` / `Get-ChildItem` / `rg --files`），旧配置里的 `glob` / `find` / `find_file` 自动映射到命令行工具，不用手动改配置

### 覆盖安装即可

无数据迁移。应用表新增的「工作目录」列会在启动时自动补齐，旧应用默认为空。从 **1.3.3**（或更早 1.3.x）覆盖安装至 **1.4.0**。
