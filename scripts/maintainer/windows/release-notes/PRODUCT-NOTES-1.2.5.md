**EvoFlow v1.2.5 — 工具超时不再拖死下一轮，知识库与预览更稳**

本版相对 **1.2.4**：修好命令行工具超时后占用执行锁导致下一轮卡住的问题；知识库自有目录与右栏预览、资产引用更可靠；并补齐 Gitee 独立发版链路（覆盖安装即可）。

### 修复

- **工具超时**：`bash` / LibreOffice 等命令超时后强制结束整个进程树，并留出短暂窗口让被丢弃的 worker 释放执行锁，下一轮不再“看起来卡住”
- **知识库自有目录**：文件夹与文件名先做大小写、斜杠规范化再匹配，目录树、文档预览与文件打开更可靠
- **右栏预览**：预览面板默认走本机「在资源管理器中显示」（不再被永久禁用的占位平台挡住）；Gateway 放行 `https://tauri.localhost`，修复媒体 `Range` 探测失败与跨域导致的「不支持播放这种媒体格式」
- **上下文用量环**：浮层打开时临时收起原生浏览器窗口，不再被右栏 WebView 压住一截
- **资产引用**：模型输出的 `note=[...]` 与路径解析更稳，可直接深链到右栏预览
- **界面细节**：浏览器面板外链图标、工具卡文件路径渲染、消息行与主题 token 微调

### 新增

- **Gitee 独立发版**：新增 Gitee Go 的 Windows 构建管线（`.workflow/`）与 `publish-gitee-release.ps1` / `ci-release-windows.ps1`

### 覆盖安装即可

无数据迁移。从 **1.2.4**（或更早 1.2.x）覆盖安装至 **1.2.5**。
