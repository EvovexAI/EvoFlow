**EvoFlow v1.3.37 — 修掉模型密钥外泄与正文串入思考过程**

本版相对 **1.3.36**：本版是一次以安全与稳定性为主的收口——修掉「查看已配模型会把 API Key 明文带进会话」这个凭据外泄口子，剥掉混进正文回复的思考过程标签，并把会话打开、代码检索、智能体工具报错三处最常见的卡顿与误导信息改掉。界面布局不变。

---

### 修复

- **模型密钥外泄**：`查看已配模型` 一类操作原来会把 API Key 原样返回（脱敏函数实际没脱敏），明文会进会话记录与日志；现在返回脱敏串，只有真实调用时取原值
- **正文串入思考过程**：部分模型把思维链写在正文里而非独立字段，回复中会出现 `<think>…</think>` 或上一轮的规划内容；现在各模型出口统一剥离
- **上拉的历史被冲掉**：上拉刚取到的更早会话行会被「上一轮尾部残片」挤掉（滚动区停在旧位置不动）；现在为本页新加载的行留出预算
- **思考中页面空白**：进行中的思考/工具行被窗口裁切一刀切掉后，后端仍在推增量、前端找不到对应行，界面出现空白；现在裁切后钉回进行中的那一轮
- **点开旧会话卡一下**：只读一个创建时间也会重建全部会话行（本机 547 个会话实测冷启 6976ms）；现在单行读取（0.017ms）
- **数据库报错误导**：并发写时报的 `database is locked` 实际是本进程内的线程锁没抢到，不是数据库文件锁，照着提示去查库毫无用处；文案改为说明真成因并给出正确处理（重试）
- **代码检索首次调用**：嵌入模型冷启动不再压在第一次检索上（原首调要等 45 秒超时才出结果）

### 改进

- **代码检索更稳更快**：文件变更检测移出检索主路径（原来每 30~60 秒必有一次检索要多付 1.2 秒）；覆盖率统计不再全表扫 1.84GB 向量表（486ms 起）；检索走独立线程池，不再和别的任务抢默认池
- **智能体工具报错说人话**：资产写入/读取失败时点名是哪个文件、缺什么（缺目录自动补、缺 `.md` 后缀自动补、找不到同名文件时给出候选名）；平台工具的只读操作不再显示「状态已变更」这类假提示；改文件时若目标字面串在内容里唯一命中则放行（此前 35 次误拦中 32 次属此类）
- **浏览器自动化更准**：元素定位补上无障碍角色映射（原来 `heading`/`searchbox`/`list` 等常见角色匹配不到，实测必搜结果的标题页匹配数为 0），选择器写错、计数参数非法时给出可读错误而非静默失败
- **运行态可自证**：状态接口现在直接给出当前运行版本与源码是否已改动未重启，「改了没生效」不再靠猜
- **调试浮层**：V4 调试浮层按当前会话过滤，一行可读（序号 + 思考/正文/工具 + 内容摘要），旁路会话与预取的流量不再混进来

### 覆盖安装即可

无数据迁移。从 **1.3.36**（或更早 1.3.x）覆盖安装至 **1.3.37**。
