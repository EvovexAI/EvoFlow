**EvoFlow v1.3.0 — 画像更统一，右栏能看文件，员工能力即时生效**

本版相对 **1.2.9**：用户画像合并为一个文件；右侧栏可直接预览工作区文件；修改员工能力后下一轮立即生效；启动更快。

### 新增

- **右栏文件预览**：工作区里的文本 / 文档可直接在右侧打开，切换标签不重复读盘
- **助手预览卡**：助手回复里的文件卡可直接校验并打开
- **扩展管理**：扩展启用 / 禁用与打开文件命令补齐权限
- **员工值班预设**：值班时段提供「每天 2 次 / 每天 9:00 / 工作日 / 每 N 小时」等常用预设
- **资产中心画像**：仅用户实体保留「画像」Tab，统一读取单个 USER.md

### 改进

- **用户画像单文件**：`basic-info.md` / `preferences.md` / `persona.md` 自动合并为 `USER.md`，旧数据无需手动迁移
- **资产记忆**：What's in Memory 只列文件名索引，摘要更短更聚焦
- **员工能力**：变更后立即失效提示词缓存，下一轮对话即生效
- **部门群**：花名册规范化、群近期上下文注入、页面重挂回填流式正文
- **创建智能体**：省略默认值时不再强制写全参数

### 修复

- **轮次死锁**：修复轮次追踪嵌套加锁导致的卡死
- **读图工具**：只有像素真正送到模型才标记「已查看」；上下文压缩后自动重挂当前轮图片
- **soul 摘要**：SOUL.md 更新后过期摘要自动回落实时正文
- **工具记录配对**：补齐中断 / 取消留下的缺失结果，减少 Volc「工具记录不完整」报错

### 覆盖安装即可

无数据迁移。从 **1.2.x** 覆盖安装至 **1.3.0**。
