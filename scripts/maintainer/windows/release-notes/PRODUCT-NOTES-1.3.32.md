**EvoFlow v1.3.32 — 打开 Agent 应用不点死、续跑不劈轮、索引打开更快**

本版相对 **1.3.31**：打开无限画布等 Agent 应用不再把客户端点死；历史回填时助手续跑不再劈成两段；打开代码索引明显更快。覆盖安装即可。

---

### 修复

- **打开 Agent 应用客户端点死**：开签前先腾出对话占用的内存；服务未就绪先显示「启动中」，不抢着加载页面；同屏只保留一个 Agent 应用签
- **历史回填续跑劈轮**：重载对话时把无新用户输入的续跑并回上一轮，避免同一轮回复被拆成两段
- **打开代码索引很慢**：读索引状态不再拖入重型模型栈，首次打开从数秒降到约百毫秒级

### 覆盖安装即可

无数据迁移。从 **1.3.31**（或更早 1.3.x）覆盖安装至 **1.3.32**。
