**EvoFlow v1.3.2 — 员工能力边界、资产记忆更省 token、部门群派工更清楚**

本版相对 **1.3.1**：员工可精确配置可用的平台能力；资产记忆注入更省上下文；部门群新增派工状态条；后台任务与知识库稳定性修复（覆盖安装即可）。

### 新增

- **员工平台能力清单**：可给每个员工选择「不设限 / 全量（含风险上限）/ 全部禁用 / 自定义域与动作」，越界调用会被拒绝，模型调用前也会看到能力边界
- **部门群派工条**：群内派工实时显示「排队中 / 回答中 / 已回 / 失败」，重开页面也能回填
- **资产记忆更省 token**：长期记忆注入时自动折叠冗长目录，偏好与提示词也有软上限

### 改进

- **媒体下载**：改为边下边写盘，下载大文件不再卡界面
- **资产工具说明**：写入位置与动作说明收敛到系统提示，减少重复
- **记忆注入文档**：分层说明同步更新

### 修复

- **run 状态**：心跳写入改 upsert，避免并发冲突；状态对账补齐
- **知识库**：分块边界与参数修正
- **后台任务**：等待期间保持 run 存活，不再被误判空闲回收
- **部门群**：嵌套策略与审计回灌细化，重挂后派工条可正确回填

### 覆盖安装即可

无数据迁移。从 **1.3.1**（或更早 1.3.x）覆盖安装至 **1.3.2**。
