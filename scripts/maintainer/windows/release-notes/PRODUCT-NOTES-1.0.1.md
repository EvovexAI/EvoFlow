**EvoFlow v1.0.1 — 体验与稳定性补丁**

在 1.0.0 公开源码可见版本之上，修启动门控与设置交互，并改进 macOS 桌面顶栏体验。

### 本版亮点

- **Gateway 启动门控**：扩展路由加载窗口返回可重试 503，避免面板出现空白「Not Found」
- **设置 · 联网搜索**：首选引擎标签单行显示，下拉样式与其它表单控件对齐
- **macOS 原生标题栏**：系统交通灯 + Overlay 标题栏，各页顶栏为交通灯让位；Windows / Linux 保持原紧凑自绘顶栏
- **侧栏悬停预热**：任务中心 / 工作流 / 智能体 / 自动化等菜单与设置各 Tab 悬停预加载模块与首屏数据，打开更快

### 版本说明

- 桌面端 / 面板 / 后端 / harness 统一 **1.0.1**
- 安装包名：`EvoFlow_1.0.1_x64-setup.exe`（macOS 对应 DMG）

### 升级说明

- 建议从 1.0.0 覆盖安装至 1.0.1
- 模型与 API Key 仍在「设置 → 模型」配置
