**EvoFlow v1.3.55 — 桌面版代码索引 / 本地向量 worker 可启动**

本版相对 **1.3.54**：安装包内网关可正确拉起代码索引与本地嵌入子进程；打包时拒绝把 Git LFS 指针当成模型权重。覆盖安装即可（需装本版安装包后生效）。

---

### 修复

- **冻结 EXE 子进程**：索引构建、本地 BGE 向量 worker 在安装包内用内部 `--mode` 分发，不再因 `gateway.exe -m …` 被拒而静默失败
- **LFS 指针当权重**：打包与运行前识别 `.safetensors` LFS 指针，避免把 100 多字节文本当成模型导致加载失败
- **构建失败可查**：索引 worker 非零退出会打 ERROR 日志，不再完全静默

### 改进

- **本机一键入口**：仓库根增加 `start-evoflow.bat` / `build-windows.bat` 便于本地起后端与打包

### 覆盖安装即可

无数据迁移。从 **1.3.54**（或更早 1.3.x）覆盖安装至 **1.3.55**。已有旧安装包内的索引/向量问题须装本版后才会修好。
