**EvoFlow v1.3.38 — 平台通知不再随发消息重播，对话视口更稳**

本版相对 **1.3.37**：修掉「调用过平台工具后，每次再发消息旧通知又弹一遍」；对话跟底与上滚历史更稳；已装资源包里同一 BOT 不再拆成两行重复计数。界面布局不变。

---

### 修复

- **平台通知重播**：发消息后右上角 toast /「平台」摘要卡不再把历史平台结果当新通知再推一遍；只在真正调用平台工具时提示一次
- **旧工具结果串进当前轮**：平台工具结束事件偶发把上一轮工具卡挂到新用户消息所在轮；现在结果保留原轮次，前端也会丢掉被误归的旧工具卡
- **跟底猛跳 / 卡片叠层**：程序化滚到底与测高中间帧抢吸底时，不再误判成用户上滚而丢跟底；开会话后气泡叠层情况减少
- **「已工作」计时器被复活**：已结束轮次不再因会话仍忙而继续计时

### 改进

- **视口调试异常**：error/warn 锁定显示，不再因 700ms 刷新与时间窗证据滑出而标题栏一闪一闪；可手动「清除锁定」
- **已装资源包计数**：员工与智能体合并为同一 BOT 组（按 id 去重），扩展改称「Agent应用」，避免同一 BOT 显示成两遍

### 覆盖安装即可

无数据迁移。从 **1.3.37**（或更早 1.3.x）覆盖安装至 **1.3.38**。
