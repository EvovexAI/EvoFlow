**EvoFlow v1.3.49 — 应用文件夹、组织包安装、对话贴底与临时错误可重试**

本版相对 **1.3.48**：工作流应用支持文件夹归类；组织包安装更稳；对话时间线贴底与收口空白更少；本机数据库忙或模型临时错误时提示可直接再发。覆盖安装即可。

---

### 新增

- **应用文件夹**：工作流列表可建嵌套文件夹、面包屑导航，应用可移入对应文件夹

### 修复

- **对话贴底**：切会话 / 收口后不再因旧高度水位整屏空白或贴不到底
- **临时内部错误**：模型短暂内部错误、断连时提示可直接再发
- **本机库忙**：水合 / 读会话在数据库锁超时上 soft-fail，不再误报成模型失败
- **观测库回收**：超限时用 VACUUM INTO 回收磁盘，忙时让路稍后重试

### 改进

- **组织包安装**：安装与注册更完整，失败路径更清楚
- **能力页签**：技能 / MCP / 知识库勾选先乐观更新，减少「点了没反应」
- **数据保留**：观测库体积与清理策略更稳妥

### 覆盖安装即可

无数据迁移。从 **1.3.48**（或更早 1.3.x）覆盖安装至 **1.3.49**。
