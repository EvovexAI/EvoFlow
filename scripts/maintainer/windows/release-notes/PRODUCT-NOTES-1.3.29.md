**EvoFlow v1.3.29 — CLI 能力面扩展、平台作用域与子任务时间线**

本版相对 **1.3.28**：命令行可管外观/渠道/媒体/插件/界面与系统自检；平台作用域提示与设置页对齐；对话子任务/工作流在时间线上的投影与角标跟跑状态一致。覆盖安装即可。

---

### 新增

- **CLI 子命令**：`appearance` / `channels` / `media` / `plugins` / `ui` / `extensions` / `verification`，覆盖外观、渠道、媒体、插件、界面与自检
- **工作流 / 任务 CLI**：列表与操作参数补齐，与平台文档一致

### 修复

- **子任务时间线**：会话内子任务/工作流投影与顶栏角标跟当前运行态，避免旧跑次占位
- **平台作用域**：提示与设置页可选范围对齐，减少「能点但不能跑」

### 改进

- **观测查询**：`obs_query` 窗口参数校验，避免空窗/错窗查询
- **系统自检剧本**：全链路场景说明跟 CLI/作用域变更同步

### 覆盖安装即可

无数据迁移。从 **1.3.28**（或更早 1.3.x）覆盖安装至 **1.3.29**。
