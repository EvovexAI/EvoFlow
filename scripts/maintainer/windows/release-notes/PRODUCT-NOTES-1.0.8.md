**EvoFlow v1.0.8 — 启动性能专项优化与浏览器面板**

### 用户可见

- **启动明显变快**：CLI 冷启动移除模块级全量导入（torch / transformers 改为按需），提速约 2.7 秒；桌面端内置后端改为后台线程拉起，窗口创建不再被端口探测阻塞，拉起失败不再终止启动（fail-open）；移除 Google Fonts 外链（首页 + 登录页），WebView 首帧不再等待外部 DNS；构建拆出内容稳定的 vendor-react chunk，二次启动缓存命中率提升
- **字体大小滑块真正起作用了**：869 处硬编码字号迁入 `--ef-text-*` 令牌，设置中的「字体大小」滑块现在能联动全部界面文字
- **内嵌浏览器面板**：右侧舞台新增浏览器标签，可实时查看远程页面、切换标签 / 视口 / 命令（CDP 控制协议）；工具调用统一为扁平时间线卡片，配色 / 间距 / 字号全部接入 EF 设计令牌
- **UI 缩放**：Ctrl + = / - / 0 缩放界面，Ctrl + 滚轮即时调整，设置面板同步开放
- **模型预设**：新增 128K 输出 / 2M 输入上下文模型预设，长文本/大输入场景一键切换
- **知识库角色级自动注入**：每角色可独立配置是否自动注入知识库上下文（auto 模式 + 手动开关）
- **全局助手可调大小**：底部固定的小 V 面板支持拖拽改高度
- **会话列左右留白**：改挂到 scroller，回合导航轨可贴边对齐，正文列宽与中轴保持不变
- **模型选择统一走 resolver**：员工模型优先于默认模型，会话内一键复用

### 修复

- 修复聊天流式拼接时文本丢失与有序列表标记被截断
- 修复企业微信接收图文混合消息的端到端通路，以及回退路径未读最新 DB 真实状态
- 修复模型限流等瞬时不可用标记不自动过期
- 修复 Anthropic 原生模型请求超时参数未映射；未指定 thinking 参数时未跟随模型默认（GLM-5.3 1210）
- 修复桌面端 health 探测应打网关基址而非页面 origin
- 修复工作区视图的会话列表漏掉未绑定会话
- 修复聊天编辑用户消息时图片增删不同步

### 版本与安装

- 桌面端 / 面板 / 后端 / harness 统一 **1.0.8**
- 安装包名：`EvoFlow_1.0.8_x64-setup.exe`（macOS 对应 DMG）

### 升级建议

- 建议从 1.0.7 覆盖安装至 1.0.8
- 本版为性能 + 浏览器面板更新，无数据迁移
