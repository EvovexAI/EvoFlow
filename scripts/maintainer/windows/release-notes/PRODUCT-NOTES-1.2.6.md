**EvoFlow v1.2.6 — 桌面资源管理器与日志导出，语音与工作流更顺**

本版相对 **1.2.5**：新增桌面资源管理器与「导出日志」；日志统一到单一根目录并按日归档（调试轨迹默认不写）；语音唤醒/ASR 与播报体验优化；工作流画布与保存工作流打磨（覆盖安装即可）。

### 新增

- **桌面资源管理器**：独立浮层窗口，用于浏览与管理本地资源
- **导出日志**：系统日志页可一键打包日志，便于排查
- **审计日志**：新增审计日志持久层与接口

### 改进

- **日志**：统一到单一日志根目录、按天命名、保留 14 天；调试轨迹（stream / tool trace 等）改为显式开启才写，导出时自动排除 `debug/`
- **语音**：桌面端唤醒与 ASR 更稳（DashScope / 火山引擎会话）；小V 播报降低机械感；新增语音时延报表（p50/p95/max）
- **工作流画布**：节点、工具条、变量面板与拖拽调色板打磨；保存工作流分组更清晰
- **渠道**：飞书 / 企业微信入站与 trace 日志收敛
- **运行态**：会话运行状态、协作子任务与员工自动化、用量账本等稳定性修补

### 修复

- 聊天粘贴截图不再出现两张相同图片
- 设置中勾选/取消「自定义音色」会正确自动保存
- 恢复公仓更新清单通道（客户端优先 jsDelivr，再回退 raw）

### 覆盖安装即可

无数据迁移。从 **1.2.5**（或更早 1.2.x）覆盖安装至 **1.2.6**。
