**EvoFlow v1.3.43 — 员工面板发消息不再串到任务线、右栏与平台卡更清楚**

本版相对 **1.3.42**：在员工对话面板发消息会落在对话会话并实时流出字，不再误写进旧任务时间线；右栏布局与会话记忆更稳；平台工具卡标题更可读；长对话 catchup / 跟底裁窗更准。覆盖安装即可。

---

### 修复

- **员工面板发消息落错会话**：对话发送拒绝 `:task:` 时间线，改用对话会话；面板直发走 live 流，不再干等整轮
- **客户端重连误停面板轮次**：`client_attach` / 重启默认不再取消正在跑的面板任务
- **长对话 tip 脱节**：投影 tip 与库尾不一致时强制重灌；跟底 soft-cap 后不再把历史灌回全量
- **平台工具卡假标题**：不再用技术串冒充卡头；有作者标题时正常显示
- **右栏代码预览崩溃**：CodeViewer 错误边界，单卡失败不拖垮整栏

### 改进

- **右栏布局**：标签与分栏回流更顺，跨会话记忆更一致
- **员工面板发送桥**：后台触发也能驱动面板自己的发送链路
- **子任务历史**：拉对话必须走网关，避免直连错源

### 覆盖安装即可

无数据迁移。从 **1.3.42**（或更早 1.3.x）覆盖安装至 **1.3.43**。
