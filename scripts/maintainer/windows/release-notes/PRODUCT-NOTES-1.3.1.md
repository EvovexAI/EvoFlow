**EvoFlow v1.3.1 — 图片生成更稳，缩略图渲染修复**

本版相对 **1.3.0**：模型请求体统一清洗，OpenAI 图片支持参考图生成（image2image），图片缩略图与内联图渲染修复。

### 新增

- **参考图生成**：图片模型支持 image2image，可带参考图保持人物/风格
- **生成中占位**：平台媒体生成时展示占位卡片，不再空白等待

### 改进

- **模型请求体**：新增统一清洗层，去掉各 provider 的冗余/非法字段，减少 400 报错
- **工具表面锁**：员工可用工具变更后与主 agent 配置保持一致
- **V4 镜像**：AG-UI 镜像与持久化行映射对齐

### 修复

- **图片渲染**：缩略图与 Markdown 内联图的尺寸、加载与点击预览
- **平台工具卡片**：媒体生成结果的展示与失败提示

### 覆盖安装即可

无数据迁移。从 **1.3.0**（或更早）覆盖安装至 **1.3.1**。
