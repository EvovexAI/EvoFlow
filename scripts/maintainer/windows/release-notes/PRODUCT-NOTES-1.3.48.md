**EvoFlow v1.3.48 — 语音音色与套餐对齐、部门群语音设置、右栏打开来源可追溯**

本版相对 **1.3.47**：阿里云 / 火山语音音色与 Token Plan、Agent Plan 套餐配置对齐；部门群可配置语音相关设置；右栏面板会记录打开来源，便于核对是谁打开的。覆盖安装即可。

---

### 修复

- **阿里云语音音色**：Token Plan 与按量 CosyVoice 音色列表分开，预览与套餐匹配
- **火山 Agent Plan 语音**：套餐落盘时补齐语音相关端点与默认项
- **工作区路径占位**：根路径占位与打开文件更稳
- **右栏打开来源**：记录打开方，减少多处查看时来源不清

### 改进

- **部门群对话**：轮次、值守与成员工作会话衔接更清楚
- **小 V 语音**：提供商与默认音色配置更完整
- **右栏状态上报**：打开来源纳入状态报告

### 覆盖安装即可

无数据迁移。从 **1.3.47**（或更早 1.3.x）覆盖安装至 **1.3.48**。
