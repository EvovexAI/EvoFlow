**EvoFlow v1.0.0 — 首个公开源码可见版本**

面向长任务的原生 Agent Runtime 与控制平面：规划、拆解、执行、恢复与交付，多 Agent 协作全程可观测、可干预。

### 本版亮点

- **Agent Teams**：多 Agent 分工、隔离上下文，支持插手、重试与验收
- **对话 / Plan / Goal**：日常协作；先出可修订计划再执行；长任务后台挂起
- **技能与 MCP**：按需加载技能包，通过连接器扩展外部工具
- **工作流与自动化**：多步骤编排、定时任务，支持飞书 / 微信等 IM 派发
- **知识、沙箱与可观测**：检索与跨会话记忆；隔离执行；任务与用量可见
- **模型配置**：在应用内「设置 → 模型」添加服务商与 API Key
