**EvoFlow v1.2.3 — 任务中心打开更快，聊天不再被列表拖死**

本版相对 **1.2.2**：修任务中心打开慢、聊天与任务列表互相拖死，并加固子代理侧栏（覆盖安装即可）。

### 修复

- **任务中心打开慢**：任务列表不再对每一行做交付物路径磁盘探测，打开目录从数秒回到毫秒级
- **聊天与任务中心互相卡**：会话列表、任务目录、子代理 transcript 分开限流并加超时，一边卡住不会拖死另一边
- **子代理侧栏**：聊天里拉起的子代理落到独立线程，侧栏走 V4 转录；未知类型按 agent 处理，停止时与主对话一并结束

### 覆盖安装即可

无数据迁移。从 **1.2.2** 覆盖安装至 **1.2.3**。
