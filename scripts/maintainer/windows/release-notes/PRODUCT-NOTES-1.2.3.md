**EvoFlow v1.2.3 — 飞书图片可通，聊天与任务中心不再互相拖死**

本版相对 **1.2.2**：修渠道图片收发与聊天发送卡顿，任务中心/侧栏不再拖死对话，子代理侧栏与停止行为对齐，工作流换成稳定 SVG 图标（覆盖安装即可）。

### 修复

- **飞书 / 渠道图片**：入站附件可被模型看图；出站消息正确带图/带文件并上传；减少飞书首提自介刷屏与小米重复自我介绍
- **聊天发送更跟手**：发送后更快上屏；V4 会话不再被慢的旧版历史回拉抢走，避免一点发送整页发僵
- **任务中心打开慢**：任务列表不再对每一行做交付物路径磁盘探测
- **聊天与任务中心互相卡**：Gateway 分车道隔离；会话列表、任务目录、子代理 transcript 分开限流并加超时
- **子代理**：未知类型按内置 agent 跑；停主对话时一并停后台子代理；聊天子代理走独立线程，右侧 V4 转录正常显示

### 改进

- **工作流图标**：列表 / 运行 / 画布统一 SVG 磁贴（按名称派生），不再用 emoji
- **智能体员工与资产中心**：值班切换与员工页更紧凑；预览换行等界面修补

### 覆盖安装即可

无数据迁移。从 **1.2.2** 覆盖安装至 **1.2.3**。
