**EvoFlow v1.3.14 — Codex 订阅可拉模型，工作流暂停不再被冲掉，会话旁任务一点即开**

本版相对 **1.3.13**：ChatGPT / Codex 订阅登录后可在模型页拉取可用模型；工作流「暂停」不会再被进度同步悄悄改回执行中；会话旁运行中图标点击直接打开对应详情。覆盖安装即可。

---

### 新增

- **Codex 订阅模型列表**：已登录 Codex / ChatGPT 订阅时，模型页可拉取远程模型目录写入连接（含内置候选与上下文窗口），无需再填 API Key

### 改进

- **会话旁运行图标**：子代理 / 工作流 / BOT / 终端等图标点击直接打开最新一条详情，不再先落到「运行中」汇总列表
- **对话轮尾截图**：多张浏览器截图改为横排优先，一行放不下再换行，避免每张独占一行
- **文案统一**：用量统计、值班与会话旁轨等处「员工」统一为「BOT」

### 修复

- **工作流暂停被冲掉**：用户暂停后，晚到的子任务进度汇总不再把主任务状态改回「执行中」，暂停会一直保持到手动恢复
- **超长附件路径**：Windows 上路径过长时对话回放不再因 `ValueError` 中断

### 覆盖安装即可

无数据迁移。从 **1.3.13**（或更早 1.3.x）覆盖安装至 **1.3.14**。
