**EvoFlow v1.3.22 — 技能列表跟得上，侧栏任务状态更准**

本版相对 **1.3.21**：员工面板「添加技能」不再用启动时的旧快照，新装技能刷新就能看到；侧栏任务在对话已跑起来时按「执行中」显示，执行者显示中文名。覆盖安装即可。

---

### 新增

- **添加技能 · 含已停用**：弹窗可勾选列出已停用技能，并打「已停用」标签，方便排查「装了却看不到」

### 改进

- **技能列表**：打开「添加」时按当前真实清单重拉；目录缓存约 30 秒过期；底部提示「共 N 项，先显示前 40 项」
- **侧栏当前任务**：会话正在跑时，仍标 pending 的聚焦任务按执行中展示；执行者 / 提起人尽量显示中文名，少露英文 code

### 覆盖安装即可

无数据迁移。从 **1.3.21**（或更早 1.3.x）覆盖安装至 **1.3.22**。
