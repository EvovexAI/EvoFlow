**EvoFlow v1.1.3 — 安装包真实官方插件（空市场修复）/ 工具审批完全访问 / 多图查看与联网搜索 / 会话与员工 UI**

本版覆盖自 **1.1.2** 以来合并进主线的全部用户可感知变更。

### 新增

- **工具审批「完全访问」**：需要权限时可一键完全访问；可勾选「新对话默认完全访问」
- **一次查看多张图**：`view_image` 支持多路径 / 多 URL，工具卡片展示更清楚
- **联网搜索增强**：设置里可配置搜索门控；百度搜索能力加强；配置可热重载
- **任务权限与启动**：智能体任务 ACL；任务启动更快
- **侧栏会话标题**：过长标题右侧渐隐，鼠标悬停走马灯滚动
- **文档**：任务中心、自动化、Agent 应用等说明与指南交叉链接补齐

### 变更

- **官方插件打进安装包**：仓库内提交真实插件压缩包，发版直接解压打包；不再用空壳 stub（否则市场一片空白）
- **新建自定义智能体**：默认不预挂技能白名单，与工具配置习惯一致
- **预设角色技能**：并入平台管理技能包，独立预设角色技能下线
- **员工区交互**：下拉与花名册同步更稳；员工会话筛选只跟你手动选的筛选，不再跟着当前会话乱跳

### 修复

- **别人装完插件市场是空的、浏览器/电脑控制用不了**：根因是发版打了占位 stub；本版打入真实插件并禁止 stub 过关
- **工具审批体验**：折叠时不再只剩审批卡；「默认完全访问」会真正作用到当前对话；审批后续流时停止与设置齿轮状态一致
- **知识库回复**：相关片段紧挨用户消息展示；历史消息重复 key 问题修复
- **停止按钮**：补充停止诊断日志，方便定位停不干净的情况

### 覆盖安装即可

无数据迁移。从 **1.1.2** 覆盖安装至 **1.1.3**。若你正在用插件市场为空的安装包，升级本版后重启即可看到官方插件。
