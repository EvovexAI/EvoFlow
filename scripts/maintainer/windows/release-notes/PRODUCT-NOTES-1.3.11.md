**EvoFlow v1.3.11 — 用量按模块看得清，高分屏浏览器面板不再错位**

本版相对 **1.3.10**：设置里的「应用用量」新增**按模块**视图，能直接看出对话、员工、工作流、知识库、媒体各花了多少 token，不再只有一堆调用类型；可观测分析补上了提示词开销的统计；修复了高分屏（缩放 125%/150%）下浏览器面板位置算错、以及右侧栏折起来时「操作都正常但浏览器就是看不见」的问题。（覆盖安装即可）

### 新增

- **用量按模块拆分**：设置 → 使用统计新增「按模块」视图，按对话 / 员工 / 工作流 / 知识库 / 媒体归类展示，支持模块筛选、关键字搜索、区间合计
- **提示词开销可见**：分析页展示主智能体与子智能体的提示词开销占比，长会话膨胀的原因一眼可查

### 修复

- **高分屏浏览器面板**：按窗口实际缩放换算位置并限制在窗口内，修复 125%/150% 缩放下面板跑到屏幕外、和窗口内容错开
- **浏览器面板不显示**：需要展示浏览器时强制撑开右侧栏，修复 agent 建窗后窗口被「停放」导致界面看起来没反应；点「新标签」也保证侧栏可见
- **模块明细读不到时**：给出明确提示（重启桌面端后再打开「应用用量」），不再静默空白

### 覆盖安装即可

无数据迁移。从 **1.3.10**（或更早 1.3.x）覆盖安装至 **1.3.11**。
