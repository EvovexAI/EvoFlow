**EvoFlow v1.3.35 — 资源包带上 MCP、上拉历史不被冲掉**

本版相对 **1.3.34**：打包分享会自动带上 Agent 绑定的 MCP 配置；上拉加载的更早对话在尾窗刷新后仍保留。覆盖安装即可。

---

### 新增

- **资源包导出 MCP**：打包分享时按 Agent 绑定自动导出本机 MCP 定义；对方装完可直接用，不再只剩名字

### 修复

- **上拉历史被冲掉**：尾窗快照刷新时保留已加载的更早行，滚到顶不再像历史丢了
- **用户气泡被裁掉**：确保 transcript 时复用已有轮次头，尾窗对齐不再裁掉紧前用户气泡

### 改进

- **资源中心**：已装/我的资源与市场页交互与说明更齐；本机市场与目录刷新互不堵

### 覆盖安装即可

无数据迁移。从 **1.3.34**（或更早 1.3.x）覆盖安装至 **1.3.35**。
