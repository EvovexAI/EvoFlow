**EvoFlow v1.3.17 — 侧栏会话标清触发方式，粘贴图片也能给模型可编辑路径**

本版相对 **1.3.16**：侧栏仍分任务 / BOT / 部门三栏，每条会话多了「对话 / 渠道 / 定时 / 任务 / 部门」标签，标题不再叠员工名或渠道长前缀；聊天粘贴或上传的图片会落到会话 uploads，生图改图能直接引用本地路径。覆盖安装即可。

---

### 新增

- **会话触发标签**：侧栏每条会话旁显示触发方式（对话 / 渠道 / 定时 / 任务 / 部门），一眼分清从哪来

### 改进

- **侧栏标题更短**：任务 / BOT / 部门三栏保留；标题不再重复拼接员工名或「飞书 · 谁 · id」长串
- **粘贴图片可引用路径**：图片与文档一样写入会话 uploads；剪贴板粘贴也能落盘，生图 / 改图可按 Path 引用
- **本地工作区上传提示**：非虚拟工作区时上传文件提示用本机绝对路径，方便工具直接打开

### 修复

- **媒体引用 uploads**：`uploads/` 与 `/mnt/user-data/uploads/…` 能解析到会话旁 uploads 目录，避免模型「找不到刚贴的图」

### 覆盖安装即可

无数据迁移。从 **1.3.16**（或更早 1.3.x）覆盖安装至 **1.3.17**。
