**EvoFlow v1.3.20 — 对话里能跟工作流进度，右栏可开交互终端，部门群跟岗更清楚**

本版相对 **1.3.19**：对话时间线可展开工作流节点进度；右栏可打开工作区交互终端；部门群 @ 唤醒立刻有「正在回复」态，过程面板可复制；知识库失败任务可忽略清理；飞书 / 企微错误配置不再死循环刷错。覆盖安装即可。

---

### 新增

- **工作流进度卡**：对话里跑工作流时，可展开节点进度与摘要，不必只盯侧栏运行图
- **交互终端**：右栏可打开工作区终端（连本机 PTY），方便边聊边敲命令
- **`/workflow` 指令**：输入框斜杠命令可带工作流名称发出（无参数会提示先写名称）

### 改进

- **部门群跟岗**：@ 入队后立刻显示正在回复；过程面板忙闲跟真实投影走，顶栏可复制对话
- **IM 会话归组**：飞书 / 企微等渠道会话更稳地归到对应 BOT 侧栏，不因旧 key 漂到别处
- **知识库失败任务**：索引失败可忽略清理；永久失败的孤儿任务可批量清掉，不再占健康度

### 修复

- **飞书 / 企微凭证错误刷屏**：应用配置或密钥永久无效时停止重连死循环，等用户改好再连
- **任务通知不进对话时间线**：部分任务类通知不再误插到 V4 对话投影里干扰阅读

### 覆盖安装即可

无数据迁移。从 **1.3.19**（或更早 1.3.x）覆盖安装至 **1.3.20**。
