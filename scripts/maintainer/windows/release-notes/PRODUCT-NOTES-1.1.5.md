**EvoFlow v1.1.5 — 内嵌浏览器软解耦 / 子代理流式侧栏 / 文件审查与媒体内联 / 切会话闪烁修复**

本版覆盖自 **1.1.4** 以来实际合入的用户可感知变更（前后端同一版本号 **1.1.5**）。

### 新增

- **子代理流式输出侧栏**：子任务工具卡可点「查看流式输出」，右侧面板轮询全量 transcript；执行中贴底跟读，终态停轮
- **工具卡内联媒体**：图片 / 视频 / 音频产物在工具卡内直接预览（大文件走 serve-file Range，不撑内存）
- **内嵌浏览器软解耦**：宿主持有浏览器窗口；右侧面板只管显示与用户 chrome，减少多会话抢主控冲突；引擎与 CDP 链路加固

### 变更

- **文件变更「审查 / 打开」**：打开可拉真实文件并按扩展名高亮；审查 diff 整行红绿底色与行内对比同源同款
- **Markdown / 表格**：流式正文表格与样式微调

### 修复

- **切换会话先闪旧样式 / 整树抖动**：V4 回落条件收紧；网关冷启动预热 hydration，首订不再双快照重挂
- **浏览器嵌入 / CDP / 桥接**：导航、视口与统一日志更稳
- **技能 / 知识库注入位置**：注入内容紧跟用户消息
- **Node REPL / 读文件 / 看图**：插件运行与多图查看路径更可靠

### 覆盖安装即可

无数据迁移。从 **1.1.4** 覆盖安装至 **1.1.5**。
