# Product release notes (this version only)

CI / `release-evopanel-public` require:

`PRODUCT-NOTES-x.y.z.md`

matching `evopanel/package.json` `version` (e.g. `PRODUCT-NOTES-1.0.0.md`).

Public source-available line starts at **1.0.0**. Historical `0.x` notes live under private-docs:

`$EVOFLOW_PRIVATE_DOCS/scripts/release-notes-history/`

Copy the latest private note as a template when cutting a new version; do not accumulate old notes in this folder.
