**EvoFlow v1.1.9 — 语音与唤醒扩展 / 媒体用量记账 / OpenAI 兼容网关 / MCP 绑定重构 / 界面与稳定性修复**

本版覆盖自 **1.1.8** 以来实际合入的用户可感知变更。

### 新增

- **DashScope 语音**：接入 DashScope ASR/TTS 语音会话与音色选择，媒体设置页可直接选音色，语音管线与媒体设置对齐
- **唤醒词 KWS**：唤醒词识别原生 sidecar（sherpa-onnx）接入，配套 Tauri 命令与权限接线，语音唤醒更稳
- **OpenAI 兼容网关**：新增 OpenAI 兼容 chat/completions 网关与 CLI `openai` 命令，内部模型可被 OpenAI 客户端直接调用
- **Computer Use 屏边蓝光**：屏幕计算机使用运行时显示屏边蓝光提示，随时可见执行状态
- **转交审核通知**：全局轮询转交审核，左下角芯片 / 侧栏角标 / 桌面通知三处提醒，不依赖打开员工页
- **任务运行时健康度**：服务端标注 live / interrupted / idle，任务中心与详情页据此展示当前执行状态
- **媒体用量记账**：媒体生成接入用量账本，用量与元信息设置页集中查看

### 变更

- **MCP 工具绑定重构**：工具白名单按角色 mcp_servers 绑定保留，会话级工具名缓存与图重建同步 tools/all_tools；移除 MCP 系统提示词注入，MCP 工具降为普通 function 工具，绑定更符合预期
- **组织与协作**：组织名册 / 协作规则拆分为独立提示块，新增雇佣通知与上游回执系统唤醒，飞书回执按角色账号路由，组织名册接入右侧栏
- **UI 扩展外壳页**：导航并入全局顶栏 chrome，顶栏感应带加宽与收起防抖，样式统一收敛
- **界面统一**：toast 定位模型统一为 center + anchor，员工雇佣 / 主动运营界面改版与主题样式统一
- **会话列表**：首屏只预拉当前目录与少量已展开组，避免抢占 app-server 管道，进聊天更快

### 修复

- 编排长跑渲染进程 OOM：封顶会话 rows 与流式缓冲；dev 环境清理 React 19.2 渲染追踪撑爆 User Timing 缓冲
- 浏览器冷启动空白页：冷启动停在空白页时自动加固
- 网关日志 500：兼容 Title-Case 响应头，/runs/stream 记日志不再 KeyError
- 工作区历史删除：按归一化路径匹配，同步会话缓存与本地镜像
- 自动化 /roles 性能：列表改走 load_agent_config 免 soul 物化，cron 运行记录显示名解析统一
- 聊天空草稿闪跳：空草稿会话加载中即居中，消除贴底转居中闪跳
- 自托管知识库：默认关闭摘要，jobs / schema / service 与阅读页对齐

### 覆盖安装即可

无数据迁移。从 **1.1.8** 覆盖安装至 **1.1.9**。
