**EvoFlow v1.1.4 — 对话显示切到新流式时间线 / 侧栏运行时长 / 多会话卡死与正文丢失修复 / 主动员工搜索**

本版覆盖自 **1.1.3** 以来实际合入的用户可感知变更（含默认开启的对话显示新链路）。

### 新增

- **对话显示新流式时间线（默认开启）**：正文流式、工具卡排布、贴底滚动与虚拟列表走新协议投影；历史会话打开会补齐轮次、工具结果与文件变更。可用 `?chatV4=0` 或关闭开关退回旧面板
- **轮尾「文件已更改」与可点 diff**：同轮写类工具汇总为文件变更卡；Edit/Write 展开可看补丁；点文件名可打开右侧预览
- **交付物卡片**：助手用 Markdown 链接 / 路径写出的产物会出预览卡（需新一轮对话吃到更新后的提示词）
- **侧栏运行时长**：执行中右侧只显示已运行多久（如「1分05秒」），不再刷工具活动文案
- **主动员工 Tab 搜索**：员工页 Tab 可搜；导航条与聊天/知识库样式微调

### 变更

- **模型输出上限**：面板里显式设的上限会真正生效；新建 OpenAI 兼容渠道默认 32K，减少上游拒答
- **插件 / 浏览器日志位置**：统一进 `logs/`（如 `plugin-control.log`），旧文件名启动时自动迁走

### 修复

- **开两个会话会卡住**：安装包 Gateway 上注入接口没正确等待，连爆错误拖垮整机，另一边对话像死了一样
- **流式时正文不出来 / 结束后空转**：文本增量没挂上；结束后短暂空白「生成中」或忙碌卡住约十几秒
- **多会话忙碌状态乱跳**：一边还在流式，列表刷新却把忙碌清掉
- **停止亮着但齿轮不转（或审批后续流丢齿轮）**：左下角齿轮与右下角停止共用同一忙碌判定
- **知识库没向量就搜不到**：无向量时仍可按关键词搜；内置用户指南打包路径修好
- **打包后浏览器桥连错端口**：子进程与桥统一走真实 Gateway 地址，不再去探已经死掉的默认口

### 覆盖安装即可

无数据迁移。从 **1.1.3** 覆盖安装至 **1.1.4**。若要临时退回旧对话面板：地址栏加 `?chatV4=0`，或把 `localStorage.evoflow_chat_v4` 设为 `0`。
