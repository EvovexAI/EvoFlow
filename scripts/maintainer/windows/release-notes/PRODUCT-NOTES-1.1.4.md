**EvoFlow v1.1.4 — 对话新流式时间线 / 授权与平台工具恢复 / 侧栏运行时长 / 小V 同款面板 / 多会话与滚动修复**

本版覆盖自 **1.1.3** 以来实际合入的用户可感知变更（前后端同一版本号 **1.1.4**）。

### 新增

- **对话显示新流式时间线（默认开启）**：正文流式、工具卡排布、贴底滚动与虚拟列表走新协议投影；历史会话打开会补齐轮次、工具结果与文件变更。可用 `?chatV4=0` 或关闭开关退回旧面板
- **轮尾「文件已更改」与可点 diff**：同轮写类工具汇总为文件变更卡；Edit/Write 展开可看补丁；点文件名可打开右侧预览
- **交付物卡片**：助手用 Markdown 链接 / 路径写出的产物会出预览卡（需新一轮对话吃到更新后的提示词）
- **授权弹窗恢复**：待审批工具以底部悬浮卡弹出（标题 / 工具名 / 摘要 / 风险 + 批准 / 拒绝 / 全部批准），批准后结果照常回流
- **侧栏运行时长**：执行中右侧只显示已运行多久（如「1分05秒」），不再刷工具活动文案
- **小V 对话区升级**：全局助手「小V」改用与主对话同款的新流式面板；窄侧栏下也能看到左侧轮次导航条
- **主动员工 Tab 搜索**：员工页 Tab 可搜；导航条与聊天/知识库样式微调

### 变更

- **表格渲染**：仅新面板内表格恢复 MD/CSV 复制 + 放大对话框 + 滚轮缩放
- **平台工具交互**：显示闸门只拦文件写类工具的重参数流，右侧面板配置 / 交互参数放行
- **小V 输入区**：发送 / 停止钮原地切换、贴底由面板自管，发消息时整栏不再抖动
- **模型输出上限**：面板里显式设的上限会真正生效；新建 OpenAI 兼容渠道默认 32K
- **插件 / 浏览器日志位置**：统一进 `logs/`（如 `plugin-control.log`），旧文件名启动时自动迁走

### 修复

- **开两个会话会卡住**：安装包 Gateway 上注入接口没正确等待，连爆错误拖垮整机
- **流式时正文不出来 / 结束后空转**：文本增量没挂上；结束后短暂空白「生成中」或忙碌卡住约十几秒
- **多会话忙碌状态乱跳**：一边还在流式，列表刷新却把忙碌清掉
- **停止亮着但齿轮不转（或审批后续流丢齿轮）**：左下角齿轮与右下角停止共用同一忙碌判定
- **授权弹窗消失**：上游状态误标导致面板不弹授权；已归一化
- **平台工具交互整块没了**：工具参数被一律拦下；闸门收窄后恢复
- **Edit / Write 工具卡**：补齐解析后的参数对象，文件 chip 可点开右侧预览
- **上滚停住后被拽回底部**：关闭滚动端口的浏览器滚动锚定
- **知识库没向量就搜不到**：无向量时仍可按关键词搜；内置用户指南打包路径修好
- **打包后浏览器桥连错端口**：子进程与桥统一走真实 Gateway 地址

### 覆盖安装即可

无数据迁移。从 **1.1.3** 覆盖安装至 **1.1.4**。临时退回旧对话面板：地址栏加 `?chatV4=0`，或把 `localStorage.evoflow_chat_v4` 设为 `0`。
