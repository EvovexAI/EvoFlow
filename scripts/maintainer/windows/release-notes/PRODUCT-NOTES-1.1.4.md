**EvoFlow v1.1.4 — 多会话卡死与流式正文修复 / 侧栏运行时长 / 主动员工 Tab 搜索 / 输出上限与知识库关键词检索 / 打包 Gateway URL**

本版覆盖自 **1.1.3** 以来合并进主线的全部用户可感知变更。

### 新增

- **侧栏运行时长**：会话执行中右侧显示已运行时长（如 `1分05秒`），不再刷工具活动文案
- **主动员工 Tab 搜索与导航条**：员工页 Tab 可搜索；导航条样式与聊天/知识库微调对齐

### 变更

- **统一插件控制日志**：`插件控制日志.log` → `logs/plugin-control.log`；`browser-cdp-bridge.log` 一并迁入 `logs/`；启动时自动迁移旧文件
- **多会话诊断日志**：`logs/subtask-stream.trace.log` 增加 `[multi-session]` 行；启动横幅与错误同步镜像到 `logs/plugin-control.log`
- **模型输出上限**：尊重面板显式设置的输出上限；OpenAI 兼容渠道新建默认 32K，降低上游拒答

### 修复

- **多会话卡死**：安装包 Gateway 上 `inject-custom` 未 await 异步适配器连爆 500，拖垮事件循环导致另一对话像被阻塞
- **流式正文丢失 / 结束后空转**：对话 WebSocket 文本增量未应用；SSE 结束后短暂空白生成态或忙碌约 15 秒
- **多会话 busy 误清**：live POST 仍开时保留回合 busy；列表刷新不再在流式未结束时误判空闲
- **左下角齿轮与停止按钮**：共用同一判定（停止亮则齿轮转；无折叠头时也渲染齿轮；审批续流把齿轮挂回工具气泡）
- **知识库**：无向量时仍可按关键词检索；内置用户指南 seed / 打包路径修复
- **打包 Gateway URL**：拆分进程与浏览器桥统一解析 Gateway 基址，避免探测死掉的 `:8070`

### 覆盖安装即可

无数据迁移。从 **1.1.3** 覆盖安装至 **1.1.4**。
