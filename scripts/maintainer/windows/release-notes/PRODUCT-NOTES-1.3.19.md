**EvoFlow v1.3.19 — 多会话切换不再空白，回合结束齿轮收干净，知识库向量失败仍可搜**

本版相对 **1.3.18**：来回切会话更快、历史能立刻出来；回合结束后画布不再空转；排队续发不再误标「用户停止」；知识库向量挂了仍可关键词检索；覆盖安装会主动关掉仍在跑的桌面/Gateway。覆盖安装即可。

---

### 新增

- **BOT 分组拖拽排序**：侧栏员工 Tab 可按花名册编制序排列，本机拖拽后记住顺序；未雇佣的会话组沉底

### 改进

- **覆盖安装更主动**：若桌面或 Gateway 仍在运行，安装/卸载前会提示并由安装程序关闭（静默 / 被动安装跳过弹窗直接关闭）
- **知识库向量降级**：向量失败或硬错误时仍可关键词检索；库设置可关「启用语义向量」；健康度按可检索计，语义降级单独提示
- **忙闲对齐**：停止键与对话齿轮跟「还有没有活」走——工具卡 / 流式正文 / 后台 bash 未收口时仍可停；侧栏已闲时不再被陈旧 running 卡钉死

### 修复

- **多会话切换空白**：切会话遮罩尽快放开；正在跑或刚切过的会话钉住投影，切回直接出历史；目标已有快照时不再盖「加载中」
- **结束后画布仍转圈**：RUN 结束后先封未收口工具与流式正文，齿轮与侧栏 idle 一致
- **排队续发误标「用户停止」**：回合中追加的消息在上一轮结束后自动发送时，不再把刚完成的一轮标成用户停止
- **网关重启后发消息历史消失**：LangGraph 线程 404 自动重建时，先把已有对话灌回新线程投影

### 覆盖安装即可

无数据迁移。从 **1.3.18**（或更早 1.3.x）覆盖安装至 **1.3.19**。
