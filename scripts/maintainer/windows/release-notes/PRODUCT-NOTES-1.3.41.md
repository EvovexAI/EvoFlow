**EvoFlow v1.3.41 — 离线知识库开箱可用、长对话更省内存、右栏切换更稳**

本版相对 **1.3.40**：安装包自带本地向量模型，知识库与代码索引不用再联网拉权重；长对话时间线复用相同内容、裁窗更稳，内存不易越聊越涨；右栏关闭/移动与会话记忆更顺；主窗口面板可导出可见对话摘要。覆盖安装即可。

---

### 新增

- **离线知识库 / 代码索引**：安装包内置本地中文向量模型，首次使用不必再下载
- **主窗口对话摘要导出**：面板通道可导出当前可见轮次文本（兼容旧安装包回退）

### 修复

- **长对话越聊越卡**：相同消息内容在界面层复用，工具长文本不再在内存里堆很多份
- **直播轮 / 裁窗抖动**：投影窗口与轮导航更稳，尾部直播不易被裁没或撑爆
- **右栏关签 / 挪签**：关闭与移动标签行为更一致，切换会话后侧栏记忆更准
- **本地打包编译失败**：主窗口 page-dump 回退脚本的 Unicode 写法已修正

### 改进

- **会话冷启动补齐**：网关重启后尽量补回未落库的尾部对话状态
- **右栏状态上报**：当前签与收起/展开语义更清晰，减少误抢焦点
- **日志噪音**：面板轮询与限流日志更干净，排障时更好找关键错误

### 覆盖安装即可

无数据迁移。从 **1.3.40**（或更早 1.3.x）覆盖安装至 **1.3.41**。
