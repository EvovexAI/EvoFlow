**EvoFlow v1.3.10 — 目标模式收口更准、工作流发布有校验、部门头像可选宫格**

本版相对 **1.3.9**：会话目标模式（ZCode 式）的指令与停止语义落地，模型配额耗尽 / 上游异常不再被误记成「这一轮跑成功了」；工作流增加发布前校验，写错依赖或条件节点的草稿会被拦住而不是悄悄变成即刻可跑的入口；部门与员工头像支持点击展开预设宫格并上传自定义图；知识库检索命中的 docId 可直接读，不再需要二次查询。（覆盖安装即可）

### 参与本次发版

- 全栈开发工程师：目标模式收口与失败判定、工作流发布校验与条件节点检查、部门头像预设宫格、知识库 docId 归一化、员工资产读写一致性、会话切换诊断日志
- 发版工程师：CI/CD 正式包发布

### 新增

- **会话目标模式**：Composer 下方「目标」药丸下达长程目标，可自行规划执行；运行中可补充指令、随时停止
- **工作流节点实时活动**：节点跑动时显示实时活动状态，点击可查看子智能体详情浮层
- **头像预设宫格**：点击部门 / 员工头像直接展开预设选择，支持上传自定义头像
- **图片附件一致化**：实时流中提取用户图片附件，历史回放通道与实时通道看到的附件一致

### 改进

- **应用冷启动**：改为短轮询，打开部门应用不再长时间白屏等待
- **记忆开关下沉**：长期记忆的读写开关可按单个员工独立设置，不再只有全局一档
- **会话切换可诊断**：切会话、消息顺序错乱、打开空白三类现场会写一行诊断日志（遮罩持有时长、尾部行序、渲染层绑定状态），便于定位

### 修复

- **目标模式失败判定**：模型 429 配额 / 上游异常（`model_error`、合成的 `RUN_ERROR` 帧）现在会被正确识别为运行失败，保持 active 等重试，不再误当成功跳过校验
- **工作流发布校验**：依赖指向不存在的节点时不再被静默清空（清空会让该节点变成即刻可跑的入口点）；新增条件节点完整性检查——缺表达式、缺分支目标、分支指向不存在的节点一律拒绝发布，并提示确定性判断请改用 template 节点
- **工作流运行状态**：状态返回体去重、参数按声明传值、读路径改走只读连接池
- **知识库检索**：`search` 命中的 docId 归一化后可直接 `read`；关键词库不再误报 degraded
- **员工资产**：消除读写分叉，修复多词检索空结果与静默丢元数据；`rename` 会同步 memory 笔记的标题与摘要
- **右栏折叠**：点名员工 / 打开 shell 时强制展开右栏，不再被折叠锁拦住
- **会话失效**：stale thread 给出重建提示，切换中不再误响应旧会话
- **组织导入导出**：`autonomy_level` 按枚举值序列化，导入兼容历史 repr 写法

### 覆盖安装即可

无数据迁移。从 **1.3.9**（或更早 1.3.x）覆盖安装至 **1.3.10**。
