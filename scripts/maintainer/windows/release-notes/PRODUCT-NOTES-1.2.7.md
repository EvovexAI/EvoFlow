**EvoFlow v1.2.7 — 部门群聊协作与首页指挥台，设置更清晰**

本版相对 **1.2.6**：新增部门群聊协作（群管家小V、@ 点名唤醒、@ 接力与消息落库）；首页新增组织指挥台与全屏总览；启动更简洁；设置中心收纳「技能 / 连接器」，能力配置统一到员工编辑（覆盖安装即可）。

### 新增

- **部门群聊**：首页「组织指挥台」查看各部门实时状态，进入部门群聊 @ 点名派活；群管家小V 常驻名单并默认接话，成员间 @ 接力自动推进；消息按气泡落库，切走再回来不丢
- **启动与总览**：启动页更简洁，新增中枢控制台动画；首页总览支持全屏影院，部门卡片可浮出信息卡直达群聊
- **设置更集中**：技能安装、MCP 连接器并入设置「数据与资源」；给员工勾选内置工具 / MCP / 技能统一到员工编辑
- **小V 形象**：新增敲键盘坐姿、聆听手扶耳动作

### 改进

- **值班**：本轮值班开场改为一条系统节拍，不再出现重复的长简报气泡；同一时段重复正文自动去重
- **工作区与加载**：工作流每步使用固定工作目录；页面加载区分模块与渲染阶段，慢加载提示更准确
- **入口精简**：侧栏与移动端移除「智能体」入口（仍可用 `#/agents` 直达）
- **语音**：唤醒词引擎未启动时只在日志记录，不再弹窗打断

### 修复

- 小V 宠物在思考时不再来回摇摆，答话动作与立绘缩放更稳定
- 交接审批可总开关关闭（默认仍保留人工确认）

### 覆盖安装即可

无数据迁移。从 **1.2.6**（或更早 1.2.x）覆盖安装至 **1.2.7**。
