**EvoFlow v1.3.28 — 微信多账号绑定、员工任务终态收口与长对话内存治理**

本版相对 **1.3.27**：一个微信渠道可绑多个账号并按账号独立收发；协作拆出的员工任务不再停在「运行中」；长对话不再把渲染进程撑到 Out of Memory；命令在 PowerShell 下不再被当成 bash 方言执行。覆盖安装即可。

---

### 新增

- **微信 iLink 多账号绑定**：同一微信渠道可绑定多个账号，按账号维度隔离会话槽位与收发链路，解绑单个账号不影响其余账号
- **员工任务终态收口**：后台对账器兜底回收异常退出的运行中任务，协作看板上的子任务状态不再长期挂蓝
- **子任务运行中角标**：顶栏显示当前会话正在跑的子任务 / 工作流数量
- **助手轮次用量**：对话行展示本轮用量标签
- **渲染内存水位探针**：采集 WebView 内存压力并落盘，用于定位长对话卡顿

### 修复

- **任务通知续写**：去重与批量投递落库；唤醒输入写入 SSOT 后再跑；防误读前缀改到提供层，会话正文保持干净
- **子任务完成后唤醒派发会话**：协作拆出的子任务结束后唤醒原对话
- **唤醒轮次 400**：可配置上下文与派发诚实性校验，避免空跑/误报
- **404 remint**：会话路径失效时检测、改写路径并回环重派，真正续上
- **唤醒 503**：就绪判据补探受访问闸门保护的端点，自验证闭环不再因误判未就绪而中断
- **会话模型覆盖**：选中的模型写入会话，不再切回默认
- **整页空白（React #185）**：V4 busy 同步改出 layout 阶段，停止按钮与对话忙碌态不再互锁刷屏
- **历史对话顺序错乱**：hydration 时间戳改为单调对齐，镜像用量补齐盖章，重载后消息不再串位或丢失本轮用量
- **bash 命令在 PowerShell 下执行异常**：按终端方言路由执行，不再把 bash 语法直接丢给 PowerShell
- **重复探索守卫误拦**：不同 SQL / uv run 参数不再被塌成同一指纹而误判为重复调用
- **岗位改名后自诊断查不到数据**：按新旧岗位码并集查询

### 改进

- **数据保留**：vacuum 增加占用让路守卫，避免与写入争抢时误清
- **live-run 快照**：同线程单飞，减少重复探针
- **多轮对话防 WebView Out of Memory**：投影窗口按渲染内存水位自适应裁顶；旧工具卡瘦身；高压时收缩后台 pin / 清 keep-warm，多轮仍可继续聊，不靠禁止多轮
- **会话列表**：员工分组排序与孤儿会话剪枝联动，删除后的残留分组不再空挂

### 覆盖安装即可

无数据迁移。从 **1.3.27**（或更早 1.3.x）覆盖安装至 **1.3.28**。
