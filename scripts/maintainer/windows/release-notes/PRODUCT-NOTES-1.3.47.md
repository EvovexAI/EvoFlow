**EvoFlow v1.3.47 — 主窗口内存不足可自动恢复、员工面板排队发送更稳、创建角色可自动入职**

本版相对 **1.3.46**：主窗口因内存不足崩溃时，可在冷却窗口内自动刷新一次；员工对话面板在上一轮还在发送时会暂存排队消息，发送成功后再清；创建 Agent 时可按流程自动入职。覆盖安装即可。

---

### 新增

- **主窗口 OOM 自动恢复**：渲染进程因内存不足退出时，宿主自动 Reload 一次（30 分钟内最多一次，避免连环刷新打断任务）

### 修复

- **员工面板排队发送**：面板忙碌时先保留待发内容，空闲后再发；失败时不清空，便于重试
- **创建 Agent 入职**：创建流程可自动完成入职绑定
- **长对话裁窗与滚动**：投影窗口与跟底裁剪更稳定
- **代码索引损坏处理**：坏库自愈与错误提示路径补充测试覆盖

### 改进

- **平台操作反馈**：动作标签与结果提示更清楚
- **评测场景**：跨模块 / 员工生命周期等场景与现网契约对齐

### 覆盖安装即可

无数据迁移。从 **1.3.46**（或更早 1.3.x）覆盖安装至 **1.3.47**。
