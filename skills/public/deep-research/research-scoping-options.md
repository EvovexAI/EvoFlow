# 阶段 0：研究界定 — 选项文案参考（供 `ask_clarification`）

使用方式：**不要机械照搬下文整套措辞**。先读取用户原问题中的主题、场景、时间（如「今日」「某公司」「是否要演示」），再用 **`questions[]` 结构化调用** `ask_clarification`：每条 `options` **只写正文**，**不要写序号或 A/B**（前端会统一编号）。

---

## 硬性约定（与 EvoFlow 前端一致）

1. **产出形态不向用户提问**：默认产出为 **HTML 洞察展示页**（可演示、含图表区与来源区）。中间研究小结可为 Markdown，**终稿对外展示以 HTML 为准**。  
2. **模板不向用户单独问卷**：由模型根据界定书自动选用 **T01–T05**（见 `SKILL.md`）；仅当用户主动说「要公司一页纸 / 要对比表 / 要时间线」时可明示选用的模板倾向写入界定书，无需再 `ask_clarification`。  
3. **选项必须与用户问题同类**：先提炼用户关心的 **1～3 个决策/信息目标**，再为每个目标设计互斥或可多选的切片；**禁止**在用户明确「日报 / 舆情 / 快讯」时仍塞满「学术理论 / 投资资本」等跑偏维度。  
4. **展示交付物**：终稿 HTML 写入 **`outputs/`**（或环境约定的等价路径）后，**主监工须在回复中用 `@@outputs/…@@` 交付**；**禁止**只写盘不在回复中交付。

---

## 合并一轮（推荐：`questions`：研究方向 + 深度）

下列 **`question`/题干** 可复制后把 `【在此填写主题】` 换成用户主题；**`options` 必须按用户问题改写**，下列 bullet **仅作维度灵感**，勿原样粘贴九大通用项。

```text
在开始对「【在此填写主题】」做联网深入研究之前，请先确认两项（补充说明可写在结构化表单「补充说明」里）：

说明：最终交付默认为 HTML 洞察展示页（含图表与来源），无需再选产出格式。

**1）你最关心哪些角度？（可多选）**
（此处由模型根据用户问题改写选项，示例——）
· AI 行业日报类：技术突破与模型、商业与投融资、产品与发布、监管与合规、综合快报、其他（请补充）
· 单公司深挖：战略与组织、产品与路线图、财务与市场表现、竞争与风险、其他（请补充）
· 技术选型类：能力边界、生态与成本、风险与限制、落地案例、其他（请补充）

**2）研究深度（单选）**
· 快速：少来源，优先可行动结论，覆盖 1～3 个关键角度
· 标准（默认）：适度扩展 + 风险/反方观点
· 深入：多轮检索 + 必要时精读权威全文

**3）边界（可选）**  
地域 / 时间窗口 / 语言 / 需排除的来源 —— 可在补充说明中简述；没有可写「无」。
```

调用工具时请拆成 **两道题**（示例字段名）：

- `questions[0]`：`prompt` = 关心角度；`allow_multiple` = true；`options` = **与用户问题强相关的** 4～7 条短句（末条建议含「其他（请补充说明）」）。  
- `questions[1]`：`prompt` = 研究深度；`allow_multiple` = false；`options` = 上表三条深度对应的三条文案（不要带前置编号）。

## 拆两轮时使用

### 第一轮：研究方向 + 深度（仍不问产出）

```text
关于「【在此填写主题】」，请先选定研究取向与深度。

产出说明：默认交付 HTML 洞察展示页；展示模板由助手按你的选择自动匹配。

（结构化 JSON：`questions` 两题；options 文案须贴合用户问题改写，勿套用无关维度。）
```

### 第二轮：核心问题 + 边界

```text
接上轮。请补充：

**1）核心问题（一句话）**  
您最想得到的结论或决策支持是：__________

**2）边界**  
地域 / 时间 / 语言 / 需排除的来源类型 —— 无则回「无」。
```

- 地域侧重：
- 时间范围：
- 语言偏好：
- 需排除的信息源类型：

说明：产出仍为默认 HTML 洞察页。

## 给模型的注意

- **`options` 有序数组**：第 1 条对应界面「1.」，**字符串内不要再写 `1.` / `A.`**。  
- **短回复与自然语言等价**：用户若已在首轮说清楚类型、深度与边界，视为阶段 0 完成，**不必为走流程而追问**。  
- 收到结构化答案后写入《研究界定书》，并写明：**产出默认为 HTML**、**选用模板 T0x 及理由**、**建议交付 HTML 文件名（优先中文、含主题/日期关键词，勿用 T01 模板原名）**、**终稿路径 + 主会话 `@@outputs/…@@` 交付**，再进入检索与子任务。
