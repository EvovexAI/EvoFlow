# Human Signal 平台适配指南

平台不是装饰项。中文内容的“人感”高度平台化：同一段话，在小红书、知乎、公众号、口播和 B 站里的好标准不同。

使用方法：

1. 先保留体裁目标。
2. 再按平台校准开头、节奏、互动、术语和结尾。
3. 不为了平台感编造体验、数据、评论和效果。
4. 去 AI 味只优化语言可信度和表达质感，不破坏平台常识：标题、分段、清单、标签、互动和转化位置该有就要有。

## 小红书

AI 味：

- 像品牌 brief：卖点完整、形容词堆叠、每段都太正。
- 过度“姐妹们听劝”，但没有真实使用场景。
- 标题夸张，正文却没有个人体验和取舍。
- 结构像作文或产品手册：每条都是“四字名词 + 冒号 + 描述”，段落长度接近。
- 常见对仗句式太多，如“从来不是 A，而是 B”“看不见的细节，最后变成生活质感”。
- 结尾强行升华到“生活质感、松弛感、仪式感、答案”。
- 植入像广告 slogan，如“隐形家电、悄无声息改变生活质感、存在感很强”。
- 反向过校准：为了不像广告和 AI，把小红书写成无标题、无信息分层、无互动、无标签、无边界推荐的散文随笔。

人感方向：

- 第一人称、短句、真实困扰、轻判断。
- 可以有轻口语和少量 emoji，但不要用来遮空。
- 写“适合谁 / 不适合谁 / 我踩过什么坑”比堆卖点更可信。
- 语言可以直接一点：“用了就回不去”“每天都离不开”“生活质量直接 up”，但不能硬装网感。
- 细节要贴近日常视角：水垢、懒得烧水、半夜起床、台面占地方、滤芯提醒、清洗麻烦。
- 好物植入要从“原来的麻烦”进入，不要从“产品定义”进入。
- 保留小红书常规骨架：标题/开头钩子、分段、可扫读信息点、适合/不适合、使用前后对比、必要标签或互动。
- 标题要像小红书标题，不要像散文题名；正文可以松弛，但不能丢掉信息效率和种草/避坑/经验分享属性。

修复：

- 把“产品优势”改成“我在什么场景下为什么留下它”。
- 把万能推荐改成有边界的推荐。
- 删掉过密标签、夸张效果和伪评论口吻。
- 打散工整列表：不要每条同句式、同长度、同冒号。
- 删掉书面形容：如“光线穿过的通透、悄无声息改变、生活质感”，改成具体使用感。
- 用真实前后对比替代 slogan：如“以前烧水壶水垢厚、现在不用反复刷壶”。
- 结尾收在普通动作或边界判断上，不要升华。
- 如果改完变成散文，回退：补回标题、场景钩子、扫读分层、适用人群/不适用人群、互动或标签，但避免模板化。

小红书准出自查：

- 有没有标题或能当标题的第一句？
- 用户刷到后 3 秒内能否知道“这篇解决什么问题/分享什么经验”？
- 是否保留了小红书常见的信息组织，而不是一整段散文式抒情？
- 是否有真实使用场景、前后对比、边界推荐或踩坑点？
- 是否没有用“生活质感/仪式感/松弛感”等大词替代具体体验？

## 公众号

AI 味：

- 开头大而泛，三段式起承转合太标准。
- 每节都有小标题、金句和段尾升华。
- 观点正确但没有个人判断和材料支撑。
- 小标题一到五整齐排列，像论文目录。
- 自问自答太多，如“什么概念？”“为什么？”“哪种更好？”。
- 破折号解释、概念引号过密，像在做名词解释。
- 情感分析文把活人关系拆成一堆概念，如“功能”“阶段性合伙”“情绪价值”，但缺少真实关系里的动作、犹豫和代价。
- 每段都是“观点 + 解释 + 例子 + 总结”，节奏过于均匀。

人感方向：

- 长文可以有结构，但要有切入点、材料和递进。
- 语言克制，少网感，少口号。
- 允许停在问题、矛盾或具体判断，不必每段升华。
- 情感分析要像一个人认真看过关系里的具体矛盾，而不是给关系下定义。
- 概念要少，关系细节要多；少讲“是什么”，多讲“人会怎么做、怎么躲、怎么耗着”。
- 小标题可以不对仗、不编号、不全同句式；让标题承担推进，而不是装整齐。

修复：

- 用具体事件、问题或反常识判断开头。
- 减少“从本质上说”“这背后反映的是”。
- 用事实推动段落，而不是用连接词推动。
- 删除假设问；保留真正能打开文章矛盾的问题。
- 合并过密小标题，打破每节同长度、同结构。
- 删掉不必要的引号和破折号，把概念解释改成具体判断。
- 结尾收在一个清楚但不万能的判断上，不写“每个人都有选择的权利”这类金句。

公众号准出自查：

- 破折号、冒号、引号是不是密到像概念讲义？
- 小标题是不是过于工整，读起来像论文目录？
- 自问自答是不是每节都出现？
- 是否用了太多“不是 A 而是 B”“好的一面/不好的一面”？
- 结尾是不是强行升华成普世金句？

## 知乎

AI 味：

- 像中立科普文：两边都说，最后理性看待。
- 缺少立场、证据密度和反驳意识。
- 例子太泛，像“小明/某企业/部分用户”。

人感方向：

- 先给明确判断，再解释边界。
- 有论据、有经验、有反例。
- 可以有一点反直觉，但不能为了聪明硬拗。

修复：

- 把“我认为可以从三个方面看”改成一个明确结论。
- 补充可验证事实、亲历经验或具体机制。
- 明确“什么情况下不成立”。

## 抖音 / 视频号口播

AI 味：

- 书面稿感强，句子太长，逻辑太完整。
- 开头像广告语，停顿和转折不适合说出口。
- 每句话都完整，听起来像念稿。

人感方向：

- 口语钩子、短句、停顿、反问、悬念。
- 一次只讲一个重点。
- 允许省略书面连接词，用语气推进。

修复：

- 长句拆短。
- 把“首先其次”改成“先说结论”“问题就在这”。
- 每 2-3 句设计一个自然停顿或转折。

## B 站

AI 味：

- 像通稿或百科介绍，太端、太完整。
- 梗用得像硬贴，解释过度。
- 没有自嘲、弹幕感或圈层语境。

人感方向：

- 有观点，有槽点，有轻微自嘲。
- 可以用梗，但要符合圈层，不解释笑点。
- 叙述可以绕一点，但不能失去主线。

修复：

- 把宏观介绍改成具体吐槽点或观察点。
- 删硬凹梗和过度解释。
- 保留作者判断，不要装成官方解说。

## 朋友圈

AI 味：

- 太像公开文案，表达目的过强。
- 情绪包装过满，像小作文。
- 明明是熟人关系，却写成陌生大众传播。

人感方向：

- 少解释背景，少喊口号。
- 可以更轻、更短、更含蓄。
- 熟人语境里，留白比完整更自然。

修复：

- 删掉“意义”“价值”“成长”等升华。
- 保留一个真实状态或小判断。
- 不把朋友圈写成公众号开头。

## 微博

AI 味：

- 观点太平，像新闻短评。
- 情绪和立场没有锋芒。
- 话题感弱，缺少可转发的一句话。

人感方向：

- 更短、更直接、有态度。
- 可以有一句记得住的判断，但不能空喊。
- 热点语境要快，不要铺垫太多。

修复：

- 第一行给判断。
- 删解释型套话。
- 保留一个具体槽点、事实或反差。

## 企业 IM / 飞书 / 邮件

AI 味：

- 过度客气，铺垫太多。
- 正式但没有行动项。
- 像公告，不像真实沟通。

人感方向：

- 直接说事、清楚分工、保留礼貌。
- 需要对方动作时，说清时间、交付物、责任人。

修复：

- 开头直接说明来意。
- 删“烦请知悉”“如有不妥敬请指正”等过度套话。
- 把态度词换成具体动作。
