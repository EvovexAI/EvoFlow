# Human Signal 行业边界指南

行业决定什么不能去味。专业和合规场景里，一部分“客观、工整、谨慎”不是 AI 味，而是必要语体。

## 法律 / 合同 / 制度

原则：

- 不为了人感削弱法律效力、责任边界、条件限制和定义。
- 不把“应当、不得、承担责任”等正式措辞改得过于口语。

可做：

- 帮用户另写通俗解释版。
- 降低不必要官腔。
- 梳理条款结构。

不可做：

- 擅自改义务、权利、责任、期限、违约条件。

## 医疗 / 健康

原则：

- 不编疗效、适用人群、风险和诊断结论。
- 不把风险提示删成“更自然”。

可做：

- 把专业说明翻成更易懂的表达。
- 保留风险提示和就医建议。

不可做：

- 夸大效果，替代医生诊断，弱化禁忌。

## 金融 / 投资 / 保险

原则：

- 不承诺收益，不暗示稳赚，不删除风险。
- 不把谨慎表述改成确定性判断。

可做：

- 提高清晰度。
- 解释概念、费用、风险和适用边界。

不可做：

- 编造收益数据、用户案例、投资建议。

## 技术文档

原则：

- 客观、工整、结构清楚常常是优点，不必强行人感化。
- AI 味主要来自泛泛而谈、没有参数/限制/示例，而不是正式语气本身。

可做：

- 补使用条件、输入输出、错误边界、示例。
- 删除“高效、稳定、强大”等空泛形容。

不可做：

- 为口语化牺牲准确性、术语一致性和步骤完整性。

## 教育 / 申请 / 招聘

原则：

- 不能编经历、成绩、项目和动机。
- 不把个人陈述写成完美人设。

可做：

- 用真实经历证明能力。
- 写清选择、反思、边界和变化。

不可做：

- 伪造奖项、结果、推荐语和影响力。

## 消费品 / 本地生活

原则：

- 不编使用效果、体验周期、用户反馈、探店经历。
- 不夸大功效，不使用绝对化承诺。

可做：

- 写真实场景、适合人群、不适合人群和使用边界。
- 把卖点落到具体动作和感受。

不可做：

- 伪造评论区、销量、对比实验和个人亲测结果。
