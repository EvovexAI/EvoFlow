# Human Signal 上游防御指南

本文件用于用户首次生成内容时，就把 AI 味压下去。目标不是写复杂 prompt，而是在生成前放入真实素材、作者声音、体裁平台边界和禁用项。

## 目录

- 基础防御 Prompt
- 首次生成模板
- 改写模板
- 诊断评分模板
- 素材清单
- 风格样本注入
- 禁用项模板
- 生成后自检

## 基础防御 Prompt

```text
请帮我写【体裁/平台】内容，主题是【主题】。

使用场景：【发布/提交/发送给谁】
作者/说话者：【身份、年龄、性格、表达习惯】
最终读者：【身份、关系、他们在意什么】
必须保留的信息：【事实、观点、数据、时间、人物、限制】
真实素材：【经历、场景、动作、矛盾、结果】

要求：
- 不要写得像 AI，不要模板腔、官腔、概念堆砌和强行升华。
- 先保证体裁和平台成立，不要为了自然破坏格式。
- 观点要有判断，但保留边界，不要端水也不要极端。
- 不能编造事实、数据、案例、评论、经历和具体对话。
- 如果素材不足，只能保守写，并标出需要补的信息。
```

## 首次生成模板

用于“帮我写个 xx，不要有 AI 味/不要太假/要有人感”的任务。重点是先定义好内容标准，再生成，不要先写一版模板再补救。

```text
请直接生成一版可发布的【体裁/平台】内容。

主需求：【要写什么】
使用场景：【发给谁/发在哪里/用于什么】
作者画像：【身份、年龄、性格、表达习惯、熟练度】
最终读者：【他们是谁、在意什么、讨厌什么、需要什么信息】
必须保留/使用的事实：【事实、经历、数据、观点、限制】
不能写的内容：【不能编造、不能承诺、不能触碰的边界】
风格样本：【可选，粘贴用户过往文字】

请先在内部判断：
1. 这是什么体裁和平台，好内容标准是什么。
2. 在这个场景里，AI 味通常表现为什么。
3. 相反，人感应该体现在哪里：事实、判断、读者视角、人物口吻、结构节奏还是细节。

输出要求：
- 直接给成品，不要先解释。
- 事实不足时保守写，不编具体事件、数据、评论、效果和对话。
- 不要为了自然破坏体裁和平台规范。
- 不要用“不是 A 而是 B”、概念引号、破折号解释、段尾升华、数据墙、广告 slogan 来制造深刻感。
```

## 改写模板

用于用户已经给草稿，并反馈“太 AI/太空/太假/不像我”。

```text
请把下面文本改得更自然真实，但保留原意和所有事实。

改写强度：【轻度/中度/重度】
使用场景：【可选】
作者/说话者：【可选】
最终读者：【可选】
必须保留：【事实、数字、引用、术语、格式】
不能改变：【立场、责任归属、时间顺序、合规边界】
禁用/少用：【用户不喜欢的词、句式、符号】

原文：
【粘贴文本】

要求：
- 只改“怎么说”，不改“说什么”。
- 如果原文已经自然，直接说不建议大改。
- 找到主要病灶后再改，不要只做口语化。
- 不编造原文没有的具体经历、数据、评论、物品、对话。
```

## 诊断评分模板

用于只想知道“哪里像 AI”或想要修改清单的任务。

```text
请只做诊断和评分，先不要改写。

文本：
【粘贴文本】

请输出：
1. AI 味指数 0-100。
2. 主要成因层：观点/结构/表达/素材/叙事/情感/语境错配。
3. 2-5 个最影响质感的问题，每个问题给原文片段、为什么像 AI、怎么修。
4. 建议改写强度：轻度/中度/重度。

诊断要结合体裁、平台、受众，不要只列禁用词。
```

## 素材清单

生成前优先向用户要这些素材。不是每项都必须有，但越具体越不容易 AI：

- 一个真实场景：什么时候、在哪、谁在场、发生了什么。
- 一个具体动作：做了什么、没做什么、卡在哪里。
- 一个真实判断：用户到底赞成什么、反对什么、保留什么。
- 一个读者痛点：读者为什么会在意这段内容。
- 一个边界：什么不能夸、不能改、不能承诺。
- 一个不完美处：犹豫、代价、冲突、失败、没想清楚的地方。

## 风格样本注入

如果用户有 500-1500 字代表作，先学习样本再写：

```text
下面是我的写作样本。请学习我的节奏、词汇、句长、判断方式和分寸，不要模仿具体内容。

【粘贴样本】

接下来写新内容时：
- 保持类似语气和节奏。
- 不要突然变得更华丽、更网感或更官方。
- 避免我平时不用的词和句式。
```

## 禁用项模板

按任务选择，不要一次塞太多：

```text
禁用：
- 过度连接词：首先、其次、此外、值得注意的是、综上所述
- 强行洞察：不是 A 而是 B、不仅是 X 更是 Y、核心就一句话
- 概念大词：赋能、闭环、生态、底层逻辑、情绪价值、自我意识觉醒
- 符号癖：连续破折号、概念引号、箭头链路
- 结尾升华：未来可期、意义所在、每个人都有选择的权利
- 平台错配：小红书不要写成散文，公众号不要写成概念讲义
```

## 生成后自检

输出前自查：

1. 这篇还像目标体裁/平台吗？
2. 有没有事实被改、被弱化、被模糊？
3. 有没有编造用户没给的经历、数据、评论或具体细节？
4. 有没有一眼 AI 的句式：不是 A 而是 B、好的一面/不好的一面、每段观点解释例子总结？
5. 有没有靠数据墙、概念大词或段尾金句假装深刻？
6. 有没有作者画像：像这个身份、年龄、性格的人会说的话吗？
7. 如果原文已经自然，是否应该不大改？
