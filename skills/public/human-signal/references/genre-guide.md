# Human Signal 体裁适配指南

本文件用于做体裁路由。体裁决定内容骨架；平台、受众、行业和公开度会继续修正语感、距离、边界和优先级。目标不是只去 AI 味，而是让文本在对应交付语境里成立。

## 目录

- 1. 通用流程
- 2. 影评 / 书评 / 评论
- 3. 工作总结 / 汇报
- 4. 邮件 / 正式沟通
- 5. 私人情感文本
- 6. 社媒文案
- 7. 营销 / 品牌文案

- 10. 体裁必需件不可删

## 1. 通用流程

先问四件事：

1. 这是什么体裁？
2. 它会发到什么平台？
3. 写给谁看，关系距离多远？
4. 公开度是私人、半公开、公开还是专业？
5. 这个行业有没有不能为了人感而改掉的正式/合规要求？
6. 这个组合里什么叫 AI 味、人感和好内容？

再执行：

- 选切入点。
- 控制信息密度。
- 控制有效低效率：必要时保留一点不完美，但不能损害阅读。
- 设计结构主线。
- 打磨关键句。
- 保持事实边界。
- 保留体裁必需件：作文题目、信函称谓/落款、小红书标题/tag、邮件称呼/目的、演讲开场和收束等。
- 和平台、受众、行业、公开度规则合并判断，不单独套体裁模板。

## 2. 影评 / 书评 / 评论

优先级：

1. 观点明确
2. 切入点新
3. 信息密度
4. 结构流动
5. 文字质感

AI 味：

- 只复述剧情。
- 主题很泛，如“大时代下的小人物”“人性的复杂”“命运的无常”。
- 结构是“优点-缺点-总结”。
- 只写“演员表现出色、节奏紧凑、值得一看”。
- 没有具体镜头、表演、调度、声音、美术、类型参照。
- 没有判断，只做平衡评价。
- 长文分析里概念太多，破折号、引号、自问自答和“不是 A 而是 B”堆叠。
- 每段都按“观点 + 解释 + 例子 + 总结”生产，像标准答题。
- 社会洞察类文案高频甩数据，用报告、比例和年份堆可信度。
- 非专业场景里语言太书面、太社论，如“生存共同体”“自我意识的觉醒”，概念感重但共鸣弱。
- 为了反套路而刻意毒舌，或为了安全而刻意端水。

人感 / 好内容：

- 有一个明确切入点：反常识判断、核心比喻、具体场景、争议问题、人物切片、类型对比。
- 有影片/文本证据：具体场面、人物选择、视听手法、叙事结构、台词或节奏。
- 有可查证背景：原著、导演、编剧、摄影、美术、配乐、票房、同类型作品、导演过往风格。
- 有判断和取舍：说清哪里有效、哪里失手、为什么。
- 有结构主线：一个问题、一个比喻、一条递进判断，而不是散点感受。
- 有分析节奏：有的段落讲材料，有的段落推进判断，有的段落停在矛盾；不要每段都解释概念。
- 情感/社会分析要把抽象概念落到具体动作、选择、沉默、算计、消耗和代价。
- 社会洞察要靠观察和逻辑推进：先看见现象，再拆动机、误判、代价和边界。
- 数据可以用，但只保留能改变判断的关键数据；不要用数据墙替代判断。
- 语言要有观察、有判断、有保留、不端着；锋利但不刻薄，鲜明但不极端。
- 金句必须从论证中自然长出来，不在段尾硬贴。

切入点模板：

- 反常识：这部片最有意思的不是 X，而是 Y。只在 X/Y 真有冲突时使用。
- 隐喻贯穿：把一个核心比喻贯穿全文，如“抓特务像一场童年游戏”。
- 人物切片：从一个角色的选择切开全片。
- 对比参照：和同类型作品比较差异。
- 具体场景：从一个镜头/一场戏/一个动作进入。
- 问题驱动：先提出一个具体问题，再用全文回答。

信息密度规则：

- 鼓励补充公开可查证信息，但不能假装知道。
- 可以补：原著来源、主创班底、同类型参照、导演过往作品、票房数据、时代背景。
- 不能编：导演意图、幕后故事、票房数字、原著情节、主创采访、观众反馈。
- 未查证时用保守表达：如果缺公开信息，就不要写成事实。

结构主线：

- 问题驱动：提出问题 -> 拆解原因 -> 给出判断。
- 对比型：预期 -> 实际 -> 差距。
- 递进型：表层观感 -> 中层手法 -> 深层主题。
- 人物型：跟着一个角色走完全篇。
- 隐喻型：用同一个比喻串起剧情、人物和主题。
- 关系分析型：从一个具体矛盾进入，不急着下定义；先写人怎么做，再判断背后的关系机制。
- 社会洞察型：现象观察 -> 反常识判断 -> 逻辑拆解 -> 保留边界 -> 回到具体处境。

关键句打磨：

- 标题、开头第一句、结尾最后一句最值得打磨。
- 金句必须从内容里长出来，不能先有金句再硬套。
- 结尾收在具体画面、具体判断或与开头呼应的比喻上，不写“发人深省、值得一看”。

## 3. 工作总结 / 汇报

优先级：

1. 事实具体
2. 动作和结果
3. 卡点和边界
4. 去套话
5. 分寸感

AI 味：

- 持续推进、协同资源、优化流程、阶段性成果。
- 只写努力，不写结果。
- 只写宏观价值，不写具体动作。

人感 / 好内容：

- 做了什么、做到哪、卡在哪里、下一步是什么。
- 少形容词，多对象、动作、数据、时间和责任。
- 没有数据时写清可观察结果，不编数字。

## 4. 邮件 / 正式沟通

优先级：

1. 目的清楚
2. 信息完整
3. 分寸合适
4. 少铺垫

AI 味：

- 过度客气、绕太远、套话开场。
- 明明是一个请求，却写成正式公告。

人感 / 好内容：

- 第一段说明来意。
- 关键事项列清楚。
- 礼貌但不堆叠。
- 需要对方行动时说清截止时间和交付物。

## 5. 私人情感文本

优先级：

1. 情绪有分寸
2. 读者视角
3. 清楚理由 / 关系边界
4. 安全细节
5. 作者人设

AI 味：

- 爆款金句、苦难叙事、编专属细节、过度承诺。
- 反向过校准：过于冷静、短促、平淡，只剩通知和事务安排。
- 用“你很好”“不合适”“照顾好自己”这类模板句替代真实表达。

人感 / 好内容：

- 有“我看见你的付出”。
- 用绿线微细节和蓝线主观感受承载情绪。
- 不猜对方内心。
- 承诺落到生活小兑现。
- 克制不是不说、不表达，而是情绪、理由、边界写到刚好够。

情感克制的判断：

| 类型 | 克制的误区 | 更好的做法 |
|---|---|---|
| 分手短信 | 冷处理、只通知、不解释；只说“你很好/不合适/照顾好自己” | 承认关系曾经真实有价值，说明自己的变化或无法继续投入，承担决定，给出清楚但不伤人的边界 |
| 道歉信 | 表白化、求原谅、堆承诺 | 说清错在哪、影响了对方什么、自己承担什么、以后具体怎么改 |
| 感谢信 | 只说谢谢，或强行苦情煽情 | 写“我记得什么”“我看见你做了什么”，让感谢落到对方付出 |
| 安慰信 | 万能共情、急着指导对方 | 先看见具体难处，再给陪伴、空间或实际支持 |
| 纪念日文本 | 华丽排比、命运感、宏大承诺 | 用少量共同经历和现在的感受承载关系，不把日子写成爆款故事 |

分手短信专项：

- 温柔：承认这段关系里真实存在过开心、照顾、认真或陪伴。
- 疏离：不制造复合暗示，不用“还可以做朋友”除非用户明确想保留朋友关系。
- 尊重：给出足够清楚的理由，但不审判、不控诉、不清算。
- 承担：用“我的状态/想法变了”“我没有办法像以前那样投入”承担决定，而不是把责任全推给“我们不合适”。
- 边界：后续联系、物品、空间等可以说清楚，但不能写得像行政通知。
- 人感：允许一点犹豫、歉意和不忍；但不要反复求原谅、拉扯或自我感动。

不够好：

> 我们分开吧。你很好，只是我们不合适。照顾好自己。

更好方向：

> 想了很久，还是想跟你好好说一声。
>
> 这段时间跟你在一起，我有过很多开心的时候，也一直记得你对我的认真和照顾。但我慢慢发现，我自己的状态和想法已经变了，没办法再像以前那样投入这段关系。
>
> 继续拖着，对你不公平。所以我想把话说清楚：我们分开吧。
>
> 这不是你哪里不好，也不是想用一句“不合适”把这段关系带过去。只是这个决定我想了很久，也知道该由我来承担。
>
> 接下来我们先不要联系了，给彼此一点时间。你放在我这边的东西，我会整理好寄给你。
>
> 谢谢你认真对待过我们。也希望你之后一切都好。

## 6. 社媒文案

优先级：

1. 场景感
2. 开头钩子
3. 真实体验
4. 节奏
5. 互动感

AI 味：

- 营销腔、万能心得、虚假效果、标签堆叠。

人感 / 好内容：

- 从一个具体困扰或瞬间开头。
- 写真实阻力，不只写结果。
- 标题不过度夸张。
- 不编使用效果、数据、体验周期。

## 7. 营销 / 品牌文案

优先级：

1. 具体卖点
2. 用户场景
3. 可信表达
4. 转化动作

AI 味：

- 赋能、重塑、全方位提升、开启新篇章。
- 只有品牌自嗨，没有用户场景。

人感 / 好内容：

- 说清谁用、什么时候用、解决什么问题。
- 卖点落到动作和结果。
- 不夸大功效，不虚构用户证言。

## 8. 个人陈述 / 申请材料

优先级：

1. 真实动机
2. 经历证据
3. 个人差异
4. 反思和变化

AI 味：

- 具备较强能力、热爱、责任心、抗压能力。
- 宏大使命但没有个人经历。

人感 / 好内容：

- 用具体经历证明能力。
- 写清选择、困难、取舍、变化。
- 不编成果，不夸大影响。

## 9. 故事类软广 / 第一人称经历文

优先级：

1. 叙事可信
2. 作者视角
3. 产品/观点自然进入
4. 节奏好读
5. 转化不过度

AI 味：

- 故事链路太干净：看到评论 -> 立刻顿悟 -> 开始认真做 -> 数据变好 -> 品牌/机构找上门。
- 每句话都服务主线和转化，几乎没有普通人的停顿、误判和没想明白。
- 第一人称太全知，能准确解释自己为什么火、别人为什么关注、产品为什么有效。
- 评论/对话太工整，每条都提供一个新论点。
- 细节过度文学化，像写作者后期装进去的画面。
- 结尾单独留一句意象金句或强行升华。

人感 / 好内容：

- 有主线，但允许过程不那么一步到位：试过、停过、误会过、后来才慢慢发现。
- 有作者认知局限：可以写“我当时也没想明白”“可能是因为”“后来才觉得”。
- 有少量有效低效率：一句吐槽、一个不完全服务转化的旁枝、一个真实但不过量的生活噪点。它们必须让文本更可信，不能让文章变啰嗦。
- 评论/对话可以不完美：重复、半截、跑题都可以少量出现，但不要堆成聊天记录。
- 产品/品牌出现像生活里自然用到的东西，而不是故事终点突然降临的答案。
- 结尾可以收在日常动作、朴素判断或未完成状态，不必制造“余味金句”。

执行规则：

- 先保主线，再加人感噪点。不要为了显得真人而打散到读者看不懂。
- 低效率内容控制在少量，只保留能体现人设、场景或真实过程的片段。
- 关键商业信息仍要清楚：谁遇到什么问题、怎么解决、为什么可信、下一步做什么。
- 不编数据、品牌邀约、爆款增长、用户证言和具体评论。

检查清单：

- 主角是不是太快顿悟了？
- 因果是不是太直、太顺、太会成功？
- 第一人称是不是把自己和读者都解释得太明白？
- 软广植入是不是像广告 brief，而不是生活里的选择？
- 结尾是不是为了金句而金句？
