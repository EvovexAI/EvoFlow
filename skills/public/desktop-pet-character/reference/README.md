# EvoPet · 桌面宠物

一个 Windows 桌面宠物：真透明窗口、永远置顶、会呼吸、能拖能扔、会跟你说话，还能被语音对话系统驱动出四种工作状态。
**六个角色**可随时切换：

![角色设计](assets/characters.png)

| 角色 | 家族 | 设定 |
| --- | --- | --- |
| **小汐** | 人物 · 冰蓝 | 冰蓝长发、素色长裙的小女孩，桌面语音助手，会思考、会敲代码、会听你说话 |
| **小九** | 狐狸 · 橙 | 一只还没长齐九条尾巴的小狐狸，脾气很好，喜欢被拖着走 |
| **小霜** | 狐狸 · 冰蓝 | 从雪原跑来的小狐狸，毛是冰蓝色的，呼出来的气都带霜 |
| **小夜** | 狐狸 · 夜空蓝 | 只在深夜出没，皮毛是星空蓝，眼睛里有没睡着的星星 |
| **小鸣** | 忍者 · 橙 | 戴护额的 Q 版忍者，梦想是当上火影，现在负责陪你写代码 |
| **小岚** | 忍者 · 水蓝 | 水之国来的忍者，一身靛蓝，擅长水遁，也擅长在你屏幕上偷懒 |

小汐的四种对话状态（待机 / 思考 / 敲代码 / 聆听 / 回答）：

![对话状态](assets/girl_states.png)

![会动的样子](assets/xiaoxi_anim.gif)

狐狸和忍者全是**纯矢量绘制**，任意缩放都清晰，换色时描边、腮红、影子会一起跟着变；小汐用的是手绘立绘，
但立绘被拆成「头 / 身」两层实时合成，所以是真的会动：

| 动什么 | 怎么做的 |
| --- | --- |
| 呼吸 | 身体层与头层错开半拍上下浮，幅度约 2 设计像素 |
| 眨眼 | 眼睛区域按 blink 值纵向压缩 + 补肤色，闭上时叠一条眼睑线 |
| 说话 | 先盖掉立绘自带的小嘴，再用「音节包络」画张嘴：三层不同频率叠加负责节奏，另一条包络控制嘴的宽窄（"啊"是竖的、"咿"是横的），偶尔闭口换气；嘴角始终上扬，配白牙 / 舌头 / 下唇高光 |
| 表情 | 每个状态一套 (笑意, 张口度, 腮红)：待机是闭口微笑，聆听笑得最开，思考抿着嘴；笑意直接决定嘴角抬多高，腮红随情绪浮在脸颊上 |
| 思考 / 聆听 | 头部绕脖子旋转，配合脑侧光点、耳侧声波 |
| 敲代码（**坐姿**） | 切到另一张坐姿立绘：坐在桌前，双手在键盘上连点，键帽逐颗点亮、键盘前缘氛围灯跟着节奏明暗，肩背与脑袋一顿一顿 |

**敲代码会换成坐姿**：站着的立绘没法表现出"坐在桌前打字"，所以单独画了一张 `assets/girl_desk.png`
（同一角色、桌前坐姿、双手落在键盘上），切到「敲代码」时两套立绘交叉淡入 —— 读起来就是她凑到桌前坐下。

头部旋转的旋转中心在脖子上，两层重叠 110 像素，所以摆头时不会露出接缝。

**已经帮你配好的**：运行环境（`.venv`）、桌面快捷方式、开机自启，以及正在运行的实例。
现在桌面上应该能看到「小汐」了，直接去摸她就行。

## 一、怎么启动

三种方式，任选：

1. **桌面图标**：双击桌面上的「桌面宠物」
2. **文件夹里**：双击 `启动桌面宠物.vbs`（无控制台、无黑框）
3. **命令行**：`.venv\Scripts\pythonw.exe main.py`

关闭：右键宠物 → **退出**，或双击 `退出桌面宠物.bat`。

> 首次启动会在 `%APPDATA%\EvoPet\config.json` 生成配置，记录角色、大小、位置等。

## 二、怎么玩

| 操作 | 效果 |
| --- | --- |
| **左键单击** | 摸一下：它会开心地眯眼、抬手、说句话 |
| **按住拖动** | 拎起来带走；松手会自由落体并弹一下 |
| **双击** | 更兴奋的反应（抖动 + 眼睛笑成 `´▽`） |
| **滚轮** | 直接放大 / 缩小 |
| **右键** | 菜单：换角色 / 大小 / 说句话 / 哄睡 / 随意走动 / 置顶 / 开机自启 / 退出 |
| **鼠标靠近** | 眼珠会跟着你的鼠标转 |
| **拖动托盘图标单击** | 显示 / 隐藏 |

它的自主行为：

- 呼吸起伏、随机眨眼、尾巴一直摇
- 偶尔左右张望、抖耳朵、抬手打招呼
- 心情好会自己沿着屏幕底部走两步（贴着地面小跳）
- 长时间不理它会犯困睡着（眼睛变成 `— —`，呼吸变慢）
- 鼠标在附近时会盯着你的光标看

## 三、开机自启

**已经开启**。启动文件夹里有 `EvoPet.lnk`，重启后会自动出现。
不想要了：右键宠物 → 取消勾选 **开机自启**，或者删掉
`%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\EvoPet.lnk`。

## 五、技术要点（想改的话看这里）

- **真透明**：`WA_TranslucentBackground + FramelessWindowHint + Qt.Tool`，无边框、不占任务栏、不抢焦点。
- **点击穿透**：每帧把带 alpha 的画面折算成 `QRegion` 遮罩（3px 块粒度）交给 `setMask`，
  所以宠物周围的透明区域不会挡住你点桌面图标。
- **高 DPI**：渲染缓存按 `devicePixelRatio` 放大后再缩回逻辑尺寸绘制，125% / 175% 缩放下都清晰。
- **性能**：30fps 定时器 + 矢量重绘，静止时几乎不占 CPU；遮罩只在画面变化时重建。
- **狐狸和忍者是用代码画的**，改颜色/比例直接改 `characters.py` 里的常量即可；小汐的形象是两张立绘：
  `assets/girl.png`（站姿，待机/思考/聆听/回答）和 `assets/girl_desk.png`（桌前坐姿，敲代码），换图即可换人。
  关键坐标（眼、嘴、手、键盘、头身分层线）都是 `GirlArt` 的类属性，换立绘时改那一组常量就行。

**想给狐狸/忍者加配色**：颜色全部是类属性，所以最省事的做法是继承现有角色、只覆盖调色板：

```python
class FoxFrost(Fox):
    name = "小霜"
    FUR_DARK, FUR, FUR_HI = QColor("#2A5F9E"), QColor("#5AA7E8"), QColor("#ACDCFA")
    CREAM, EDGE, NOSE = QColor("#F4FBFF"), QColor("#1B4B76"), QColor("#22557F")
    sparkle_color = QColor("#E8F6FF")   # 不想要星光就留 None
    sparkles = ((50, 68, 6.0, 0.0), (150, 60, 4.6, 1.7))
```

再注册到文件末尾的 `CHARACTERS` 字典，右键「换个角色」里就会自动出现（按狐狸 / 忍者分组，新物种会排在分组下方）。
可覆写的键：`FUR* / CREAM / EAR_IN / INK / IRIS / EDGE / NOSE / SHADOW / BLUSH`（狐狸），
`HAIR* / SUIT* / NAVY / SKIN* / COLLAR / METAL* / WHISKER / EDGE / SHADOW / BLUSH`（忍者）。
台词在 `pet/window.py` 的 `LINES` / `IDLE_BUBBLE` 里按 key 配，缺了会自动回退到默认台词。

## 六、常见问题

**双击后没反应？**
看 `pet.log`。最常见的是没装依赖 —— 跑一次 `install.bat`。

**它挡住了我点桌面？**
不会，遮罩已经把透明区域排除了；只有角色本体可以被点到。

**多显示器 / 换分辨率后位置不对？**
启动时会自动夹回主屏可视区域内；右键 →「走过来」可一键回到底部居中。

**我想让它彻底消失**
右键 → 退出，并在启动项里取消勾选开机自启。
