# 12 条高频缺陷自检清单

按严重度排序。审自己的提示词、或审别人的，都从 P0 往下过。

| # | 缺陷 | 为什么危险 | 最小修复 | 级别 |
|---|---|---|---|---|
| 1 | **引用退役/不存在的工具名** | 模型不会报错，它会假装调用过，然后基于"看过"编内容 | 对照 `reality-cheatsheet.md` 第二节逐个改名 | P0 |
| 2 | **承诺了做不到的能力** | 例：要求描述图片构图，但角色没有读图能力 → 每一行都是编的 | 要么补能力，要么把该字段降级为"页面级描述"并写明"未读图不得描述" | P0 |
| 3 | **无裁决链** | 规则冲突时模型自行取舍，每次取的不一样，输出不稳定 | 开头加显式优先级段（见 `rtco.md`） | P1 |
| 4 | **自估金额/数值，不用权威源** | "预计费用区间"本质是让模型编数字；有报价接口却不用 | 改为先取真实报价再执行；拿不到就说拿不到 | P1 |
| 5 | **把初筛工具当裁决** | 例：违禁词扫描只在词面匹配，分不清"宣称"与"引用/否定" → 误报被当真 | 降级为线索；命中项必须逐条看上下文；话术固定为"初筛通过" | P1 |
| 6 | **循环无终止条件** | "命中就改，再扫一次"遇到反复命中的词会死循环，或无限重写 | 加"同一处最多 N 轮，仍命中就停手交人判" | P1 |
| 7 | **输出契约缺失** | 用箭头串代替字段，每次交付形态都不一样，无法核对 | 固定字段/小标题 + 缺项取值约定 | P2 |
| 8 | **只有动作清单，没有完成判据** | 全篇都是"做什么"，没有一句"做到什么程度算过" → 模型只能自我感觉良好 | 每模块加一行"合格 = …" | P2 |
| 9 | **一刀切禁令** | "禁止换模型"同时覆盖了"防重复扣费"和"模型下架"，后者会把 Agent 逼进死路 | 拆开写：失败不重提 / 不可用则报错停手 | P2 |
| 10 | **调了工具但没写读什么、读到什么算数** | 例如调 `health` 却不写读 `ok` 与可用性字段，等于走了个过场 | 补一句判据与分支 | P2 |
| 11 | **护栏分散重复** | 同一禁令散在 3–4 处，改一处漏另一处（漂移源） | 合并成一段；或用 soul/system_prompt 分工切干净 | P3 |
| 12 | **缺高危场景专项规则** | 真人肖像、医疗功效、未成年人、金融承诺这类，通用护栏盖不住 | 按场景补一条专项禁令，宁可窄 | P3 |

## 症状 → 根因速查

| 你看到的现象 | 大概率是 |
|---|---|
| 输出开头一堆"好的，以下是…" | 输出契约没约束前后文，也没指定首字符 |
| 规则像没看见 | 规则不可判定（"专业一些""注意质量"） |
| 编造参数、法规、价格 | 缺不确定性出口（`unknowns` / 待核实） |
| 长提示词自相矛盾 | 段落职责重叠，一句话被两段分别规定 |
| 每次格式都不一样 | 只描述格式没给样例 |
| 越写越长越空 | 角色太宽 + 无篇幅上限 |
| 明明做不到却说做了 | P0-1 / P0-2：工具不存在，或能力不存在 |

## 审计命令

```bash
# 结构诊断（裁决链、重复、路径风格、超长）
python scripts/prompt-audit/prompt_audit.py <file>
python scripts/prompt-audit/prompt_audit.py <file> --json

# 退役工具名 / 死路径（仅扫仓库提示词栈，不扫数据库里的 agent）
python backend/scripts/prompt_drift_guard.py
```

机检只能抓结构，抓不到"承诺了做不到的事"——**第 1、2、4、5 条必须人工实测**。
