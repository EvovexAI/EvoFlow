小V「一员工一会话」：微信式委派

真实需求 · 非演示玩具 工作区 EvoFlow 谨慎型交工

目标：打开小V，像微信一样左侧点员工、右侧直接委派；能看进行中进度与最新汇报，工作轨迹按需展开。

  • 1左侧联系人列表：在岗员工可点选；小V 本人会话保留
  • 2右侧对员工输入目标即可派发；展示进行中 Task + 最新汇报
  • 3工作轨迹默认折叠；打开工具详情不得报「缺少会话标识」
  • 4值班派发可续用同一轮工作轨迹，不另起空会话
