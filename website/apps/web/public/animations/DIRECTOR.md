# 智能员工动画 · 导演手册（对齐产品能力）

> 每条必须能对上 [智能体员工是什么](../../../docs/user/explanation/smart-employees.md) 与雇佣模板。  
> **禁止**：空口号、抽象箭头文案、片尾文字清单糊弄。

## 产品能力清单（写进片子的「真本事」）

| 能力 | 产品入口 / 说法 |
|------|----------------|
| 雇岗位 | 智能体员工 → 雇佣员工；模板：研发助理 / 运维值班 / 学习助理 / 内容策划 / 文档管理员 |
| 绑目录 | 管辖工作空间（本机文件夹） |
| 自动上班 | 页头「开启自动上班」+ 上班频率 |
| 立即开工 | 卡片 ⋯「现在开始工作」 |
| 临时派活 | 派发任务；小V 选员工发目标；飞书点名该岗 |
| 正式交工 | 结案填直属下级 → 待审批「同意派发」（飞书或客户端） |
| 同级帮忙 | 派发 / wake，不走同意派发 |
| 看结果 | 工作日志（近 2 天）、任务总结、工作轨迹 |
| 绑飞书 | 扫码绑定；汇报与审批可推到飞书 |

## 1. 概念片 ≈ 55s · `smart-employees/`

**给谁**：第一次听说  
**产品主张**：把 AI 编成岗位合同——职责、文件夹、频率、审批策略；到点主动干、写工作汇报。

| 场 | 演什么（真能力） |
|----|------------------|
| 开场 | 「不是陪聊，是岗位合同」 |
| 场1 | 五个模板名牌依次亮：研发助理…文档管理员 |
| 场2 | 合同四要素卡：职责 / 工作文件夹 / 上班频率 / 审批策略 |
| 场3 | 自动上班开关打开 → 研发助理扫目录 → 工作汇报打出真实模板文案 |
| 收束 | 停在汇报画面：你看结果，偶尔审批 |

## 3. 互相帮忙 ≈ 60s · `smart-employees-collab/`

**给谁**：雇了 ≥2 人、要传活  
**真能力**：两条通道别混。

| 场 | 演什么 |
|----|--------|
| 开场 | 「正式交工 ≠ 临时派活」 |
| 场1 | 对照表：正式交工仅直属下级+同意派发；派发/小V/同级可叫醒、不走该门 |
| 场2 | 研发助理结案 → 下游测试（直属）→ 客户端/飞书「同意派发」→ 子任务叫醒 |
| 场3 | 内容策划 派发/叫醒 文档管理员（同级）——无同意派发按钮 |
| 收束 | 双路径画面停住 |

## 4. 一个人用 ≈ 60s · `smart-employees-indie/`

**给谁**：独立开发者（落地页主人群）  
**真能力**：研发助理模板闭环。

| 场 | 演什么 |
|----|--------|
| 开场 | 「一个人：雇研发助理盯项目目录」 |
| 场1 | 雇佣模板研发助理 → 选管辖工作空间 → 确认上班 → 开自动上班 |
| 场2 | 「现在开始工作」→ 扫脏文件清单打进汇报（对齐模板职责） |
| 场3 | 小V 选该员工临时派一句 → 或飞书推送汇报；打开工作日志 |
| 收束 | 停在工作日志：清单路径 + 建议你处理什么 |

## 5. 小团队 ≈ 60s · `smart-employees-team/`

**给谁**：2～5 人小团队  
**真能力**：多岗 + 待审批 + 日志。

| 场 | 演什么 |
|----|--------|

| 场2 | 左：工作日志近况；右：待审批「同意派发」 |
| 场3 | 点同意派发 → 下游开干；旁路小V/派发同级帮忙 |
| 收束 | 停在双栏：日志 + 待审批清空后的平静 |

## 6. 产品交付线 ≈ 70s · `smart-employees-org/`

**给谁**：要看「组织汇报线 + 真实需求怎么拆」  
**素材**：本机产品交付编制（产品经理 → 技术总监 → 前/后/测）。  
**禁止**：改按钮文案类玩具题；禁止把视频拆解塞进本片。

```text
产品经理（产品）
 └── 技术总监（技术部）
      ├── 前端工程师
      ├── 后端工程师
      └── 测试工程师
```

**本片真实需求**：小V「一员工一会话」（联系人轨 / 委派会话 / 轨迹按需 / 派发续跑同一轮）——对齐已发版能力与验收口径。

| 场 | 演什么 |
|----|--------|
| 开场 | 只讲产品交付线 |
| 场1 | 组织架构 Tab：汇报线 = 正式交工合法下游 |
| 场2 | 产品方案四条验收 → 技术总监拆前/后/测子单 → 同意派发 |
| 场3 | 工作项看板链 + 待审批；收束在交付叙事 |

## 7. 视频拆解 ≈ 70s · `smart-employees-video/`

**给谁**：想用飞书 + 小V 拆抖音创意的人  
**素材**：真实案例「当我用游戏的方式打开制造型企业」（飞书截图 + 网页报告截图 + `analysis_2607270405_1c5b.html`）  
**禁止**：演示 `decompose.js` / 技能脚本调用步骤；本片讲**用户交互**。

| 场 | 演什么 |
|----|--------|
| 开场 | 刷到有趣的视频，也能拆清楚为什么火（**不提小V**） |
| 场1 | 横屏满幅播 `clip-10s.mp4`（**无口播**）→ 播完切手机 → 分享飞书 |
| 场2 | 发给小V（智能体员工助手）「拆解这个视频」→ 派给拆解分析师 |
| 场3 | 过后再问「搞定了吗」→ 要点 + 报告回来 |
| 场4 | iframe 打开本地报告自动滚动 → CTA：评论区内测体验智能体员工 |

## 两类层（必须分开）

| 类型 | 类名 | 放哪 | 怎么写 |
|------|------|------|--------|
| **动画字幕** | `.caption` | 画面旁 / 顶部 pill | 短标签，可两行；`EFAnim.captionIn`，有弹出动效 |
| **口播字幕** | `#vo.vo` | 屏幕**底部居中** | **单句口语**，一句一句换；`EFAnim.say(tl,"#vo",文案,时刻,停留秒)` |

口播示例（口语；成片前 10 秒无口播；字幕 hold 对齐 TTS）：
- 「先看一段视频」
- 「当你在抖音上刷到一条有趣的视频」
- 「想拆清楚它好在哪，不用自己从头分析」
- 「发给小V就行——它是你的智能体员工助手」
- 「跟它说一句：拆解这个视频」
- 「小V马上派给拆解分析师——智能体员工自己开干」
- 「过一会儿再问搞定了吗，要点和报告就回来了」
- 「打开一看：赛道、钩子、评分都齐了」
- 「更重要的是，拆解记录能分类归档，方便以后复盘和学习总结」
- 「评论区聊聊：你最近想拆哪类视频」

禁止：口播上下两行叠在一起；禁止把动画 pill 当口播。

## 自检

- [ ] 岗位名来自 `proactive-hire-templates.js` 或本机真实编制  
- [ ] 出现的按钮/Tab 名与客户端一致  
- [ ] 能对上概念文「入口 / 两条通道 / 同意派发」  
- [ ] 不是「雇人→他自己干→你看结果」这类空箭头  
- [ ] 产品交付片与视频拆解片**不得混在一条时间线**  
- [ ] 视频拆解片讲用户路径（抖音→飞书小V→追问→报告），不是脚本 API 演示
