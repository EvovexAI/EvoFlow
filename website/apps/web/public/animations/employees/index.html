概念片 · 岗位合同

  • 五个开箱模板：研发助理 / 运维值班 / 学习 / 内容 / 文档
  • 岗位合同四要素 + 开启自动上班
  • 研发助理真实汇报文案（清单落盘、建议人处理）
给谁：想动手试试≈70s

怎么用 · 派活 · 审核 · 看报告

定位：日常怎么用、怎么审

  • 雇人上班，绑上飞书
  • 飞书里点名员工派任务
  • 飞书或客户端都能审核；日志里看进度和报告
给谁：雇了 ≥2 人≈60s

互相帮忙 · 两条通道

定位：正式交工 vs 派发 / wake，别混

  • 对照表：正式交工仅直属下级 +「同意派发」
  • 研发助理结案 → 客户端待审批 + 飞书通知 → 点同意派发
  • 内容策划「派发任务」叫醒文档管理员（同级，无同意派发）
给谁：独立开发者≈60s

一个人用 · 研发助理

定位：雇岗绑目录 · 手动或自动上班 · 工作日志看汇报

  • 雇佣员工：研发助理模板、管辖工作空间、谨慎型、确认上班
  • 卡片 ⋯「现在开始工作」→ 扫脏文件清单（不擅自批量删除）
  • 工作日志近 2 天 + 小V 派发；终场停在工作日志
给谁：2–5 人小团队≈60s

小团队 · 日志与待审批

定位：四岗名册 · 左日志右待审批 · 同意派发

  • 研发助理 / 运维值班 / 内容策划 / 文档管理员（部分飞书已绑定）
  • 工作日志近 2 天各岗真实汇报 · 待审批「同意派发」
  • 点同意派发下游开干；旁路小V 同级派发
给谁：产品交付编制≈70s
